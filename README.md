# MMOProject: เมืองอีเดน + เวททุ่งดอกไม้

ต้นแบบเกม MMORPG บนเว็บ เริ่มที่เมืองอีเดน ออกประตูไปฟิลด์รอบเมือง แล้วเดินทางต่อไปอีก 6 เมืองและฟิลด์ 20 แห่งระหว่างทาง เลือกคลาสจอมเวท นักรบ นักธนู หรือนักบวช ตีสไลม์ เก็บเลเวล (สูงสุด 200) แจกแต้มสกิลลงตำราสกิล ความเชี่ยวชาญ และธาตุ เก็บของเข้ากระเป๋า และแต่งตัว
TypeScript (strict) + Canvas 2D, build ด้วย Vite

## เล่น

```sh
npm install
npm run dev        # เปิด http://localhost:5173
npm run build      # ตรวจ type (tsc --noEmit) แล้ว build ลง dist/
npm run typecheck  # ตรวจ type อย่างเดียว
```

Vercel build ด้วย `npm run build` แล้วเสิร์ฟ `dist/` (ดู `vercel.json`) ไฟล์ภาพและ JSON ทั้งหมดอยู่ใน `public/assets/` และเสิร์ฟที่ `assets/...`

และมี `manifest.webmanifest` (เต็มจอ แนวนอน) สำหรับเพิ่มลงหน้าจอโฮม

## หน้าเริ่มเกมและตัวละคร

เปิดเกมแล้วเจอหน้าเลือกตัวละคร (`src/title.ts`) มีได้ 6 ตัวต่อเบราว์เซอร์ เลือกแล้วกดเริ่มเกม (หรือดับเบิลคลิก/แตะสองครั้ง) สร้างใหม่ หรือลบ
- **สร้างตัวละคร** (`src/title.ts`, `src/starter.ts`): ตั้งชื่อ เลือกเพศ สีผม สีตา แล้วเลือกอาชีพ (นักเวท/นักรบ/นักธนู/นักบวช)
  ตำราสกิลเริ่มต้น 1 จาก 3 เล่มของอาชีพ และธาตุเริ่มต้น 1 จาก 4 (ดิน น้ำ ลม ไฟ) ทั้งสามแถวเลือกจากไอคอน
  (อาชีพใช้ไอคอนความเชี่ยวชาญของอาวุธประจำอาชีพ) ชื่อและคำอธิบายของอันที่เลือกขึ้นใต้แถว มีภาพตัวละครหมุนดูได้
  ความเชี่ยวชาญเริ่มต้นไม่ต้องเลือก ได้ของอาวุธประจำอาชีพเสมอ (นักเวท ไม้เท้า · นักรบ ดาบ · นักธนู ธนู · นักบวช ค้อน)
- ทุกคนเริ่มด้วยผมบ็อบธรรมดาและชุดสีน้ำตาล ทรงผมกับชุดอื่นหาได้ในเกม ตัวละครใหม่ถืออาวุธประจำอาชีพ
  และของมือรองตามอาชีพถ้าอาวุธเป็นแบบมือเดียว (นักเวทและนักบวชได้สมุดเวท นักรบได้โล่ไม้กลม)
  ในกระเป๋ามีแค่ยาแดงกับยาฟ้าอย่างละ 5 และ 200 ทอง
- ทุกตัวละครเซฟแยกกันใน localStorage (`src/save.ts`: `mmoproject.c<id>.*` และรายชื่อใน `mmoproject.roster.v1`) เซฟจากก่อนมีระบบนี้กลายเป็นตัวละคร 1
- ในเกมกลับไปหน้าเลือกตัวละคร หรือออกจากเกม ได้จากเมนูตั้งค่า (<kbd>O</kbd>)

## คลาส เลเวล และค่าสถานะ

อาชีพเลือกตอนสร้างตัวละครและเปลี่ยนไม่ได้ ตัวละครรู้แค่ตำราสกิลกับธาตุที่เลือกตอนสร้าง และความเชี่ยวชาญอาวุธประจำอาชีพ
ที่เหลือต้องหาตำรามาอ่านในเกม (หน้าต่างสกิลกับโปรไฟล์แสดงเฉพาะที่เรียนแล้ว) ตัวละครจากก่อนมีระบบนี้ได้ทุกอย่างที่เคยใช้ได้

| คลาส | จุดเด่น | ตำราสกิลของอาชีพ |
| --- | --- | --- |
| นักเวท | MP และพลังเวทสูง HP ต่ำ | เวทโจมตี, เวทพฤกษา, เวทผนึก |
| นักรบ | HP พลังโจมตี และพลังป้องกันสูง | ผู้ทำลาย, ผู้พิทักษ์, นักดาบพริ้ว |
| นักธนู | ยิงไกล คริติคอลสูง ตีเร็ว (เริ่มด้วยธนู) | ธนูทำลาย, ธนูพายุ, ธนูพราน |
| นักบวช | ฮีลและบัฟตัวเอง ต้านเวทสูง (เริ่มด้วยค้อนกับสมุดเวท) | เวทฟื้นฟู, เวทสนับสนุน, นักบวชนักรบ |

- เลเวลสูงสุด 200 ค่าประสบการณ์ต่อเลเวลคือ `round(25·L^1.55 + 15)` (`src/progression.ts`)
- ทุกเลเวลได้ 1 skill point (เลเวล 1 มี 1 แต้ม) แจกได้สามทาง: ตำราสกิล ความเชี่ยวชาญ ธาตุ
  ลงแต้มต้องยืนยันก่อนทุกครั้ง และคืนแต้มไม่ได้
- ค่าสถานะ (`src/stats.ts`): HP, MP, พลังโจมตี, พลังเวท, ป้องกัน, ป้องกันเวท, คริติคอล, แรงคริติคอล, ความเร็วโจมตี, ความเร็วเดิน, ลดคูลดาวน์, ลดเวลาร่าย, ฟื้น HP/MP, โชคดี, หลบเวท
  โอกาสคริติคอลตันที่ 50% (`CRIT_CAP`) ทั้งค่าสถานะและโอกาสจริงหลังคูณโชค แหล่งคริติคอลทุกแหล่ง (ความเชี่ยวชาญ ธาตุ ต้นสกิล อาวุธ อาชีพ) ลดลงราวครึ่งหนึ่งใน v0.2
  **โชคดี** (`luck`): ทุกอย่างที่สุ่มของตัวละครผ่าน `lucky(chance, stats)` ซึ่งคูณโอกาสด้วย `luckFactor` = 1 + โชค/100 (โชค 20 → โอกาส ×1.2)
  ได้แก่ คริติคอล ยิงซ้อน ตีให้มึน ตีติดพิษ เหยี่ยว คูลดาวน์หายของลม แช่แข็ง สถานะของความมืด สาปหิน และโอกาสตาบอดตอนโดนกัดก็ลดลง
  มอนสเตอร์คริติคอลใส่เราน้อยลง (หารด้วย `luckFactor`) ของดรอปและทอง ×(1 + โชค/200) และลูกเต๋า (`rollDie`) มีโอกาส โชค% (สูงสุด 80%) ทอยสองครั้งเอาค่าดีกว่า
  **หลบเวท** (`magicDodge`, สูงสุด 60%): โอกาสที่การโจมตีเวทของมอนสเตอร์ (ตัวร่ายเวท และกระสุนที่ไม่ใช่ลูกศร ปืน หิน ฯลฯ, `Monster.magical`) ไม่โดนเลย มาจากธาตุควัน
  ฟื้น HP/MP มาเป็นก้อนทุก 5 วิ (`REGEN_TICK` ใน `src/hero.ts`) เท่ากับอัตราต่อวินาที × 5 เช่น ฟื้น 4/วิ ได้ 20 ทุก 5 วิ หน้าโปรไฟล์แสดงเป็น "20 / 5 วิ" ยาจึงเป็นทางฟื้นทันที
- MP ของสกิลขึ้นตามระดับ (`mpCost`): ค่าที่เขียนไว้คือระดับ 1 ระดับสูงสุดใช้มากขึ้น 80% (สกิลระดับเดียวไม่เปลี่ยน) หน้าต่างสกิลบอก MP ระดับนี้และระดับถัดไป ตารางระดับมี MP ทุกระดับ
  ลดเวลาร่าย (`castRed`, สูงสุด 60%) ย่อเวลาร่ายของสกิลที่ต้องร่าย แยกจากลดคูลดาวน์ (สูงสุด 50%) มาจากร่ายไว (4%/ระดับ)
  ความเชี่ยวชาญไม้เท้าระดับ 20 (8%) สมุดเวท (5%) คัมภีร์โบราณ (10%) หมวกพ่อมด (5%) และแหวนบทร่าย (8%, ร้านค้า 950)
  มาจากค่าตั้งต้นของคลาส + การเติบโตต่อเลเวล + ธาตุ + passive + บัฟ
- สูตรดาเมจ: ตีปกติ = (ดาเมจสุ่มของอาวุธ + พลังโจมตี) × (1 + โบนัสดาเมจ) ไม้เท้าใช้พลังเวทแทน
  สกิล = (พลังโจมตีหรือพลังเวท + พลังอาวุธ) × ตัวคูณของสกิล
  คริติคอลคูณ (1 + แรงคริติคอล) แล้วลดตามป้องกัน `× 100 / (100 + def)` (ป้องกัน 100 รับดาเมจครึ่งเดียว)
- **ธาตุแฝงในทุกการโจมตี** (`elementBonus` ใน `src/stats.ts`): หลังได้ดาเมจแล้ว ทุกธาตุเอา พลังโจมตีธาตุของผู้ตี − ป้องกันธาตุนั้นของเป้า
  (ติดลบนับเป็น 0) มาบวกเข้าดาเมจตรง ๆ ทั้งตีปกติและสกิล เช่น ดาเมจ 100 ไฟ 60 ดิน 30 ใส่เป้าที่ป้องกันไฟ 20 ดิน 50 → 100 + 40 = 140
  การโจมตีที่มีธาตุ (สกิลธาตุ หรืออาวุธที่เคลือบธาตุ) ยังบวก พลังโจมตีธาตุนั้น × 1.5 (`ELEMENT_SWING`) เข้าไปในพลังโจมตี/พลังเวทก่อนคำนวณด้วย
  ส่วนบวกจากธาตุไม่คูณคริติคอล มอนสเตอร์ที่กัดเป็นธาตุก็คิดแบบเดียวกันกับป้องกันธาตุของผู้เล่น
  ตัวเลขดาเมจคริติคอลเป็นสีเหลืองบนรูประเบิดสีแดง (หนามและเอียงสุ่มต่อครั้ง) ดาเมจปกติสีครีม เวทสีฟ้า

เลเวล 30 ขึ้นไปเปลี่ยนอาชีพได้ครั้งเดียว ต้องไปหาเจ้าอาชีพในเมืองเอง คุยแล้วเขาบอกเงื่อนไขในหน้าเควส

**กลไกใหม่**
- สกิลตามอาวุธ (`need`): บางสกิลใช้ได้เฉพาะอาวุธที่ถือ (`{ weapons }` มือหลัก หรือ `{ dual }` อาวุธมือเดียวทั้งสองมือ)
  ใช้ไม่ได้ช่องในแถบสกิลจะมืดและบอกเหตุผล (เช่น "ต้องถือดาบมือเดียว ทั้งสองมือ") passive ที่มี `need` นับเฉพาะตอนถือครบ
  สกิลจากความเชี่ยวชาญก็ต้องถืออาวุธชนิดนั้น
- เผ่าของมอนสเตอร์ (`RACE_OF` ใน `src/bestiary.ts`): ไร้รูปร่าง อันเดด สัตว์ป่า พืช แมลง ปลา ปีศาจ มนุษย์ เทวดา มังกร
  ป้ายชื่อมอนแสดงเป็นสัญลักษณ์หน้าชื่อ (`RACE_ICONS`): หยดน้ำ หัวกะโหลก รอยเท้าสัตว์ ใบไม้ แมลง ปลา หัวมีเขา คน ปีก หัวมังกร
  ขึ้นท้ายชื่อบนป้าย ค่า `undeadDmg`, `demonDmg`… เพิ่มดาเมจใส่เผ่านั้น และสกิลมี `vs` (เช่นเวทแสงแรงใส่อันเดด)
- ธาตุพิษ (`poison`, ตำราธาตุพิษ): พิษแรงขึ้น (`poisonPct`) ศรพิษ หมอกพิษ ฝนพิษ เป็นธาตุพิษแล้ว อันเดดต้านพิษ 40% ไร้รูปร่าง 25%
  สกิล `detonate` จุดพิษที่ค้างในตัวมอนให้ระเบิดทีเดียวแล้วล้างพิษออก
- กับดัก (`trap`): วางตรงจุดที่เล็ง ตั้งพร้อมใน 0.5 วิ มอนตัวแรกที่เดินเข้ามาทำให้ระเบิดใส่ทุกตัวในวง วางได้ 3 อันพร้อมกัน อยู่ 20 วิ
- เหยี่ยว (`falcon`): สกิลสั่งเหยี่ยวโฉบใส่เป้าที่ล็อก และ `falconChance` ให้เหยี่ยวโฉบตามเองตอนตีปกติ แรงตาม `falconPower`
- เคลือบธาตุ (`enchant` ของบัฟ): อาวุธตีเป็นธาตุนั้นตลอดเวลาบัฟ (ตีปกติและสกิลกายภาพที่ไม่มีธาตุของตัวเอง) ทีละธาตุ
- ดูดเลือด (`lifesteal` และ `drain` ของสกิล) ยิ่งเลือดน้อยยิ่งแรง (`lowHpDmg`) สกิลแรงตามระดับความเชี่ยวชาญอาวุธที่ถือ (`masteryScale`)
  และสกิลที่ใช้ทั้งพลังโจมตีและพลังเวท (`stat: "both"` อย่างละ 0.6 โดนแน่นอนแบบเวท)

**กลไกของอาชีพ v0.2** (`src/trees/v02jobs.ts`)
- ตีซ้ำ (`doubleHit`, หัวขโมยถือมีดสั้น): ตีปกติมีโอกาสโดนอีกครั้งทันที (โชคดีช่วย สูงสุด 60%)
- ขโมย (`steal` + `stealChance` ของสกิล): ทอง (เลเวลมอน × 4–8) หรือของดรอปชิ้นหนึ่งของมันตามโอกาสดรอป มอนแต่ละตัวโดนขโมยได้ครั้งเดียว (`Monster.stolen`)
- ซ่อนตัว (บัฟที่มี `stealth`): มอนสเตอร์มองไม่เห็นและเลิกไล่ (`MonsterCtx.unseen`) การโจมตีครั้งแรกขณะซ่อนแรงขึ้นตาม `ambush` แล้วหายจากการซ่อน (`Hero.reveal`)
- ร่างแยก (สกิล `decoy`): ร่างของผู้เล่นสีจางยืนข้างหน้า มอนทุกตัวหันไปไล่และกัดร่างแยกแทน (HP ตามสัดส่วน HP สูงสุด) จนหมดเวลาหรือ HP หมด
- ลูกเต๋า (`dice`): สกิลโจมตีทอยเต๋าทุกครั้งที่โดน ดาเมจ × แต้ม/3.5 บัฟเสี่ยงดวงบวก `roll` × (แต้ม − 3)/3 (แต้ม 1 ลดลง แต้ม 6 ได้เต็ม) โชคดีช่วยให้ทอยสองครั้งเอาค่าดีกว่า (`rollDie`)
- โล่ในมือรอง (`need.shield`, `offhandKind`): สกิลหอกกับโล่ต้องถือหอกมือเดียวและโล่ไม้กลม/โล่อัศวิน
- ตัวตลกได้ค่าโชคดี 10 และ +0.3 ต่อเลเวลหลังเปลี่ยนอาชีพ อาชีพใหม่ยังใช้ตราคลาสเดิมจนกว่าจะมีภาพตราอาชีพ

**ตำราใหม่ 10 เล่ม** อ่านได้ทุกอาชีพ ดรอปจากมอนสเตอร์ในฟิลด์เหมือนตำราอื่น: ตำราจอมเวทน้ำแข็ง ตำราจอมเวทสายฟ้า ตำรานักดาบพายุคลั่ง
ตำราพื้นฐานพลังเวท ตำราพื้นฐานร่างกาย ตำราพื้นฐานการต่อสู้ ตำราตาเหยี่ยว ตำราบทสวด ตำรานักดาบศักดิ์สิทธิ์ ตำราพ่อค้าพเนจร
(ตำราพื้นฐานทั้งสามเล่มดรอปจากมอนสเตอร์ในฟิลด์)

**ตำราพ่อค้าพเนจร** (`merchant`, ดรอปจากมอนสเตอร์): ต่อรองราคา (ซื้อของจากร้าน NPC ถูกลง 2%/ระดับ)
ปากหวาน (ขายของให้ร้านได้ราคาเพิ่ม 3%/ระดับ) กระเป๋าใบใหญ่ (+4 ช่อง/ระดับ) เท้าพเนจร (เดินเร็วขึ้น) ตาพ่อค้า (ทองจากมอน +6%/ระดับ)
ตาถึงของดี (โอกาสได้ของ) เส้นสายนักเดินทาง (ค่าเดินทางกับผู้นำทางถูกลง 5%/ระดับ) ราชาพ่อค้า และกองคาราวาน (+8 ช่องต่ออัน)
เต็มที่แล้วซื้อถูกลง 25% ขายได้เพิ่ม 40% กระเป๋าจาก 40 เป็น 76 ช่อง (`bagSlots`, `Inventory.resize`) ร้านไม่รับซื้อของที่ตัวเองขาย
แพงกว่าราคาที่ขายให้ (ซื้อมาขายคืนไม่มีกำไร) ส่วนลดสูงสุด 50% กระเป๋าใหญ่เกิน 7 แถวจะเลื่อนดูได้

ตรวจต้นสกิลทั้งหมดด้วย `node tools/tree_check.cjs` (ตำแหน่ง เงื่อนไข ค่าสถานะ ตัวเลขในคำอธิบาย)

**การร่ายเวท** (`src/skills.ts`): สกิลโจมตีหลักของจอมเวทต้องร่ายก่อน (ศรเพลิง 1 วิ ศรน้ำแข็ง 0.8 ห่าศรวิญญาณ 1 ลูกไฟระเบิด 1.6
หอกน้ำแข็ง 1.8 ลำแสงทำลายล้าง 2.5 พายุอุกกาบาต 3 หนามพันธนาการ 1.2 แส้เถาวัลย์ 0.8 พายุกลีบดอก 1.5 แรงโน้มถ่วง 1.8 หลุมดำ 2.8)
แลกกับดาเมจแรงขึ้นราว 2–2.5 เท่า ระหว่างร่ายยืนนิ่งใต้แถบร่าย เวทออกเมื่อแถบเต็ม แล้วจึงเสีย MP และเริ่มคูลดาวน์
เดิน (ปุ่มหรือคลิกพื้น) ระหว่างร่ายคือยกเลิก ไม่เสียอะไร มอนที่ตกเป็นเป้า (ตัวที่ล็อก หรือตัวในวงที่เล็ง) รู้ตัวทันที มี "!" ขึ้นหัว
แล้วหันมาโจมตีพร้อมฝูง สกิลวางพื้นจะตามมอนตัวที่เล็งไว้ไปตกตรงที่มันอยู่ตอนแถบเต็ม สกิลเป้าเดียวที่เป้าตายก่อนจะไม่ออกและไม่เสีย MP
ลูกศรเวท เมล็ดพุ่ง และสกิลป้องกันตัว (โล่มานา คลื่นผลัก วงแหวนเยือกแข็ง ผนึกกาลเวลา เทเลพอร์ต) ยังใช้ได้ทันที

ระหว่างร่ายมีวงเวทใต้ตัวแบบทุ่งดอกไม้ (`src/circles.ts` วาดด้วยโค้ด, `src/castfx.ts` เอฟเฟกต์) แต่ละสกิลมีสี
รูปตรงกลาง และอักขระของตัวเอง อักขระแยกตามสำนัก: ไฟเป็นขีดแหลมมีเปลว น้ำแข็งเป็นเส้นตรงทำมุม 60° เวทลี้ลับเป็นวงกับจุด

**ตำราสกิล** (`TREES`, ในโค้ดเรียก tree): ต้นสกิลมีสกิลน้อย ตัวละครเก่งขึ้นจากความเชี่ยวชาญ ธาตุ และของสวมใส่เป็นหลัก (`TREE_SKILLS`: ต้นของคลาสแรก 5 สกิล สายอาชีพที่ 2 มี 6 สกิล คลาสที่ 3, 4, 5 ในอนาคตจะมี 7, 8, 9) สกิลที่เหลือในแต่ละต้นมีทั้งตีเป้าเดี่ยว ตีเป็นวง บัฟหรือ passive และสกิลปิดท้าย แต่ละต้นยังเล่นต่างกัน
วางแบบหน้าต่างสกิลของ Ragnarok คือแต่ละต้นมีสกิลเริ่มต้นหลายตัวในแถวบน แต่ละตัวแตกเป็นสายของตัวเอง
บางช่องต้องมีแต้มในสายข้าง ๆ ด้วย (`req`: ช่องไหนถึงระดับเท่าไร) และระดับสูงสุดมี 1, 5 หรือ 10 ต้นไม่ได้มาบรรจบที่ช่องเดียว แต่ละต้นหน้าตาต่างกัน
ช่องวางเป็นตาราง 4 คอลัมน์ (`pos`) เส้นเชื่อมมีป้าย "Lv N" บอกระดับที่ต้องมี (ชี้ดูประโยคเต็ม)

ชนิดสกิลที่เพิ่มมา: ระเบิดตรงจุดที่เล็งได้หลายครั้ง (`hits` ของ `blast` เช่น อุกกาบาต 4 ลูก) และพุ่งโดยไม่มีตัวคูณดาเมจคือเทเลพอร์ต (บอทไม่ใช้เป็นท่าโจมตี)
ยิงทีละหลายลูกต่อกันได้ด้วย `hits` กับ `every` ของ `bolt` (ศรพันดอก ยิงกระหน่ำ) และ `arrow` ทำให้เป็นลูกธนูจริง

**ชื่อและ HP ของมอนสเตอร์** ขึ้นใต้เท้าตัวที่ล็อกเป้าอยู่ (หรือที่บอทกำลังล่า) และตัวที่เราทำดาเมจใส่ภายใน 8 วินาที: เลเวล ชื่อ และหลอด HP พร้อมตัวเลข (ตัวหายากและบอสชื่อสีทอง)

**สถานะผิดปกติของมอนสเตอร์** ขึ้นเป็นไอคอนเล็กเหนือหัว:
- พิษ (`poison`) กัดเพิ่มตามสัดส่วนของดาเมจใน 4 วินาที (ตีปกติติดพิษได้จาก "เคลือบพิษ")
- ช้า มึน แช่แข็ง แบบเดิม
- อ่อนแรง (`weaken`) กัดเบาลงตามเปอร์เซ็นต์
- ทำลายเกราะ (`expose`) โดนแรงขึ้นตามเปอร์เซ็นต์ ทั้งสกิลและตีปกติ
- ตาบอด (`blind`) กัดพลาดครึ่งหนึ่ง
อ่อนแรงกับทำลายเกราะอยู่ `debuff` วินาที (ตั้งต้น 6) ธาตุดินระดับ 10 ทำให้ทุกสถานะนานขึ้น 30%

ค่าสถานะใหม่จากต้นสกิล: พลังรักษา (`healPct`) โอกาสยิงซ้อนตอนยิงธนูปกติ (`multiShot`) โอกาสตีติดพิษ (`poisonHit`)
ดาเมจใส่ศัตรูที่ติดสถานะ (`huntDmg`) และเวลาบัฟ (`buffTime`)
เซฟจากต้นสกิลแบบเดิมได้แต้มต้นสกิลคืนทั้งหมดหนึ่งครั้ง (`treesV` ล่าสุดตอนตัดเหลือต้นละ 5–6 สกิล) แต้มความเชี่ยวชาญกับธาตุยังอยู่ ตำราสกิลอื่นเรียนจากตำราที่หาได้ในเกม ("ผู้รอดชีวิต" ใช้ได้ทุกอาชีพ)

**ของดรอป** (`src/loot.ts`): ของที่มอนสเตอร์ดรอปตกลงพื้นรอบจุดที่ตาย (ทองยังเข้ากระเป๋าเงินทันที) เดินไปเหยียบในระยะ 70 ซม. หรือคลิกที่ของเพื่อเดินไปเก็บ
กระเป๋าเต็มของจะอยู่ที่พื้นต่อ ของอยู่ได้ 2 นาที (กะพริบก่อนหาย 12 วินาที) และหายเมื่อเปลี่ยนแผนที่

**ตารางดรอปของมอนสเตอร์** (`src/drops.ts`, `fieldDrops`): มอนสเตอร์ในฟิลด์ทุกตัวดรอปวัตถุดิบตามเผ่า (`MATERIAL_OF`)
สัตว์ แมลง สัตว์น้ำ → หนังสัตว์ · ไร้รูป มนุษย์ อันเดด → แร่เหล็ก · พืช ปีศาจ เทวะ มังกร → เศษอัญมณี (มังกรได้หนังสัตว์ด้วย)
ตัวธรรมดา 12% (ตัวถึก 14% ตัวไว 11%) ตัวหายาก 60% บอส 96% แก่นอสูร 1.5% + 0.03% ต่อเลเวล (ตัวหายาก ×10 บอส ×16)
หินนภาและหินดาราอย่างละ 0.4% (ตัวหายาก 5% บอส 30%) และอุปกรณ์ของช่วงเลเวลตัวเอง (`gearTierAt`: เลเวล 30–59 ได้ของเลเวล 30 ฯลฯ)
ตัวธรรมดา 0.3% ตัวหายาก 6% บอส 40% สุ่มชิ้นใดก็ได้ในช่วงนั้น (`TIER_DROP`) ทุกโอกาสเพิ่มตามโอกาสได้ของและโชคดีของผู้เล่น
มอนสเตอร์ในเกมสูงสุดเลเวล 105 อุปกรณ์เลเวล 120 ขึ้นไปจึงได้จากการสร้างเท่านั้น

**ตำรา** (`BOOKS`): ตำราสกิลทุกเล่ม ความเชี่ยวชาญทุกอย่าง และธาตุทุกธาตุมีตำราของตัวเอง (`book_<kind>_<id>`)
ดับเบิลคลิกในกระเป๋าเพื่ออ่าน ตำราสกิลของอาชีพอื่นอ่านไม่ได้ มอนสเตอร์ในฟิลด์ดรอปตำราที่ผู้เล่นยังเรียนได้
แต่หายากมาก (`BOOK_CHANCE`: ตัวธรรมดา 0.04% ตัวหายาก 2% บอส 25%) สไลม์ยังดรอปตำราผู้รอดชีวิต เก็บเกี่ยว และสายฟ้า (เล่มละ 0.03% สไลม์ม่วง 0.2%) ร้านค้าไม่ขายตำรา
สไลม์รอบอีเดนดรอปน้อย: เยลลี่ 40–60% ใบอ่อน (สไลม์เขียว 3% สไลม์ม่วง 20%) และไม่ดรอปชุด ชุดซื้อได้ที่ร้านค้า

**ตำราขั้นสอง**: ความเชี่ยวชาญอาวุธทุกอย่าง (`book_mastery2_<id>` ขยายถึง 60) และธาตุทุกธาตุ (`book_element2_<id>` ขยายถึง 100)
อ่านได้เมื่อเรียนเล่มแรกแล้วเท่านั้น ดรอปจากมอนสเตอร์เลเวล 40 ขึ้นไปเท่านั้น (`TIER2_DROP_LEVEL`) มูลค่า 9000 ทอง
ที่อ่านแล้วเก็บในเซฟ (`extended`) ช่วงขั้นสองของเส้น (และจุดบนเส้นช่วงนั้น) ขึ้นในหน้าต่างสกิลเมื่ออ่านตำราแล้วเท่านั้น
ไอคอนตำราขั้นสองใช้ภาพของเล่มแรกพร้อมป้าย "II" ที่มุมขวาล่าง (`icon.badge`)

**หน้าต่างสกิล** (<kbd>K</kbd>): กด + จองแต้มได้หลายแต้ม (− คืน) แถบด้านบนสรุปว่าจะลงอะไรเท่าไร แล้วกดยืนยันทีเดียว แท็บตำราสกิลวาดต้นไม้พร้อมเส้นบอกว่าต้องอัพอะไรถึงระดับเท่าไรก่อน สกิลที่ทำดาเมจบอกธาตุที่โจมตี (หรือไร้ธาตุ) คลิกสกิลเพื่อดูตารางทุกระดับ (เปอร์เซ็นต์ ส่วนที่เพิ่ม และดาเมจโดยประมาณจากค่าสถานะตอนนี้) แท็บความเชี่ยวชาญและธาตุเป็นเส้นตรงที่มีจุดความสามารถพิเศษ ชี้ที่จุดเพื่อดูรายละเอียด ลากสกิลไปวางที่แถบสกิล หรือดับเบิลคลิกเพื่อใส่ช่องว่างช่องแรก คลิกขวาที่ช่องเพื่อถอด
แถบสกิลกับความคืบหน้าทั้งหมดเซฟใน localStorage (`mmoproject.character.v1`)

## บอทล่ามอนสเตอร์

บอท (`src/bot.ts`, หน้าต่าง `src/botui.ts`) ล่าสไลม์รอบจุดที่ยืนตอนกดเริ่ม เดินอ้อมบ้าน บ่อน้ำ และพุ่มไม้ด้วยการหาเส้นทางบนกริด 40 ซม. (`findPath` ใน `src/world.ts`)
ตั้งค่าได้ในหน้าต่าง <kbd>B</kbd> และเซฟไว้ใน localStorage (`mmoproject.bot.v1`)

- **สกิล:** ทุกสกิลที่เรียนแล้วมีกฎของตัวเอง เปิด/ปิด และเลื่อนลำดับได้ (บนสุดใช้ก่อน) เงื่อนไขมี 3 แบบ:
  - ทันทีที่พร้อม: สกิลโจมตีใช้เมื่อเป้าหมายอยู่ในระยะ ส่วนฮีล โล่ และบัฟใช้ระหว่างสู้เมื่อเลือดไม่เต็ม ไม่มีโล่ หรือบัฟหมด
  - เมื่อ HP ต่ำกว่า X%
  - เมื่อมอนในวงสกิล (หรือรอบตัว) มีอย่างน้อย N ตัว
  สกิลที่เรียนใหม่จะเพิ่มท้ายรายการพร้อมเงื่อนไขตั้งต้นตามชนิด
  สกิลโจมตีที่ถึงเงื่อนไขแล้วแต่ MP ยังไม่พอ จะกัน MP ส่วนนั้นไว้ สกิลที่อยู่ล่างกว่าใช้ได้เฉพาะ MP ที่เกินจากนั้น
  (ไม่งั้นสกิลถูก ๆ จะใช้ MP ทันทีที่ฟื้น จนสกิลใหญ่ด้านบนไม่ได้ใช้เลย) สกิลที่แพงเกิน MP สูงสุดไม่กันอะไร
- **ตีปกติ:** ตีระหว่างรอคูลดาวน์ ถ้าปิดไว้ บอทจะยืนห่างตามระยะของสกิลที่สั้นที่สุด
- **เป้าหมาย:** เลือกชนิดสไลม์ที่จะล่า เลือกตัวที่ใกล้ที่สุด เลือดน้อยที่สุด หรือเลเวลสูงที่สุด และเลือกได้ว่าจะสู้กับตัวที่โจมตีเราก่อนเสมอ
- **พื้นที่ล่า:** รัศมี 3–25 ม. รอบจุดศูนย์กลาง (เส้นประบนพื้น) ย้ายจุดศูนย์กลางมาที่ตัวละครได้ ไม่มีมอนในเขตก็เดินกลับไปรอที่จุดศูนย์กลาง
  หรือติ๊ก "ล่าทั้งแผนที่" ให้ไล่ตัวไหนก็ได้ทั่วลาน (ซ่อนเส้นประและแถบรัศมี) ไม่มีมอนเหลือก็ยืนรอตรงนั้นจนมีตัวเกิดใหม่
- **พักฟื้น:** HP หรือ MP ต่ำกว่าที่ตั้งไว้และไม่มีตัวไหนไล่ตีอยู่ จะนั่งพัก (ฟื้น 2.5% ต่อวินาที) จนถึงระดับที่ตั้งไว้ และเก็บ MP ส่วนหนึ่งไว้ให้สกิลช่วยเหลือได้
- **เก็บของ:** ติ๊ก "เดินไปเก็บของที่ดรอป" (เปิดไว้ตั้งแต่ต้น) แล้วระหว่างไม่มีตัวไหนไล่ตี บอทจะเดินไปเหยียบของที่ตกในเขตล่า (ล่าทั้งแผนที่: ในระยะ 9 ม.) ก่อนหาตัวต่อไป ไปไม่ถึงจะข้ามชิ้นนั้น 8 วินาที
- **อื่น ๆ:** หยุดเมื่อกระเป๋าเต็ม ตัวละครล้มเมื่อไรบอทหยุดเองเสมอ
- กดเดิน คลิก หรือ Space เองได้ตลอด บอทจะหยุดรอ 2.5 วินาทีแล้วทำต่อ เดินไปหาเป้าหมายไม่ได้นานเกิน 1.2 วินาทีจะข้ามตัวนั้นไป 8 วินาที
- ระหว่างทำงานปุ่ม "ออโต้" ข้างแถบสกิลขึ้นว่าหยุดออโต้ หน้าต่างบอทบอกสถานะ เวลา จำนวนที่ล่าได้ EXP และของที่ได้

## เมืองอีเดนและแผนที่

- **อีเดน** (`src/world3d/town_eden.ts`) เมืองเริ่มต้น วางตามผังที่วาดมือ (ทิศเหนือขึ้นจอ 1 พิกเซลผัง = 18 ซม. แล้วย่อทั้งเมืองเหลือ 85% ด้วย `TOWN_SCALE` ทั้งตึก ถนน ต้นไม้ กรอบชน และตำแหน่งชาวเมือง ตัวเมืองราว 150 × 128 ม.)
  มีกำแพงเมืองและประตู 3 ทิศ ถนนใหญ่สองสายตัดกันกลางเมือง และย่านละหนึ่งลาน:
  มหาวิหาร (ตะวันตกเฉียงเหนือ) ตลาด (ตะวันออกเฉียงเหนือ) สวนวีรบุรุษ (ตะวันตกเฉียงใต้) ลานน้ำพุกับโรงเตี๊ยมและร้านเครื่องมือ (ตะวันออกเฉียงใต้)
  และย่านท่าเรือริมทะเลฝั่งตะวันออก มีแอ่งจอดเรือ ท่าเทียบเรือ เรือใหญ่ และประภาคาร
- **บ้านเรือน** เรียงติดกันเป็นแถวตลอดแนวถนนแบบพรอนเทร่า เว้นซอยเข้าลาน บ้านแต่ละหลังสลับแบบและสีหลังคา/ผนัง
  ของทุกชิ้นมาจากชุดของเมือง (`src/world3d/kits/`) วาดเป็น instanced mesh แยกตามบล็อก 50 ม. บล็อกที่อยู่นอกจอจึงไม่เสียแรงวาด
- **มองทะลุตึก:** ตึกหรือต้นไม้ที่บังผู้เล่นจะโปร่งเป็นวงรอบตัว (dither) ถนนระหว่างตึกสูงจึงยังมองเห็น
- **ชาวเมือง** (`src/npcs.ts`) ยืนตามจุดแดงในผัง: ทหารยามประตู ผู้นำทาง นักบวชรักษาฟรี ร้านเครื่องมือ กะลาสี ฯลฯ หันหาผู้เล่นเมื่อเข้าใกล้ เหนือหัวมีแค่ชื่อกับฉายา (ฉายาสว่างขึ้นเมื่ออยู่ในระยะคุย) คุยด้วยแล้วขึ้นหน้าต่างคุย (ดูหัวข้อ "คุยกับชาวเมือง และเควส")
- **วาร์ป:** เดินเข้าวงแสงสีฟ้าหน้าประตูเพื่อออกไปฟิลด์ข้างนอก (ประตูตะวันตก: ทุ่งหญ้าตะวันตก ประตูเหนือ: ถนนหลวง ประตูใต้: ทุ่งสะวันนาใต้) และวงแสงในฟิลด์พากลับ
  วาร์ปพาไปถึงจุดของแผนที่ปลายทางที่บอกว่า "มาจากแผนที่ไหน มาโผล่ตรงไหน" (`gates` ของแต่ละแผนที่) จึงไปและกลับได้ทุกทาง
  ในเมืองไม่มีมอนสเตอร์ ตายแล้วฟื้นที่ลานน้ำพุของอีเดน
- **เรือโดยสาร:** กัปตันที่ท่าเรืออีเดนพาไปโยเดียหรือโอซากิ กัปตันที่โยเดียและโอซากิพากลับอีเดน (เปิดแผนที่โลกให้เลือกได้แค่ท่าเรือของเรือลำนั้น)
- **แผนที่** (`src/maps.ts`) สร้างครั้งแรกที่เข้าแล้วเก็บไว้ เมื่อเข้าแผนที่ กรอบชน ขอบเขต และตาราง path ของ `src/world.ts` เปลี่ยนตาม
- **หน้าโหลด:** ตอนเข้าเกมและตอนเปลี่ยนแผนที่ หน้าโหลดบังจอพร้อมแถบความคืบหน้าจนกว่าทุกอย่างพร้อม: สร้างฉาก แต่งตัวชาวเมืองครบ
  compile shader ทุกตัวของฉาก (`World3D.compile`) และถ่ายภาพแผนที่ ระหว่างนั้นเกมหยุดรอ จึงไม่มีเฟรมกระตุกหรือคนที่ยังไม่ได้แต่งตัวโผล่มา

### Minimap และหน้าต่างแผนที่ (`src/mapui.ts`, `src/worldmap.ts`)

- **ภาพแผนที่** ของแต่ละที่คือฉาก 3 มิติจริงมองจากด้านบนตรง ๆ ทิศเหนือขึ้น (`World3D.snapshot`) ถ่ายในเฟรมแรกที่เข้าแผนที่นั้นแล้วเก็บไว้
  วาดเป็นแผ่น ๆ ลงมุมของ canvas เกมเองแล้วคัดลอกออก shader ทุกตัวจึงไม่ต้อง compile ใหม่ ปิดหมอกและการมองทะลุตึกตอนถ่าย
  และยกดวงอาทิตย์ให้สูงขึ้นเงาจะได้สั้น ภาพกว้างกว่าขอบเขตเดินได้ 10 ม. ทุกด้านให้เห็นวงวาร์ป (คอม 2048 พิกเซล มือถือ 1280)
- **Minimap** มุมขวาบน รัศมีราว 60 ม. รอบตัว (มือถือ 48 ม.) ทิศเหนือขึ้นเสมอ ลูกศรคือทางที่ตัวละครหัน พัดจาง ๆ คือทางที่กล้องมอง
  จุดเหลืองร้านค้า จุดเขียวนักบวช จุดขาวชาวเมือง จุดแดงมอนสเตอร์ วงฟ้าวาร์ป บนมือถือแตะ minimap เพื่อเปิดแผนที่ (ปุ่มแถบเมนูเลื่อนไปทางซ้ายของ minimap)
- **แผนที่ของที่ที่อยู่:** ภาพเต็มของเมืองหรือทุ่ง ชื่อย่าน (`labels` ของแต่ละแผนที่) ร้าน นักบวช ทางวาร์ปว่าไปไหน ประตูที่ปิดเป็นกากบาท
  ชี้ที่จุดเพื่อดูชื่อคนหรือคำอธิบายข้างล่าง
- **คลิกเพื่อเดินไป:** คลิก (หรือแตะ) ตรงไหนบนแผนที่ ตัวละครเดินไปเองตามเส้นทางที่อ้อมบ้านและกำแพง (`findPath` ของ `src/world.ts`)
  คลิกชาวเมืองก็เดินไปคุย (ร้านเปิดร้าน นักบวชรักษา) คลิกวงวาร์ปก็เดินเข้าวาร์ป บนแผนที่โลกคลิกที่ที่ติดกับแผนที่นี้เพื่อเดินไปวาร์ปทางนั้น
  ทางที่เหลือเป็นเส้นประสีทองพร้อมธงปลายทางบนแผนที่และ minimap และมีวงสีทองบนพื้นตรงจุดหมาย
  คลิกพื้นในฉากก็เดินแบบเดียวกัน (คอมพิวเตอร์) กดเดินเอง โจมตี หรือติดอยู่กับที่เกินวินาทีกว่า ๆ (เช่นโดนมอนสเตอร์ขวาง) คือเลิกเดิน ที่ที่ไปไม่ถึงเลย (กลางทะเล ในตึก) ขึ้นว่า "ไปที่นั่นไม่ได้"
  บนมือถือแตะแล้วแผนที่ปิดเองให้เห็นตัวละครเดิน
- **แผนที่โลก** วาดด้วยโค้ดทั้งหมดแบบแผนที่ RO: ทวีปรูปเกือกม้ารอบทะเลใน แดนเหนือหิมะกับเทือกเขา ทุ่งสเตปป์ ชายแดนตะวันออกกับดินแดนอสูร
  ทะเลทราย ป่าแดนใต้ แม่น้ำ ถนน และเส้นทางเรือ เมืองทั้ง 7 วางตามภูมิภาคของชุดของแต่ละเมือง ปราสาทหลวงเหนืออีเดน และฟิลด์ทั้ง 20 แห่งตามถนน
  ที่ที่ยังไม่มีแผนที่ในเกมขึ้นว่า "ยังไม่เปิด" วงสีทองกะพริบบอกว่าอยู่ที่ไหน ชี้หรือแตะเมืองเพื่ออ่านเรื่องของเมืองนั้น

## เมืองและฟิลด์

เมือง 7 แห่ง (`src/world3d/town_<id>.ts`) และฟิลด์ 20 แห่ง (`src/world3d/field_<id>.ts`) โหลดครั้งแรกที่เข้า ผู้นำทางในทุกเมืองพาไปเมืองอื่นได้ทันที เสียค่าเดินทาง 1,000 ทองขึ้นไป ไกลยิ่งแพง (`travelFee` ใน `src/mapui.ts`; ชี้ที่เมืองเพื่อดูราคา) เรือโดยสารยังไม่เสียเงิน
ผู้นำทางมี 2 เมนูในหน้าต่างคุย: "เซฟจุดเกิด" (ล้มเมื่อไรฟื้นที่เมืองนั้น ยังไม่เซฟจะฟื้นที่อีเดน) และ "วาร์ป" (เปิดแผนที่โลกให้เลือกเมือง)
ประตูเมืองที่มีฟิลด์อยู่ข้างนอกเปิดหมดแล้ว เหลือปิดสองประตู (ตะวันตกของคราเดีย ประตูป่าของโยเดีย)

| สาย | ฟิลด์ (เลเวลมอนสเตอร์) |
| --- | --- |
| ตะวันตกของอีเดน | ทุ่งหญ้าตะวันตก (1–8) → ป่าใหญ่ตะวันตก (8–15) |
| เหนือ: อีเดน → ไอซ์เบิร์ก | ถนนหลวง (10–18, ปลายทางคือประตูปราสาทหลวงที่ยังปิด) → เชิงเขาหิมะ (35–45) → ช่องเขาน้ำแข็ง (45–55) → ไอซ์เบิร์ก → ทุ่งน้ำแข็งเหนือ (55–70) |
| ตะวันออกเฉียงเหนือ | ถนนหลวง → ป่าสนริมแม่น้ำ (20–30) → สเตปป์ตะวันตก (30–40) → ทรุนราดา → ทุ่งเลี้ยงม้า (40–50) / ที่ราบหินโบราณ (50–60) → คราเดีย |
| ชายแดนตะวันออก | คราเดีย → ป่าชายแดน (60–70) / แนวป้องกันชายแดน (70–85) → ดินแดนอสูร (85–100) |
| ใต้ | อีเดน → ทุ่งสะวันนาใต้ (12–20) → ขอบทะเลทราย (20–30) → บาฮามัส → ทะเลทรายใหญ่ (30–45) / ป่าดิบแดนใต้ (25–35) → โยเดีย → ชายฝั่งป่าชายเลน (35–45) |
| เกาะโอซากิ | โอซากิ → เนินซากุระและป่าไผ่ (45–60) → ยอดภูเขาไฟ (60–75) |

- **พื้นต่างระดับ** (`src/world3d/terrain.ts`): เนิน แอ่ง ที่ราบสูงมีหน้าผาหินล้อมรอบ (เดินขึ้นลงหน้าผาไม่ได้) และทางลาดขึ้นแต่ละชั้น
  ความสูงของพื้นใต้แต่ละจุดเข้าไปใน `mapY` ของ `src/projection.ts` ตัวละคร มอนสเตอร์ เอฟเฟกต์ วงเป้าหมาย และวาร์ปจึงยืนบนพื้นจริง
  คลิกพื้นหาจุดที่สายตาชนพื้นก่อน (`groundAt`) หน้าผาที่บังอยู่จึงรับคลิกแทนพื้นข้างหลัง ของทุกชิ้นที่วางในเมืองและฟิลด์ตั้งบนพื้นเอง
- **ฟิลด์** (`src/world3d/field.ts`): สร้างแบบเดียวกับเมือง มีทางดิน แม่น้ำ สะพาน จุดวาร์ป และจุดเกิดมอนสเตอร์ ขอบรอบนอกเป็นป่าทึบ หน้าผา หรือทะเล ไม่เห็นขอบโลก
  ของประกอบฉากแต่ละภูมิประเทศอยู่ในชุด `plains` `snowland` `steppe` `frontier` `desert` `jungle` `volcanic` (ดูได้ที่ `/kits.html`)
- **มอนสเตอร์ในฟิลด์:** ยังเป็นสไลม์ 4 สี แต่โตตามเลเวลของฟิลด์ (HP พลังโจมตี ป้องกัน และ EXP ตามสูตร `atLevel` ใน `src/monsters.ts`) สีอ่อนอยู่ปลายล่างของช่วงเลเวล สีม่วงอยู่ปลายบน

## คุยกับชาวเมือง และเควส

คุยกับใครก็ได้ (คลิกหรือ <kbd>F</kbd>) ขึ้นหน้าต่างคุย (`TalkDialog` ใน `src/questui.ts`): สิ่งที่เขาพูด (เปลี่ยนไปทุกครั้งที่คุย) แล้วเป็นเมนู
- **เมนูหน้าที่** (▸): ร้านค้า "ซื้อของ" / "ขายของ" (เปิดหน้าต่างร้านที่แท็บนั้น) · นักบวช "รักษา" (HP และ MP เต็ม ตอบในหน้าต่าง) ·
  ผู้นำทาง "เซฟจุดเกิด" / "วาร์ป" · กัปตันเรือ "ขึ้นเรือ"
- **เควสของเขา:** ป้าย "ส่งเควส" (ทำครบแล้ว) · "เควส" (รับได้) · "กำลังทำ" เลือกแล้วอ่านเรื่องกับรางวัล แล้วกด "รับเควส" หรือ "ส่งเควส"
  ไม่บอกล่วงหน้าว่าเควสมีกี่ขั้น หรือขั้นต่อไปคืออะไร เห็นแค่ขั้นที่ทำอยู่ (ผู้เล่นลุ้นเอง)

ไม่มีเครื่องหมายบนหัวชาวเมือง เควสที่รับได้ทั้งหมดดูได้ในสมุดเควส แท็บ "รับได้" (บอกว่าใครให้ อยู่เมืองไหน)
เดินออกห่างหรือกด <kbd>Esc</kbd> แล้วหน้าต่างปิดเอง
<kbd>J</kbd> หรือปุ่ม "เควส" เปิดสมุดเควส: กำลังทำ (สิ่งที่ต้องทำตอนนี้ ความคืบหน้า ส่งที่ใคร ยกเลิกได้) · รับได้ (และที่ยังรับไม่ได้เพราะอะไร) · สำเร็จแล้ว

**บอกสถานที่:** ทุกที่ที่เอ่ยชื่อคน (คนให้เควส คนที่ต้องไปคุย คนรับของ) บอกเมืองกับจุดที่ยืน เช่น "ท่านนาดีม (บาฮามัส · โอเอซิส)"
ขั้นล่ามอนบอกฟิลด์ที่มันอยู่ จุดที่ยืนคือป้ายชื่อบนแผนที่ที่ใกล้ที่สุด (`src/world_index.ts` สร้างด้วย `node tools/world_index.cjs`)

**นำทาง** (ปุ่มในตัวติดตามเควสใต้ HP/MP ในสมุดเควส และในหน้าต่างคุยตอนเควสยังไม่เสร็จ, `src/guide.ts`): เดินไปจุดหมายของขั้นที่ทำอยู่เอง
ข้ามแผนที่ทีละแผนที่ทางทางออกที่สั้นที่สุด ถึงแล้วเดินเข้าไปคุยกับคนนั้น หรือหยุดเมื่อถึงฟิลด์ของมอน ที่ไปได้แค่ทางเรือจะพาไปหากัปตันเรือ
กดเดินเองหรือคลิกที่อื่นคือเลิกนำทาง
เควสที่ทำอยู่ขึ้นที่แถบใต้ HP/MP ด้วย (คลิกเพื่อเปิดสมุด)

- **แบบ:** ทำครั้งเดียว หรือทำซ้ำได้ (รับใหม่ได้เมื่อครบเวลา 3–15 นาที) ขั้นเดียวจบ หรือต่อกันหลายขั้น แต่ละขั้นส่งให้คนที่กำหนดก่อนขึ้นขั้นต่อไป

## ร้านค้า ทอง และยา

- **ร้านเครื่องมือของลิเลีย** อยู่ลานน้ำพุในอีเดน และ **แม่ค้ามิร่า** ยืนข้างรถเข็นกลางลานในทุ่งหญ้า (`src/shop.ts`) หันหาผู้เล่นเมื่อเข้าใกล้ ใช้สไปรต์นักผจญภัยตัวแรกจาก Oriverse (ไม่ใช้เครดิตเพิ่ม) และมีกรอบชนของตัวเองใน `src/world.ts`
- **ซื้อ:** ขายแค่ของพื้นฐาน: ยาแดง/ยาแดงเข้มข้น (ฟื้น HP 150/500) ยาฟ้า/ยาฟ้าเข้มข้น (ฟื้น MP 60/200) อาวุธทุกชนิด ของมือรองทุกชิ้น และเสื้อผ้าบางสี ยากดจำนวนได้
  (ตำรา หมวก รองเท้า แหวน และเครื่องประดับไม่ขาย ต้องหาในเกม) ยาฟื้นเป็นหน่วยตายตัว ขวดแปรธาตุเพิ่มให้ 25%
- **ขาย:** ทุกอย่างในกระเป๋าที่ไม่ได้สวมใส่ ได้ 40% ของราคา วัตถุดิบมีราคารับซื้อของตัวเอง และมีปุ่มขายวัตถุดิบทั้งหมด
- **ดูรายละเอียด:** ชี้เมาส์ที่ไอเท็ม (ทั้งหน้าซื้อและหน้าขาย) เห็นรายละเอียดแบบเดียวกับในกระเป๋า (ชนิด ค่าสถานะ ดาเมจ/ระยะ และเหตุผลถ้ายังใส่ไม่ได้) แตะหรือคลิกที่ไอเท็มเพื่อเปิดรายละเอียดค้างไว้ใต้แถว (สำหรับจอสัมผัส) แตะอีกครั้งเพื่อปิด
- **ทอง:** สไลม์ทุกตัวให้ทองตามเลเวล (การเก็บเกี่ยวเพิ่มให้ด้วย)
- **ยา:** ดับเบิลคลิกเพื่อดื่ม (คูลดาวน์ 0.8 วิ) บอทดื่มเองเมื่อ HP/MP ต่ำกว่าที่ตั้งไว้ โดยเลือกขวดเล็กที่สุดที่พอ

## ระบบอื่น

**กระเป๋า** (`src/inventory.ts`, `src/ui.ts`): ตาราง 8×5 กับช่องสวมใส่ 10 ช่อง (มือหลัก มือรอง หมวก เสื้อ กางเกง/กระโปรง รองเท้า แหวน 2 ช่อง ประดับ 2 ช่อง) และทองที่มี
หมวก รองเท้า แหวน และเครื่องประดับเพิ่มค่าสเตตัส (ยังไม่วาดบนตัวละคร) ร้านค้าไม่ขาย มอนสเตอร์ในฟิลด์ดรอปทุกแบบ (ตัวธรรมดา 1.2% ตัวหายาก 25% บอส 60%)
**อุปกรณ์ตามเลเวล** (`GEAR_TIERS`: 30 60 90 120 150 180, id `t<เลเวล>_<ช่อง>`): ทุกเลเวลมีอาวุธครบ 10 ชนิด เสื้อเกราะ เกราะท่อนล่าง หมวก รองเท้า แหวน และจี้
ชื่อตามวัสดุ (เหล็ก เงินยวง ทองคำขาว มิธริล อดามันต์ ดารา) แรงกว่าของร้านนิดหน่อยและไม่มีความสามารถพิเศษ (`tierStats`) ใส่ได้เมื่อเลเวลถึง
อาวุธ: พลังโจมตี (ไม้เท้า: พลังเวท) 0.3 × เลเวลของอุปกรณ์ สองมือ ×1.5 (อาวุธมือรองให้ค่าสถานะครึ่งหนึ่ง) · เสื้อ: ป้องกันและต้านเวท · ท่อนล่าง: ป้องกันและ HP
· หมวก: ป้องกันและต้านเวท · รองเท้า: ป้องกัน หลบหลีก ความเร็วเดิน 4% · แหวน: พลังโจมตีและพลังเวท · จี้: HP และ MP
เสื้อและท่อนล่างตามเลเวลใส่ได้ทั้งชายและหญิง (`Item.male`: ตัวละครชายใช้ทรงนักรบสีเดียวกัน, `garmentLook`) เลเวลบอกในคำอธิบายไอเทม (ไอคอนไม่มีเลข)
หาได้จากมอนสเตอร์ (ดูตารางดรอป) หรือสร้างเท่านั้น ร้านค้าไม่ขาย
**ไอเทมตีบวกและไอเทมที่สร้าง**: id ของอุปกรณ์มีระดับตีบวกและชื่อผู้สร้างต่อท้ายได้ `<id>~<บวก>^<ผู้สร้าง>` เช่น `t60_sword_1h~3^มิร่า`
(`splitId`/`joinId`) `ITEMS` เป็น Proxy ที่สร้างไอเทมนั้นจากของตั้งต้นตอนถูกเรียกครั้งแรก: ชื่อ "+3 ดาบมือเดียวเงินยวง ของมิร่า" ค่าสถานะของตั้งต้นบวกค่าตีบวก (`refineStats`)
ตีบวกได้ถึง +10 (`REFINE_MAX`) ต่อ +1: อาวุธ พลังโจมตี/พลังเวท 2–6 (ตามเลเวลอุปกรณ์) · แหวน พลังโจมตีและพลังเวท 1–3 · จี้ HP 8–28 · โล่ ป้องกันและต้านเวท ·
สมุด/ขวด พลังเวท 2 · ที่เหลือ ป้องกัน 1–3 หินที่ใช้ (`stoneFor`): หินนภาสำหรับอาวุธและแหวน หินดาราสำหรับชุด หมวก รองเท้า จี้ และของมือรอง ไอคอนมี "+N" ที่มุมซ้ายบน
**วัตถุดิบ**: แร่เหล็ก หนังสัตว์ เศษอัญมณี แก่นอสูร (ใช้สร้างของ) หินนภา หินดารา (ใช้ตีบวก) ดรอปจากมอนสเตอร์ตามตารางดรอป

**สารบัญ** (<kbd>C</kbd> หรือปุ่ม "สารบัญ", `src/codex.ts`): ข้อมูลทั้งหมดของเกม อ่านจากตารางในโค้ดตรง ๆ จึงตรงกับเกมเสมอ
- มอนสเตอร์: เรียงตามฟิลด์และเลเวล ภาพจากสไปรต์ (ไม่มีภาพใช้สัญลักษณ์เผ่า) HP พลังโจมตี ป้องกัน ต้านเวท EXP ที่ปลายทั้งสองของช่วงเลเวล (`statsFor`)
  นิสัย (โจมตีก่อน ยิงไกล เรียกพวก…) ป้องกันธาตุ ที่อยู่ และของดรอปพร้อมโอกาส (`fieldDrops` อุปกรณ์ตามเลเวล ของร้านแบบสุ่ม ตำรา)
- ไอเทม: กรองตามชนิดและค้นหาชื่อ แต่ละชิ้นบอกรายละเอียดและที่มาทุกที่ (ร้านค้า มอนสเตอร์ที่ดรอป ช่วงเลเวลของอุปกรณ์ การสร้าง รางวัลเควส ของระหว่างเควส)
- เปลี่ยนอาชีพ: อาชีพแรกและตำรา อาชีพที่ 2 ทุกอาชีพ เจ้าอาชีพกับเมือง เงื่อนไข ขั้นตอนเควส และสายทั้งหมด
- ตำนาน: ยังว่างไว้ (เล่าทีหลัง) · ที่มาของเมือง: ประวัติทั้ง 7 เมือง (`TOWN_LORE`)

**โรงช่าง** (`src/workshop.ts`): เปิดได้สองทาง
1. คุยกับช่างตีเหล็ก (NPC `role: "smith"`: กุนเธอร์ที่อีเดน บียอร์นที่ไอซ์เบิร์ก ฮันส์ที่คราเดีย ซอลองโกที่ทรุนราดา) เลือก "ตีบวก" หรือ "สร้างไอเทม"
   ช่างทำให้ทุกคนแต่คิดค่าจ้างเป็นทอง เดินห่างจากช่างหน้าต่างจะปิด
2. สกิลของความเชี่ยวชาญการสร้าง (ลากใส่แถบสกิลแล้วกดใช้) เปิดหน้าต่างได้ทุกที่ ไม่เสียค่าจ้าง:
   ระดับ 1 สกิลสร้าง (เตาหลอมพกพา / โต๊ะช่างเกราะ / โต๊ะเจียระไน) ระดับ 3 สกิลตีบวก (ทั่งตีบวก / ตีบวกเกราะ / ตีบวกอัญมณี: เฉพาะของที่ความเชี่ยวชาญนั้นสร้าง)
   บอทไม่ใช้สกิลพวกนี้
- **ตีบวก**: ของที่สวมอยู่และในกระเป๋า ครั้งละหิน 1 ก้อน (`stoneFor`) ที่ช่างเสียค่าจ้างอีก 100 × (ระดับถัดไป) × (1 + เลเวลอุปกรณ์/60) ทอง
  โอกาสสำเร็จ (`REFINE_CHANCE`) ถึง +4: 100% · +5 85% · +6 70% · +7 55% · +8 40% · +9 30% · +10 20% คูณโชคดี (`luckFactor`)
  และบวก 0.5% ต่อระดับของความเชี่ยวชาญการสร้างที่ทำของชนิดนั้น (`CRAFT_REFINE`) ตีไม่ติดเสียหิน (และค่าจ้าง) ของยังเป็นระดับเดิม
- **สร้างไอเทม**: สูตร (`recipe`, k = เลเวลอุปกรณ์/30): อาวุธ แร่เหล็ก 3k+2 (สองมือ ×1.5) · ชุด หนังสัตว์ 3k+2 · หมวก/รองเท้า หนังสัตว์ 2k+1 · แหวน/จี้ เศษอัญมณี 2k+2 ทุกชิ้นใช้แก่นอสูร k ก้อน
  ที่ช่าง: สร้างได้ทุกชนิดถึงเลเวลของผู้เล่น จ่ายค่าจ้าง 250–300 × k ทอง ของไม่มีชื่อผู้สร้าง
  ด้วยสกิล: ต้องรู้ความเชี่ยวชาญการสร้าง (`weaponcraft` สร้างอาวุธ, `armorcraft` สร้างชุด หมวก รองเท้า, `jewelcraft` สร้างแหวนและจี้)
  ได้จากอาชีพนักประดิษฐ์หรือตำรา (`book_mastery_<id>` ดรอปแบบตำราทั่วไป) เป็นความเชี่ยวชาญสายชีวิต สูงสุด 30 ระดับ (`CRAFT_MAX`) ไม่เพิ่มค่าสถานะ
  ระดับ 1/5/10/15/20/25 สร้างได้ถึงของเลเวล 30/60/90/120/150/180 (`CRAFT_TIER_AT`) ไม่เสียค่าจ้าง ของมีชื่อผู้สร้าง (ชื่อตัวละคร)
  และทุกระดับเพิ่มโอกาสที่ของออกมาเป็น +1 อีก 1% (`CRAFT_BONUS`, คูณโชคดี)
ปุ่ม "เรียงของ" รวมกองที่ซ้อนได้แล้วเรียงตามชนิด ทรง และสี คลิกขวาที่ไอเท็มมีเมนูใช้/ใส่ ทิ้ง 1 ชิ้น ทิ้งทั้งหมด หรือลากไอเท็มออกนอกกระเป๋าไปวางในฉากเพื่อทิ้ง (ถามยืนยันก่อนเสมอ)
ลากไอเท็มเพื่อย้ายหรือสลับช่อง ไอเท็มชนิดเดียวกันซ้อนกันได้ ดับเบิลคลิกเพื่อใส่ ถอด หรืออ่านหนังสือ
ตำแหน่งล่าสุด (แผนที่และจุดที่ยืน) เซฟทุก 2 วินาทีและตอนปิดหน้าหรือกลับหน้าเลือกตัวละคร เข้าเกมครั้งต่อไปจึงอยู่ที่เดิม (ตัวใหม่เริ่มที่อีเดน ตายแล้วเซฟจุดสุดท้ายที่ยังมีชีวิต)
ของเซฟใน localStorage ตัวละครใหม่มีแค่ของที่ใส่อยู่ ยา และทอง (ดูหน้าเริ่มเกม) (เซฟเก่าที่มีไอเท็มชุดจะแยกเป็นเสื้อกับกางเกงให้เอง มีดคู่กลายเป็นมีดสั้นสองเล่ม
และเซฟจากก่อนมีมือรองได้โล่ไม้กลม สมุดเวท และมีดสั้นเพิ่มหนึ่งครั้ง)

**แต่งตัว** (`src/look.ts`): เพศกับสีตาเลือกตอนสร้างตัวละคร สีผมเปลี่ยนได้ทุกเมื่อในโปรไฟล์ ทรงผมตั้งต้นคือบ็อบธรรมดา
(ผมที่ตัวชุดสีน้ำตาลถูกสร้างมาด้วย ตัดออกเป็นชั้นผม `hair_bob`) ทรงอื่นได้จาก "ตำราทำผม" (อ่านแล้วเลือกทรงในโปรไฟล์) ซึ่งตอนนี้มอนสเตอร์ไม่ดรอปแล้ว คนที่มีอยู่ยังใช้ได้
เสื้อกับกางเกงเปลี่ยนจากกระเป๋า ไม่ใส่ก็เป็นชุดสีน้ำตาล
เสื้อกับกางเกง/กระโปรงเป็นไอเท็มแยกกัน แต่ละชิ้นมี **ทรง** (ครึ่งหนึ่งของสไปรต์ตัวละครจาก Oriverse: เสื้อคือหัวถึงเอวรวมแขน กางเกงคือเอวถึงเท้า) และ **สี**
ใส่เสื้อทรงไหนคู่กับกางเกงทรงไหนก็ได้ ทีละเฟรม เกมวาดท่อนล่าง แล้ววาดท่อนบนทับเป็นชั้น ๆ โดยเลื่อนให้สองชิ้นโยกตัวไปด้วยกัน (`waist` ใน `bodies.json`)
- **ชั้นของแต่ละชิ้น** (`piece` ใน `src/look.ts`): เสื้อเก็บทุกส่วนของตัวเองไว้แม้อยู่ใต้เอว ทั้งชายเสื้อคลุมที่ยาวลงไป (`tails`) มือ ขอบและเส้นขอบที่ติดกัน
  กางเกงลบส่วนที่เป็นของเสื้อทรงเดิมออก (ชายเสื้อ มือ) แล้วเติมขาที่ถูกบังด้วยสีจากขาข้างล่าง (`legs`) จึงไม่มีรอยตัดครึ่งตัว เสื้อคลุมยาวทับกระโปรงได้ และใต้เสื้อสั้นยังเห็นขาเต็ม
- **ส่วนสูงเท่ากันทุกชุด:** ตัวจาก Oriverse สูงไม่เท่ากัน (คอของชุดนักบวชและนักผจญภัยต่ำกว่าชุดจอมเวท) `stretch` ใน `bodies.json` ยืดแถวของชีตจากคอถึงเท้าให้หัว เอว และเท้าตรงกับตัวอื่น
  ตำแหน่งหัว มือ และเอวยืดตามไปด้วย ใส่ชุดไหนคู่กับชุดไหนตัวละครก็สูงเท่าเดิม

| ทรง | เสื้อ | กางเกง/กระโปรง | สีที่มี |
| --- | --- | --- | --- |
| จอมเวท (`mage`, ตัว `mageb`) | เสื้อคลุมยาวขลิบทอง แขนกว้าง เสื้อกั๊กคาดเข็มขัด | ชายเสื้อคลุม กางเกงรัดรูป บูท | เสื้อ: ขาว ฟ้า ชมพู มิ้นต์ ม่วง · กางเกง: ดำ กรมท่า แดงไวน์ เขียวเข้ม น้ำตาล |
| นักบวช (`priestess`) | เสื้อแขนยาว ปกสูง ผ้าคลุมไหล่ | กระโปรงยาว ผ้าคาดหน้าตราอาทิตย์ | กรมท่า แดงไวน์ เขียวเข้ม ดำ ขาว |
| นักผจญภัย (`adventurer`) | เสื้อกั๊กหนัง เกราะไหล่ สายสะพาย | กระโปรงจีบ เลกกิ้ง บูทสูง | เสื้อ: แดง กรมท่า เขียวหัวเป็ด ม่วงพลัม มัสตาร์ด · กระโปรง: เขียว ทราย น้ำตาล ดำ แดงไวน์ |
| นักรบ (`warrior`, ตัวละครชาย) | แจ็กเก็ตแขนพับ | กางเกงขายาว | แดง/กรมท่า/เขียวเข้ม · กรมท่า/น้ำตาล/ดำ |

- ช่องว่าง หรือชิ้นที่เป็นของอีกเพศ ใช้ทรงตั้งต้น (หญิง: จอมเวท, ชาย: นักรบ)
- ทรงที่ชีตยังไม่ครบ 5 ท่า (ยืน เดิน ฟัน แทง ยิง ตาม `clips` ใน `bodies.json`) ใช้ทรงตั้งต้นแทนจนกว่าจะเพิ่มชีตครบ หน้าต่างแต่งตัวบอกให้รู้
- ท่าร่ายเวทไม่บังคับ: เสื้อที่ไม่มีท่านี้ยกแขนด้วยท่าฟันแทน กางเกงที่ไม่มีก็ขยับขาตามท่าฟัน
- ชุดนักบวชยังไม่มีท่าฟัน (Oriverse สร้างไม่สำเร็จ) จึงใช้ท่าแทงแทนไปก่อน
- เสื้อนักบวชเป็นชุดคลุมยาวที่ต่อลงเป็นกระโปรง (`dress` ใน `bodies.json`) ใส่กับท่อนล่างชุดอื่นจึงได้ชุดคลุมทั้งตัว ตรงผ้าคาดหน้าเปิดให้เห็นท่อนล่าง แทนที่จะถูกตัดครึ่งที่เอว ส่วนขอบกระโปรงของเสื้อที่ยังเหลือตรงเอว (`hem` เช่นเสื้อกั๊กนักผจญภัย) กลายเป็นเข็มขัดหนัง
- ท่าที่ Oriverse วาดอาวุธมาให้ในภาพแล้ว (`builtin` ใน `bodies.json`) ใช้ตามภาพเฉพาะธนูในท่ายิง ส่วนดาบในท่าฟันลอยหลุดมือในบางทิศ เกมจึงวาดดาบเข้ามือเองในท่าแทงแทน ท่าที่มีอาวุธในภาพไม่ใช้กับอาวุธอื่น (สกิลท่าฟัน/ยิงตอนถือค้อน ร่ายเวทของชุดที่ไม่มีท่าร่าย) จะได้ไม่มีอาวุธชิ้นที่สามงอกออกมา
- ไอคอนของเสื้อและกางเกงเป็นภาพชิ้นผ้าแยกชิ้นแบบ RO (เสื้อคลุม กระโปรง กางเกง...) วาดเป็นพิกเซล 24×24 ต่อทรงใน `src/garments.ts` แล้วลงสีตามสีย้อมของไอเท็ม
- สีย้อมเปลี่ยนเฉพาะผ้าหลักของชิ้นนั้น (`cloth` ใน `bodies.json`) ชิ้นอื่นและผมไม่โดน
- เสื้อกับกางเกงทรงเดียวกันย้อมทั้งตัวตามชิ้นผ้า ไม่ตัดที่เอว (เสื้อคลุมจอมเวทยาวเลยเอวลงไป เสื้อกั๊กสีเดียวกับกางเกงอยู่เหนือเอว) ใส่ต่างทรงกันจึงย้อมแค่ชิ้นของตัวเอง

ทรงผมทำงานแบบหัวกับตัวแยกกัน (อย่าง Ragnarok Online):
- ตัวของชุดใหม่สร้างด้วยผมสั้น `tools/char_layers.py body` หาหัวในท่ายืนแล้วตามหัวไปทุกเฟรมของทุกท่า (template matching) เก็บตำแหน่งหัวแต่ละเฟรมลง `bodies.json` แล้วลบหัวออกจากชีต
- ทรงผมแต่ละทรงเป็นสไปรต์ Oriverse ท่ายืน 8 ทิศ ใส่ชุดแดงล้วนเพื่อให้แยกผมออกจากชุดด้วยสีได้ `tools/char_layers.py hair` ตัดหัวเหนือคอกับผมที่ต่อจากหัวลงมา เป็นชั้นหลัง (ผมยาวที่อยู่หลังตัว) กับชั้นหน้า
- ในเกม `Looks.attachHead` วาดชั้นหลัง ตัว ชั้นหน้า ทีละเฟรมตามตำแหน่งหัว หัวทุกสไปรต์ต่อกันได้ที่คอเพราะ Oriverse วางตัวละครทุกตัวกลางช่องเดียวกัน
- ชุดจอมเวทใช้ตัวผมสั้น `outfit_mage_boycut` ที่ตัดหัวแล้ว (`mageb`) ครบ 6 ท่า ผมทวินเทลจึงเป็นทรงผมหนึ่งในระบบทรงผมเหมือนทรงอื่น ตัวจอมเวทตัวเดิมที่มีทวินเทลติดตัว (`mage`) เก็บไว้เฉย ๆ ไม่ได้ใช้แล้ว

สีเปลี่ยนตามช่วงสีของแต่ละตัวใน `public/assets/chars/bodies.json` (ผมกับตาของชั้นหัวอยู่ใน `hair.json`) สีย้อมผมจึงไม่ไปโดนชุด
ตัวละครชาย (`warrior`) ผมกับเสื้อแจ็กเก็ตเป็นแดงชุดเดียวกัน จึงแบ่งด้วยแนวคอที่เลื่อนตามหัวทุกเฟรม

ใช้ทั้งในแท็บหน้าต่างสกิลและเป็นภาพของตำราแต่ละเล่มในกระเป๋าและร้านค้า

## ฉาก 3 มิติ

ชุดของสำหรับ 7 เมือง (อีเดน บาฮามัส โยเดีย คราเดีย ไอซ์เบิร์ก ทรุนราดา โอซากิ) และ 7 ภูมิประเทศของฟิลด์ (ทุ่งราบ เทือกเขาหิมะ สเตปป์ ชายแดน ทะเลทราย ป่าดิบ ภูเขาไฟ) อยู่ใน `src/world3d/kits/` ดูทุกชิ้นได้ที่ `/kits.html`

ลานหมู่บ้านเป็นฉาก 3 มิติจริง (three.js, WebGL: `src/world3d/`) ส่วนตัวละครยังเป็นสไปรต์ 2D แบบ Ragnarok
- **ของในฉากแปลงจาก Oriverse ทีละสูตร:** `courtyard.ts` คือ `#mesh` ทุกชิ้นของ `oriverse/frieren/courtyard.weave` (repo the-hero-fighter)
  เขียนด้วยฟังก์ชันชื่อเดียวกับ Weave ใน `geo.ts` (`box_at`, `beam_between`, `gable_roof`, `array`, `rotate_z` ...) ตัวเลขและตำแหน่งตรงตามไฟล์ Weave
  บ้าน ศาลาบ่อน้ำ รถเข็น ม้านั่ง ลัง รั้ว ป้าย หิน วางตาม `object` ของ world เดียวกัน (กรอบชนใน `src/world.ts` จึงตรงกับของ)
- **ต้นไม้และพุ่มไม้** (`trees.ts`) สร้างจากสูตร `#tree` เดิม: ลำต้นผ่าน trunk point กิ่งเข้าทรงพุ่มรี (`crown_ellipsoid`) และใบเป็นแผ่นลาย LeafClump ไหวตามลม
- **หินและไม้ตามธรรมชาติ** (`geo.ts` `rock`, `nature.ts`): หินทุกก้อนพองเป็นก้อนนุ่ม ๆ แล้วถูกระนาบแตกตัดเป็นหน้าเรียบใหญ่ ๆ
  แบบหินแตกจริง (ก้อนเกินเมตรมีหน้ามากขึ้น) `coverTop` ปูมอส หิมะ ทราย หรือเถ้าบนหน้าที่หงายขึ้น (ขอบหยัก แรเงานุ่ม `patches` ทำให้เป็นหย่อม)
  `fallenTrunk` ขอนไม้ล้ม (แผ่นรากถอนพร้อมดิน ปลายเลื่อยมีวงปี หรือปลายหักเป็นเสี้ยน กิ่งตอ มอสเป็นหย่อม เห็ดชั้น)
  `stumpOf` ตอไม้บนรากแผ่ (รอยเลื่อยเอียงมีวงปี หรือยอดหักเป็นเสี้ยน หิมะพอกบนหน้าตัด)
  `snag` ต้นไม้ไม่มีใบ (แตกกิ่ง 4 ชั้น รากเกาะดิน ตอกิ่งเลื่อย โพรง ยอดหัก) หน้าตัดไม้ใช้ลายวงปี (`endgrain` ใน `textures.ts`, `endGrain(สี)`)
- **พื้น** (`ground.ts`): ลายหญ้าผสมทางดินตามโพลิกอน `#terrain_paint` ของ Oriverse ใน shader (พื้นเรียบ ไม่มีกอหญ้า 3 มิติ) และดอกไม้ขาว/เหลืองตาม `#scatter`
- รอบลานมีป่า (ต้นไม้และพุ่มไม้) เพื่อไม่ให้เห็นขอบโลก
- **วัสดุ** (`textures.ts`): ลายไม้ หิน ปูน ผ้า โลหะ เปลือกไม้ กระเบื้องหลังคา วาดด้วยโค้ดตอนเริ่ม แล้วย้อมสีตามวัสดุของ Weave (ไม่มีไฟล์ภาพให้โหลด)
- **แสงเงา:** แสงท้องฟ้า + ดวงอาทิตย์ เงาจริง (shadow map คำนวณครั้งเดียวเพราะฉากไม่ขยับ) tone mapping แบบ ACES

กล้อง orthographic ก้ม 45° ตรงกับ `src/projection.ts` ทุกประการ (1 ซม. ต่อ 1 พิกเซลแผนที่) หมุนได้รอบตัวด้วยคลิกขวาลาก หรือปัดจอบนมือถือ
แคนวาส 2D เดิมจึงวาดเอฟเฟกต์เวท ลูกธนู และตัวเลขดาเมจทับฉากได้ตรงตำแหน่ง และการคลิกยังแปลงเป็นจุดบนพื้นด้วยสูตรเดิม
เอฟเฟกต์ที่ราบกับพื้น (วงเวท ดอกไม้ของทุ่งดอกไม้ แสงเรืองบนพื้น) วาดเป็นแผ่นสี่เหลี่ยมในฉาก 3 มิติแทน (`World3D.ground`, `groundSprites` ใน `src/particles.ts`)
ดอกไม้จึงอยู่ใต้เท้าตัวละครและสไลม์ และโดนม้านั่ง กระถาง หรือบ้านบังตามจริง ส่วนกลีบที่ลอยกับลำแสงยังวาดบนแคนวาส 2D

ตัวละคร (ผู้เล่น สไลม์ แม่ค้า) วาดด้วยโค้ดวาด 2D เดิมลงแคนวาสเล็กของแต่ละตัว แล้วตั้งเป็นป้ายหันหน้าเข้ากล้อง (billboard) ยืนที่เท้าในฉาก 3 มิติ
ต้นไม้หรือบ้านที่อยู่หน้าตัวละครจึงบังตามความลึกจริง และตัวผู้เล่นมีเงาจาง ๆ ซ้อนทับให้เห็นแม้เดินไปหลังบ้านหรือใต้ต้นไม้
ดอกไม้ไม่บังตัวละคร วงเป้าหมายใต้สไลม์และวงเขตล่าของบอทเป็นวงบนพื้นในฉาก ตัวละครเลือกแถวของชีตตามมุมกล้อง (8 ทิศ / สไลม์ 4 ทิศ) และ WASD เดินตามมุมกล้องเสมอ

บนมือถือดอกไม้ 60% และ shadow map 2048 (คอมพิวเตอร์ 4096)

## ตัวละครและมอนสเตอร์จาก Oriverse

- จอมเวท: `Ori.sprite.@taoisaman.mage_twintail` สร้างจากข้อความล้วน 8 ทิศ ช่อง 96 px
  ท่ายืน (Rest) เดิน (Walk) ฟัน (Swing) แทง (Thrust) ยิง (Shoot) ร่ายเวท (Cast)
- ชุดนักบวช `outfit_priestess` ชุดนักผจญภัย `outfit_adventurer_b` ตัวละครชาย `warrior_boy` และทรงผม `hair_*` สร้างแบบเดียวกัน
  ชุดใหม่ใช้ท่าตี 4 เฟรม (ประหยัดเครดิต) เดิน 8 เฟรม ทรงผมมีแค่ท่ายืน ตัวละครชายใช้ท่าตี 8 เฟรม
- ชุดจอมเวทผมสั้น `outfit_mage_boycut` (ตัดหัวเป็น `mageb`) ยืน เดิน 8 เฟรม ฟัน แทง ยิง 4 เฟรม ร่ายเวท 8 เฟรม ใช้แทนตัวจอมเวทที่มีทวินเทลติดตัว
- สไลม์: `Ori.sprite.@taoisaman.jelly_slime` 4 ทิศ ช่อง 64 px ยืน กระโดด (Hop) โดนตี (Hurt) ตาย (Die) สีอื่นได้จากการหมุน hue
- ตัวที่สร้างโดยแนบภาพอ้างอิงไปด้วยสร้างท่าทางไม่ได้ ("Animation first frame differs from its retained input") ต้องสร้างจากข้อความล้วน
- ดึงเฟรมจาก `preview_sprite` (`height_px` เท่ากับขนาดช่อง) ได้ 1 ภาพต่อท่าต่อทิศ แล้วต่อเป็นชีต:
  ```sh
  python3 tools/sprite_cells.py --size 96 --frames 8 public/assets/chars/mage_walk.png Walk_0.png … Walk_7.png
  python3 tools/char_layers.py body priestess RAW_DIR 39       # ตามหัว ลบหัว เขียน bodies.json
  python3 tools/char_layers.py hair bob Rest.png               # แยกชั้นผมหลัง/หน้า เขียน hair.json
  python3 tools/hand_anchors.py priestess public/assets/chars/priestess_thrust.png …
  python3 tools/hand_fists.py priestess                       # มือลงกำปั้น หามือรองใหม่
  ```
  ทุกชีตมี 1 แถวต่อทิศ (ลำดับของ Oriverse: หน้า แล้ววนตามเข็มนาฬิกามองจากด้านบน) และ 1 คอลัมน์ต่อเฟรม
