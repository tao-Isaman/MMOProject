# MMOProject: เมืองอีเดน + เวททุ่งดอกไม้

ต้นแบบเกม MMORPG บนเว็บ เริ่มที่เมืองอีเดน ออกประตูไปฟิลด์รอบเมือง แล้วเดินทางต่อไปอีก 6 เมืองและฟิลด์ 20 แห่งระหว่างทาง เลือกคลาสจอมเวท นักรบ นักธนู หรือนักบวช ตีสไลม์ เก็บเลเวล (สูงสุด 200) แจกแต้มสกิลลงตำราสกิล ความเชี่ยวชาญ และธาตุ เก็บของเข้ากระเป๋า และแต่งตัว
TypeScript (strict) + Canvas 2D, build ด้วย Vite

## เล่น

```sh
npm install
npm run dev        # เปิด http://localhost:5173
npm run build      # ตรวจ type (tsc --noEmit) แล้ว build ลง dist/
npm run typecheck  # ตรวจ type อย่างเดียว
```

Vercel build ด้วย `npm run build` แล้วเสิร์ฟ `dist/` (ดู `vercel.json`) ไฟล์ภาพและ JSON ทั้งหมดอยู่ใน `public/assets/` และเสิร์ฟที่ `assets/...`

### มือถือและแท็บเล็ต

เครื่องที่ใช้นิ้วเป็นหลัก (หรือเมื่อแตะจอครั้งแรก) เข้าโหมดสัมผัส (`src/touch.ts`, `body.touch` ใน `style.css`) เล่นได้เฉพาะแนวนอน
ถือแนวตั้งจะขึ้นหน้าบอกให้หมุนโทรศัพท์ กดเริ่มเกมแล้วเกมขอเต็มจอและล็อกแนวนอน (Android; iOS ไม่อนุญาตทั้งสองอย่าง ใช้หน้าบอกให้หมุนแทน)
และมี `manifest.webmanifest` (เต็มจอ แนวนอน) สำหรับเพิ่มลงหน้าจอโฮม

## หน้าเริ่มเกมและตัวละคร

เปิดเกมแล้วเจอหน้าเลือกตัวละคร (`src/title.ts`) มีได้ 6 ตัวต่อเบราว์เซอร์ เลือกแล้วกดเริ่มเกม (หรือดับเบิลคลิก/แตะสองครั้ง) สร้างใหม่ หรือลบ
- **สร้างตัวละคร** (`src/title.ts`, `src/starter.ts`): ตั้งชื่อ เลือกเพศ สีผม สีตา แล้วเลือกอาชีพ (นักเวท/นักรบ/นักธนู/นักบวช)
  ตำราสกิลเริ่มต้น 1 จาก 3 เล่มของอาชีพ และธาตุเริ่มต้น 1 จาก 4 (ดิน น้ำ ลม ไฟ) ทั้งสามแถวเลือกจากไอคอน
  (อาชีพใช้ไอคอนความเชี่ยวชาญของอาวุธประจำอาชีพ) ชื่อและคำอธิบายของอันที่เลือกขึ้นใต้แถว มีภาพตัวละครหมุนดูได้
  ความเชี่ยวชาญเริ่มต้นไม่ต้องเลือก ได้ของอาวุธประจำอาชีพเสมอ (นักเวท ไม้เท้า · นักรบ ดาบ · นักธนู ธนู · นักบวช ค้อน)
- ทุกคนเริ่มด้วยผมบ็อบธรรมดาในชุดของคลาส (ยังไม่มีคลาสใส่ชุดสีน้ำตาล) ชุดที่เห็นเปลี่ยนตามอาชีพ ทรงผมอื่นหาได้ในเกม ตัวละครใหม่ถืออาวุธประจำอาชีพ
  และของมือรองตามอาชีพถ้าอาวุธเป็นแบบมือเดียว (นักเวทและนักบวชได้สมุดเวท นักรบได้โล่ไม้กลม)
  ในกระเป๋ามีแค่ยาแดงกับยาฟ้าอย่างละ 5 และ 200 ทอง
- ทุกตัวละครเซฟแยกกันใน localStorage (`src/save.ts`: `mmoproject.c<id>.*` และรายชื่อใน `mmoproject.roster.v1`) เซฟจากก่อนมีระบบนี้กลายเป็นตัวละคร 1
- ในเกมกลับไปหน้าเลือกตัวละคร หรือออกจากเกม ได้จากเมนูตั้งค่า (<kbd>O</kbd>)

## คลาส เลเวล และค่าสถานะ

อาชีพเลือกตอนสร้างตัวละครและเปลี่ยนไม่ได้ ตัวละครรู้แค่ตำราสกิลกับธาตุที่เลือกตอนสร้าง และความเชี่ยวชาญอาวุธประจำอาชีพ
ที่เหลือต้องหาตำรามาอ่านในเกม (หน้าต่างสกิลกับโปรไฟล์แสดงเฉพาะที่เรียนแล้ว) ตัวละครจากก่อนมีระบบนี้ได้ทุกอย่างที่เคยใช้ได้

| คลาส | จุดเด่น | ตำราสกิลของอาชีพ |
| --- | --- | --- |
| นักเวท | MP และพลังเวทสูง HP ต่ำ | เวทโจมตี, เวทพฤกษา, เวทผนึก |
| นักรบ | HP พลังโจมตี และพลังป้องกันสูง | ผู้ทำลาย, ผู้พิทักษ์, นักดาบพริ้ว |
| นักธนู | ยิงไกล คริติคอลสูง ตีเร็ว (เริ่มด้วยธนู) | ธนูทำลาย, ธนูพายุ, ธนูพราน |
| นักบวช | ฮีลและบัฟตัวเอง ต้านเวทสูง (เริ่มด้วยค้อนกับสมุดเวท) | เวทฟื้นฟู, เวทสนับสนุน, นักบวชนักรบ |

- เลเวลสูงสุด 200 ค่าประสบการณ์ต่อเลเวลคือ `round(25·L^1.55 + 15)` (`src/progression.ts`)
- ทุกเลเวลได้ 1 skill point (เลเวล 1 มี 1 แต้ม) แจกได้สามทาง: ตำราสกิล ความเชี่ยวชาญ ธาตุ
  ลงแต้มต้องยืนยันก่อนทุกครั้ง และคืนแต้มไม่ได้
- ค่าสถานะ (`src/stats.ts`): HP, MP, พลังโจมตี, พลังเวท, ป้องกัน, ป้องกันเวท, คริติคอล, แรงคริติคอล, ความเร็วโจมตี, ความเร็วเดิน, ลดคูลดาวน์, ลดเวลาร่าย, ฟื้น HP/MP, โชคดี, หลบเวท
  โอกาสคริติคอลตันที่ 95% (`CRIT_CAP`) ทั้งค่าสถานะและโอกาสจริงหลังคูณโชค แหล่งคริติคอลทุกแหล่ง (ความเชี่ยวชาญ ธาตุ ต้นสกิล อาวุธ อาชีพ) ลดลงราวครึ่งหนึ่งใน v0.2
  **โชคดี** (`luck`): ทุกอย่างที่สุ่มของตัวละครผ่าน `lucky(chance, stats)` ซึ่งคูณโอกาสด้วย `luckFactor` = 1 + โชค/100 (โชค 20 → โอกาส ×1.2)
  ได้แก่ คริติคอล ยิงซ้อน ตีให้มึน ตีติดพิษ เหยี่ยว คูลดาวน์หายของลม แช่แข็ง สถานะของความมืด สาปหิน และโอกาสตาบอดตอนโดนกัดก็ลดลง
  มอนสเตอร์คริติคอลใส่เราน้อยลง (หารด้วย `luckFactor`) ของดรอปและทอง ×(1 + โชค/200) และลูกเต๋า (`rollDie`) มีโอกาส โชค% (สูงสุด 80%) ทอยสองครั้งเอาค่าดีกว่า
  **หลบเวท** (`magicDodge`, สูงสุด 60%): โอกาสที่การโจมตีเวทของมอนสเตอร์ (ตัวร่ายเวท และกระสุนที่ไม่ใช่ลูกศร ปืน หิน ฯลฯ, `Monster.magical`) ไม่โดนเลย มาจากธาตุควัน
  **ต้านสถานะ** (`statusRes`, สูงสุด 75%, v0.3): โอกาสไม่ติดสถานะผิดปกติที่มอนสเตอร์ทิ้งไว้ ทั้งจากการกัด กระสุน ทุบพื้น และระเบิด (ทุกอย่างผ่าน `bite` ใน `src/main.ts`):
  หนาวสั่น โคลนติดเท้า ตาพร่า (กัดธาตุน้ำแข็ง โคลน ความมืด) เชื่องช้า ตัวแข็งเป็นหิน และไฟลวก ต้านได้ขึ้นคำว่า "ต้านทาน" โชคดีช่วยเหมือนโอกาสอื่น (`resists` ใน `src/stats.ts`)
  มาจากธาตุทอง (ธาตุพืชระดับ 50 ยังไม่ติดสถานะเลย) ยังไม่มีมอนสเตอร์วางกับดักใส่ผู้เล่น
  ฟื้น HP/MP มาเป็นก้อนทุก 5 วิ (`REGEN_TICK` ใน `src/hero.ts`) เท่ากับอัตราต่อวินาที × 5 เช่น ฟื้น 4/วิ ได้ 20 ทุก 5 วิ หน้าโปรไฟล์แสดงเป็น "20 / 5 วิ" ยาจึงเป็นทางฟื้นทันที
- MP ของสกิลขึ้นตามระดับ (`mpCost`): ค่าที่เขียนไว้คือระดับ 1 ระดับสูงสุดใช้มากขึ้น 80% (สกิลระดับเดียวไม่เปลี่ยน) หน้าต่างสกิลบอก MP ระดับนี้และระดับถัดไป ตารางระดับมี MP ทุกระดับ
  ลดเวลาร่าย (`castRed`, สูงสุด 60%) ย่อเวลาร่ายของสกิลที่ต้องร่าย แยกจากลดคูลดาวน์ (สูงสุด 50%) มาจากติดตัวของต้นสกิล (ร่ายคล่องของเวทโจมตี
  และร่ายไวของสายเวทมนตร์ 0.75%/ระดับ ฯลฯ) ความเชี่ยวชาญไม้เท้าระดับ 20 (12%) 50 (10%) 60 (5%) สมุดเวท (5%) คัมภีร์โบราณ (10%) หมวกพ่อมด (5%) และแหวนบทร่าย (8%, ร้านค้า 950)
  มาจากค่าตั้งต้นของคลาส + การเติบโตต่อเลเวล + ธาตุ + passive + บัฟ
- สูตรดาเมจ: ตีปกติ = (ดาเมจสุ่มของอาวุธ + พลังโจมตี) × (1 + โบนัสดาเมจ) ไม้เท้าใช้พลังเวทแทน
  สกิล = (พลังโจมตีหรือพลังเวท + พลังอาวุธ) × ตัวคูณของสกิล
  คริติคอลคูณ (1 + แรงคริติคอล) แล้วลดตามป้องกัน `× 100 / (100 + def)` (ป้องกัน 100 รับดาเมจครึ่งเดียว)
- **ธาตุแฝงในทุกการโจมตี** (`elementBonus` ใน `src/stats.ts`): หลังได้ดาเมจแล้ว ทุกธาตุเอา พลังโจมตีธาตุของผู้ตี − ป้องกันธาตุนั้นของเป้า
  (ติดลบนับเป็น 0) มาบวกเข้าดาเมจตรง ๆ ทั้งตีปกติและสกิล เช่น ดาเมจ 100 ไฟ 60 ดิน 30 ใส่เป้าที่ป้องกันไฟ 20 ดิน 50 → 100 + 40 = 140
  การโจมตีที่มีธาตุ (สกิลธาตุ หรืออาวุธที่เคลือบธาตุ) ยังบวก พลังโจมตีธาตุนั้น × 1.5 (`ELEMENT_SWING`) เข้าไปในพลังโจมตี/พลังเวทก่อนคำนวณด้วย
  ส่วนบวกจากธาตุไม่คูณคริติคอล มอนสเตอร์ที่กัดเป็นธาตุก็คิดแบบเดียวกันกับป้องกันธาตุของผู้เล่น
  ตัวเลขดาเมจคริติคอลเป็นสีเหลืองบนรูประเบิดสีแดง (หนามและเอียงสุ่มต่อครั้ง) ดาเมจปกติสีครีม เวทสีฟ้า
- สไลม์มีเลเวล (1, 3, 5, 9) และสวนกลับ สไลม์ม่วงโจมตีก่อนเมื่อเข้าใกล้ สไลม์ตายแล้วเกิดใหม่หลัง 9 วินาที
- ผู้เล่น HP หมดแล้วเกิดใหม่ที่จุดเริ่มหลัง 4 วินาที

**กลไกใหม่**
- สกิลตามอาวุธ (`need`): บางสกิลใช้ได้เฉพาะอาวุธที่ถือ (`{ weapons }` มือหลัก หรือ `{ dual }` อาวุธมือเดียวทั้งสองมือ)
  ใช้ไม่ได้ช่องในแถบสกิลจะมืดและบอกเหตุผล (เช่น "ต้องถือดาบมือเดียว ทั้งสองมือ") passive ที่มี `need` นับเฉพาะตอนถือครบ
  สกิลจากความเชี่ยวชาญก็ต้องถืออาวุธชนิดนั้น
- เผ่าของมอนสเตอร์ (`RACE_OF` ใน `src/bestiary.ts`): ไร้รูปร่าง อันเดด สัตว์ป่า พืช แมลง ปลา ปีศาจ มนุษย์ เทวดา มังกร
  ป้ายชื่อมอนแสดงเป็นสัญลักษณ์หน้าชื่อ (`RACE_ICONS`): หยดน้ำ หัวกะโหลก รอยเท้าสัตว์ ใบไม้ แมลง ปลา หัวมีเขา คน ปีก หัวมังกร
  ขึ้นท้ายชื่อบนป้าย ค่า `undeadDmg`, `demonDmg`… เพิ่มดาเมจใส่เผ่านั้น และสกิลมี `vs` (เช่นเวทแสงแรงใส่อันเดด)
- ธาตุพิษ (`poison`, ตำราธาตุพิษ): พิษแรงขึ้น (`poisonPct`) สกิลของสายวางยาพิษ (เขี้ยวพิษ ลูกดอกพิษ ขวดหมอกพิษ พิษปะทุ) เป็นธาตุพิษ อันเดดต้านพิษ 40% ไร้รูปร่าง 25%
  สกิล `detonate` จุดพิษที่ค้างในตัวมอนให้ระเบิดทีเดียวแล้วล้างพิษออก
- กับดัก (`trap`): วางตรงจุดที่เล็ง ตั้งพร้อมใน 0.5 วิ มอนตัวแรกที่เดินเข้ามาทำให้ระเบิดใส่ทุกตัวในวง วางได้ 3 อันพร้อมกัน อยู่ 20 วิ
- เหยี่ยว (`falcon`): สกิลสั่งเหยี่ยวโฉบใส่เป้าที่ล็อก และ `falconChance` (เหยี่ยวคู่ใจ) ให้เหยี่ยวโฉบตามเองตอนตีปกติ
  เป็นแนวตรงจากตัวเราถึงเป้า จิก 5 ครั้งติดกัน (`FALCON_HITS` ใน `src/skills.ts`) แต่ละครั้งโดนทุกตัวในแนวกว้าง 90 ซม. (`FALCON_WIDTH`)
  ครั้งละ `falconPower` × พลังโจมตี ลดตามป้องกันแบบการตีกายภาพ ไม่พลาด
- เคลือบธาตุ (`enchant` ของบัฟ): อาวุธตีเป็นธาตุนั้นตลอดเวลาบัฟ (ตีปกติและสกิลกายภาพที่ไม่มีธาตุของตัวเอง) ทีละธาตุ
- ดูดเลือด (`lifesteal` และ `drain` ของสกิล) ยิ่งเลือดน้อยยิ่งแรง (`lowHpDmg`) สกิลแรงตามระดับความเชี่ยวชาญอาวุธที่ถือ (`masteryScale`)
  และสกิลที่ใช้ทั้งพลังโจมตีและพลังเวท (`stat: "both"` อย่างละ 0.6 โดนแน่นอนแบบเวท)

**กลไกของอาชีพ v0.2** (`src/trees/v02jobs.ts`)
- ตีซ้ำ (`doubleHit`, หัวขโมยถือมีดสั้น): ตีปกติมีโอกาสโดนอีกครั้งทันที (โชคดีช่วย สูงสุด 60%)
- ขโมย (`steal` + `stealChance` ของสกิล): ทอง (เลเวลมอน × 4–8) หรือของดรอปชิ้นหนึ่งของมันตามโอกาสดรอป มอนแต่ละตัวโดนขโมยได้ครั้งเดียว (`Monster.stolen`)
- ซ่อนตัว (บัฟที่มี `stealth`): มอนสเตอร์มองไม่เห็นและเลิกไล่ (`MonsterCtx.unseen`) การโจมตีครั้งแรกขณะซ่อนแรงขึ้นตาม `ambush` แล้วหายจากการซ่อน (`Hero.reveal`)
- ร่างแยก (สกิล `decoy`): ร่างของผู้เล่นสีจางยืนข้างหน้า มอนทุกตัวหันไปไล่และกัดร่างแยกแทน (HP ตามสัดส่วน HP สูงสุด) จนหมดเวลาหรือ HP หมด
- ลูกเต๋า (`dice`): สกิลโจมตีทอยเต๋าทุกครั้งที่โดน ดาเมจ × แต้ม/3.5 บัฟเสี่ยงดวงบวก `roll` × (แต้ม − 3)/3 (แต้ม 1 ลดลง แต้ม 6 ได้เต็ม) โชคดีช่วยให้ทอยสองครั้งเอาค่าดีกว่า (`rollDie`)
- โล่ในมือรอง (`need.shield`, `offhandKind`): สกิลหอกกับโล่ต้องถือหอกมือเดียวและโล่ไม้กลม/โล่อัศวิน
- ตัวตลกได้ค่าโชคดี 10 และ +0.3 ต่อเลเวลหลังเปลี่ยนอาชีพ

**ตำราใหม่ 10 เล่ม** อ่านได้ทุกอาชีพ ดรอปจากมอนสเตอร์ในฟิลด์เหมือนตำราอื่น: ตำราจอมเวทน้ำแข็ง ตำราจอมเวทสายฟ้า ตำรานักดาบพายุคลั่ง
ตำราพื้นฐานพลังเวท ตำราพื้นฐานร่างกาย ตำราพื้นฐานการต่อสู้ ตำราตาเหยี่ยว ตำราบทสวด ตำรานักดาบศักดิ์สิทธิ์ ตำราพ่อค้าพเนจร
(ตำราพื้นฐานทั้งสามเล่มดรอปจากมอนสเตอร์ในฟิลด์)

**ตำราพ่อค้าพเนจร** (`merchant`, ดรอปจากมอนสเตอร์): ต่อรองราคา (ซื้อของจากร้าน NPC ถูกลง 2%/ระดับ)
ปากหวาน (ขายของให้ร้านได้ราคาเพิ่ม 3%/ระดับ) กระเป๋าใบใหญ่ (+4 ช่อง/ระดับ) เท้าพเนจร (เดินเร็วขึ้น) ตาพ่อค้า (ทองจากมอน +6%/ระดับ)
ตาถึงของดี (โอกาสได้ของ) เส้นสายนักเดินทาง (ค่าเดินทางกับผู้นำทางถูกลง 5%/ระดับ) ราชาพ่อค้า และกองคาราวาน (+8 ช่องต่ออัน)
เต็มที่แล้วซื้อถูกลง 25% ขายได้เพิ่ม 40% กระเป๋าจาก 40 เป็น 76 ช่อง (`bagSlots`, `Inventory.resize`) ร้านไม่รับซื้อของที่ตัวเองขาย
แพงกว่าราคาที่ขายให้ (ซื้อมาขายคืนไม่มีกำไร) ส่วนลดสูงสุด 50% กระเป๋าใหญ่เกิน 7 แถวจะเลื่อนดูได้

**กลไกของอาชีพที่ 3** (ส่วนกลาง ใช้ได้ทุกต้นด้วยข้อมูลอย่างเดียว คำอธิบายฟิลด์อยู่ที่ `SkillDef` ใน `src/progression.ts`)
- **ผู้ช่วย** (สกิล `summon`, `src/allies.ts`): เรียก `ally` อยู่ `duration` วิ มีได้ชนิดละ `count` ตัว (เรียกเกินตัวเก่าสุดหายไป)
  HP เป็นสัดส่วน `base` ของ HP สูงสุด ตีด้วย `mult` ของพลังโจมตี/พลังเวทของผู้เล่น ทุก `every` วิ มี `range` คือวางตรงจุดที่เล็ง
  - หมาป่า (`wolf`): เดินตาม กัดตัวที่ผู้เล่นตี ตัวที่ไล่ผู้เล่น หรือตัวที่ไล่มัน (วาดด้วยหมาป่าสนสีอุ่น)
  - ร่างแยก (`clone`): หน้าตาผู้เล่นสีฟ้าจาง ตีตัวที่ผู้เล่นตีด้วยอาวุธของผู้เล่น (`mult` ของการตีปกติ)
  - รูปปั้น (`statue`): ยืนนิ่ง ใครยืนในวง `radius` ได้บัฟ `buff` (วงเรืองบนพื้นเป็นระยะ)
  - กำแพง (`wall`): ก้อนหินขวางทาง มอนสเตอร์เดินผ่านไม่ได้ ถ้ากำแพงขวางทางที่มันจะไป มันตีกำแพงก่อน
  - หุ่นปูน (`golem`): เดินช้าไปหามอนตัวที่ใกล้ที่สุด ตี และดึงความสนใจมอนสเตอร์มาที่ตัวเอง
  ผู้ช่วยมีวงสีเขียวใต้เท้าและหลอด HP สีเขียว โดนตีตามป้องกันและหลบหลีกของมันเอง HP หมดก็ล้ม มอนสเตอร์เลือกเป้าเอง:
  ร่างแยกของตัวตลกก่อน ไม่งั้นตัวที่ใกล้ที่สุดระหว่างผู้เล่นกับผู้ช่วย (หุ่นปูนนับว่าใกล้กว่าจริง รูปปั้นนับว่าไกลกว่า ตัวที่เพิ่งตีมันนับว่าใกล้ขึ้น)
  แล้วถ้ามีกำแพงขวางอยู่ใกล้ ๆ ก็ตีกำแพง (`foeFor`) ผู้เล่นซ่อนตัวแล้วมอนยังเห็นผู้ช่วย ของที่ผู้ช่วยฆ่าได้ EXP และของเหมือนผู้เล่นฆ่าเอง
  ร่างแยกของตัวตลก (`decoy`) ย้ายมาอยู่ในระบบนี้ด้วย (ทุกตัวไปหามันก่อน)
- **ร่ายเองเมื่อโจมตี** (ค่าสถานะ `autocast_<id สกิล>` ในติดตัวหรือบัฟ): ตีปกติโดนแล้วมีโอกาสเท่าค่านั้นร่ายสกิลนั้นฟรีใส่ตัวที่ตี
  ที่ระดับสกิลที่เรียนไว้ ต้องถืออาวุธที่สกิลต้องการ ไม่เสีย MP ไม่ติดคูลดาวน์ เว้นระยะกัน 0.6 วิ (`autocast` ใน `src/skills.ts`)
- **ก๊อปปี้** (สกิล `mimic`): ก๊อปการโจมตีของมอนตัวที่ล็อก (ยิงอะไร ธาตุอะไร หรือกัด) ใช้ได้ `uses` ครั้งใน `duration` วิ
  ช่องเดิมกลายเป็นการโจมตีที่ก๊อปมา แรง `mult` ของพลังโจมตี (หรือพลังเวทถ้ามันยิงเวท) ไม่เสีย MP ห่างกัน `every` วิ หมดแล้วเริ่มคูลดาวน์
- **บัฟตามภูมิประเทศ** (`terrain` ของบัฟหรือติดตัว, `src/terrain.ts`): ทุกแผนที่มีชนิด (เมือง ทุ่งหญ้า ป่า หิมะ ทะเลทราย ป่าดิบ
  ชายฝั่ง ภูเขาไฟ ซากโบราณ ภูเขา) สกิลให้ค่าต่างกันตามชนิดที่ยืนอยู่ เปลี่ยนแผนที่แล้วค่าเปลี่ยนตาม
- **คอมโบ** (`combo: { after, within, more }`): ใช้ภายใน `within` วิ (ปกติ 3) หลังสกิลใน `after` แรงขึ้น `more` ขึ้นคำว่า "คอมโบ!"
  และ **หลายฮิต** (`hits`) ใช้ได้กับลูกเวท ฟันด้านหน้า ระเบิด ฟันรอบตัว ลำแสง และพุ่ง
- **เผามานา** (`manaBurn`, `silence`): แรงขึ้นใส่มอนที่ร่ายเวท (`Monster.magical`) และมอนที่ร่ายหรือยิงได้หยุดร่าย หยุดยิง
  หยุดฮีลตัวเองและเรียกพวก `silence` วิ (ตั้งต้น 4.5 ป้ายสถานะสีฟ้าเทา)
- **ควันซ่อนตัว** (สกิล `smoke`): กลุ่มควันรัศมี `radius` อยู่ `duration` วิ ผู้เล่นยืนในควันคือซ่อนตัว (พร้อม `buff`)
  ตีออกไปแล้วโผล่ให้เห็นครู่หนึ่ง (1.2 วิ) แล้วควันซ่อนให้อีก ออกจากควันก็เห็นตัว (เพื่อนในปาร์ตี้ภายหลัง)
- **สร้างยาพิษและเคลือบอาวุธ** (สกิล `make`, `src/poisons.ts`): เปลี่ยนวัตถุดิบในกระเป๋า (`make.from`) เป็นไอเทม เช่นขวดยาพิษ
  ขวดยาพิษ (60 วิ) และขวดยาพิษเข้มข้น (90 วิ) กดใช้จากกระเป๋าแล้วอาวุธเคลือบพิษ (บัฟเคลือบธาตุพิษ ตีปกติมีโอกาสติดพิษ)
  เคลือบใหม่หรือเคลือบธาตุอื่นแทนของเดิม
- **หัวก้อย** (`coin`): ทุกฮิตโยนเหรียญแบบเดียวกับที่ `dice` ทอยเต๋า ออกหัวแรงขึ้น `coin` ออกก้อยเบาลงเท่ากัน (ขึ้น "หัว!" / "ก้อย")
  โชคดีมีโอกาสโยนใหม่ตอนออกก้อย ออกหัวได้มากสุด 70% (`flipCoin` ใน `src/stats.ts`, นักมายากลสายนักเสี่ยงดวง)
- **ฝูงขย้ำ** (สกิล `falcon` ที่มี `ally: "wolf"`): หมาป่าทุกตัวที่เรียกไว้กระโจนไปรุมกัดเป้าแทนเหยี่ยว (`pounce` ใน `src/allies.ts`)
  ไม่มีหมาป่าอยู่ก็ใช้ไม่ได้และไม่ร่ายเองตอนตีปกติ (นักล่าสายสัตว์ล่าเหยื่อ)
- `statusRes` (ต้านสถานะ) เป็นค่าของธาตุทอง ต้นสกิลใช้ได้เหมือนค่าอื่น
- ขวดยาพิษทำจากหนังสัตว์ 2 ผืน ขวดยาพิษเข้มข้นทำจากขวดยาพิษ 2 ขวดกับเศษอัญมณี 1 ชิ้น (นักฆ่าสายนักวางยาพิษ)

ตรวจต้นสกิลทั้งหมดด้วย `node tools/tree_check.cjs` (ตำแหน่ง เงื่อนไข ค่าสถานะ ตัวเลขในคำอธิบาย จำนวนสกิลของแต่ละคลาส
ชนิดผู้ช่วย สกิลที่คอมโบหรือร่ายเองต้องมีอยู่จริง ชนิดภูมิประเทศ ไอเทมที่สร้าง) ไม่ใส่ชื่อต้นจะตรวจความเชี่ยวชาญ
(อาวุธทุกชนิดมีความเชี่ยวชาญและภาพในมือ) และธาตุ (ค่าสถานะ จุดบนเส้น และสมดุลของธาตุ ดูหัวข้อธาตุ) ด้วย

**การร่ายเวท** (`src/skills.ts`): สกิลโจมตีหลักของนักเวทต้องร่ายก่อน (`cast`: ลูกไฟระเบิด 1.6 วิ พายุอุกกาบาต 3 ทุ่งดอกไม้ 1.5 พายุกลีบดอก 1.5
สายอาชีพที่ 2 ขึ้นไปและตำราก็มีสกิลที่ต้องร่ายอีกหลายสกิล ดูเวลาร่ายในหน้าต่างสกิล)
แลกกับดาเมจแรงขึ้นราว 2–2.5 เท่า ระหว่างร่ายยืนนิ่งใต้แถบร่าย เวทออกเมื่อแถบเต็ม แล้วจึงเสีย MP และเริ่มคูลดาวน์
เดิน (ปุ่มหรือคลิกพื้น) ระหว่างร่ายคือยกเลิก ไม่เสียอะไร มอนที่ตกเป็นเป้า (ตัวที่ล็อก หรือตัวในวงที่เล็ง) รู้ตัวทันที มี "!" ขึ้นหัว
แล้วหันมาโจมตีพร้อมฝูง สกิลวางพื้นจะตามมอนตัวที่เล็งไว้ไปตกตรงที่มันอยู่ตอนแถบเต็ม สกิลเป้าเดียวที่เป้าตายก่อนจะไม่ออกและไม่เสีย MP
ลูกศรเวท เมล็ดพุ่ง และสกิลป้องกันตัว (โล่มานา ผนึกกาลเวลา เทเลพอร์ต) ยังใช้ได้ทันที

ระหว่างร่ายมีวงเวทใต้ตัวแบบทุ่งดอกไม้ (`src/circles.ts` วาดด้วยโค้ด, `src/castfx.ts` เอฟเฟกต์) แต่ละสกิลมีสี
รูปตรงกลาง และอักขระของตัวเอง อักขระแยกตามสำนัก: ไฟเป็นขีดแหลมมีเปลว น้ำแข็งเป็นเส้นตรงทำมุม 60° เวทลี้ลับเป็นวงกับจุด
พฤกษาเป็นเถาม้วนกับใบไม้ ความว่างเปล่าเป็นตะขอกับก้นหอย

| สกิล | รูปตรงกลาง | ละอองที่ลอยขึ้น |
| --- | --- | --- |
| ลูกไฟระเบิด / พายุอุกกาบาต | ดวงอาทิตย์เปลวไฟ / ดาวแปดแฉกมีดาวบริวาร | ถ่านไฟ |
| พายุกลีบดอก | ดอกกุหลาบ | กลีบดอก |
| สกิลร่ายอื่น ๆ (`lookFor`) | เลือกจากไอคอนของสกิล (สามเหลี่ยม ดาวห้าแฉก เกล็ดหิมะ ดาวหกแฉก ดวงตา วงหนาม เถาวัลย์ วงโคจร ก้นหอย ฯลฯ) | ตามธาตุหรือชื่อ: ถ่านไฟ เกล็ดน้ำแข็ง ใบไม้/กลีบดอก ดวงไฟ ละอองถูกดูด |

วงเปิดขึ้นแบบเด้งนิด ๆ ขอบหมุนทางหนึ่ง รูปตรงกลางหมุนสวน ยิ่งแถบร่ายเต็มยิ่งหมุนเร็วและสว่างขึ้น
ตราเล็กหมุนอยู่ใต้เป้า (ใต้มอนที่ล็อก หรือตรงจุดที่สกิลวางพื้นจะตก ตามมอนที่เล็งไว้) แถบเต็มแล้ววงแวบสว่าง มีวงแหวนวิ่งออกแล้วจางไป
ยกเลิกกลางคัน วงจะหรี่ กะพริบ แล้วแตกเป็นประกาย

**ตำราสกิล** (`TREES`, ในโค้ดเรียก tree): ต้นสกิลมีสกิลน้อย ตัวละครเก่งขึ้นจากความเชี่ยวชาญ ธาตุ และของสวมใส่เป็นหลัก (`TREE_SKILLS`: ต้นของคลาสแรก 5 สกิล สายอาชีพที่ 2 มี 6 อาชีพที่ 3 มี 7 อาชีพที่ 4 มี 8 อาชีพที่ 5 ในอนาคตจะมี 9) ทุกต้นมีสกิลติดตัว (passive) 2–4 สกิล (`TREE_PASSIVES`) ที่เหลือมีทั้งตีเป้าเดี่ยว ตีเป็นวง บัฟ และสกิลปิดท้าย แต่ละต้นยังเล่นต่างกัน
ในตารางต้นสกิลทั้งหมดของไฟล์นี้ "(ติดตัว)" คือ passive ส่วนที่ไม่มีวงเล็บคือสกิลกดใช้ ตารางสร้างจากโค้ด (`TREES`) ไม่ได้เขียนมือ
วางแบบหน้าต่างสกิลของ Ragnarok คือแต่ละต้นมีสกิลเริ่มต้นหลายตัวในแถวบน แต่ละตัวแตกเป็นสายของตัวเอง
บางช่องต้องมีแต้มในสายข้าง ๆ ด้วย (`req`: ช่องไหนถึงระดับเท่าไร) และระดับสูงสุดมี 1, 5 หรือ 10 ต้นไม่ได้มาบรรจบที่ช่องเดียว แต่ละต้นหน้าตาต่างกัน
ช่องวางเป็นตาราง 4 คอลัมน์ (`pos`) เส้นเชื่อมมีป้าย "Lv N" บอกระดับที่ต้องมี (ชี้ดูประโยคเต็ม)

ชนิดสกิลที่เพิ่มมา: ระเบิดตรงจุดที่เล็งได้หลายครั้ง (`hits` ของ `blast` เช่น พายุอุกกาบาต 3 ลูก) และพุ่งโดยไม่มีตัวคูณดาเมจคือเทเลพอร์ต (บอทไม่ใช้เป็นท่าโจมตี)
ยิงทีละหลายลูกต่อกันได้ด้วย `hits` กับ `every` ของ `bolt` (ยิงสองดอก ยิงรัว) และ `arrow` ทำให้เป็นลูกธนูจริง

**ชื่อและ HP ของมอนสเตอร์** ขึ้นใต้เท้าตัวที่ล็อกเป้าอยู่ (หรือที่บอทกำลังล่า) และตัวที่เราทำดาเมจใส่ภายใน 8 วินาที: เลเวล ชื่อ และหลอด HP พร้อมตัวเลข (ตัวหายากและบอสชื่อสีทอง)

**สถานะผิดปกติของมอนสเตอร์** ขึ้นเป็นไอคอนเล็กเหนือหัว:
- พิษ (`poison`) กัดเพิ่มตามสัดส่วนของดาเมจใน 4 วินาที (ตีปกติติดพิษได้จากโอกาสตีติดพิษ `poisonHit` และอาวุธที่เคลือบขวดยาพิษ)
- ช้า มึน แช่แข็ง แบบเดิม
- อ่อนแรง (`weaken`) กัดเบาลงตามเปอร์เซ็นต์
- ทำลายเกราะ (`expose`) โดนแรงขึ้นตามเปอร์เซ็นต์ ทั้งสกิลและตีปกติ
- ตาบอด (`blind`) กัดพลาดครึ่งหนึ่ง
อ่อนแรงกับทำลายเกราะอยู่ `debuff` วินาที (ตั้งต้น 9 ตั้งแต่ v0.6 จากเดิม 6) ธาตุดินระดับ 10 ทำให้ทุกสถานะนานขึ้น 30%

ค่าสถานะใหม่จากต้นสกิล: พลังรักษา (`healPct`) โอกาสยิงซ้อนตอนยิงธนูปกติ (`multiShot`) โอกาสตีติดพิษ (`poisonHit`)
ดาเมจใส่ศัตรูที่ติดสถานะ (`huntDmg`) และเวลาบัฟ (`buffTime`)
เซฟจากต้นสกิลแบบเดิมได้แต้มต้นสกิลคืนทั้งหมดหนึ่งครั้ง (`treesV` เทียบกับ `TREES_VERSION` ล่าสุดคือ 4 ของ v0.6) แต้มความเชี่ยวชาญกับธาตุยังอยู่ ตำราสกิลอื่นเรียนจากตำราที่หาได้ในเกม ("ผู้รอดชีวิต" ใช้ได้ทุกอาชีพ)

**ความเชี่ยวชาญ** (`MASTERIES`): อัปเป็นเส้นตรงสูงสุด 30 ระดับ (`MASTERY_MAX`) อ่านตำราขั้นสองแล้วไปต่อได้ถึง 60 (`MASTERY_MAX2`)
ได้ผลเมื่อถืออาวุธชนิดนั้น อาวุธแต่ละชนิดโตไปคนละทาง จุดบนเส้น: ระดับ 5, 10, 20, 30, 40, 50, 60 ติดตัว และ 15 ได้สกิล
สกิลระดับ 15 แรงขึ้น 3% ต่อระดับความเชี่ยวชาญ (ระดับ 60: +180%) อาวุธทุกชนิด (ดาบ ขวาน ค้อน หอก มีด ไม้เท้า ธนู สนับมือ กรงเล็บ) ซื้อได้ที่ร้าน
ความเชี่ยวชาญสนับมือกับกรงเล็บ (v0.3) ได้จากตำรา (`book_mastery_knuckle`, `book_mastery_claw` และขั้นสอง) เหมือนอาวุธอื่นที่ไม่ใช่อาวุธประจำอาชีพ

**ธาตุ** (`ELEMENTS`): อัปเป็นเส้นตรงสูงสุด 50 ระดับ (`ELEMENT_MAX`) อ่านตำราขั้นสองแล้วไปต่อได้ถึง 100 (`ELEMENT_MAX2`) มี 17 ธาตุ
ทุกระดับได้พลังโจมตีธาตุนั้น +2 และป้องกันธาตุนั้น +1.5 (เท่ากันทุกธาตุ) ค่าสถานะทั้งฝั่งโจมตีและฝั่งป้องกัน และความเด่นของธาตุ
ความเด่นมีสามแบบ: ดิน น้ำ ลม ไฟ สายฟ้า พืช เสริม**ทุกสกิล** · น้ำแข็ง แสง ความมืด หิน โคลน ลาวา พิษ ได้ผลกับ**การโจมตีธาตุของตัวเอง** (สกิลธาตุนั้น หรืออาวุธที่เคลือบธาตุ)
· โลหะ ควัน เงา ทอง เด่นเป็น**ค่าสถานะของตัวเอง** (สะท้อน หลบเวท หลบหลีกกับพลังโจมตี ต้านเวทกับต้านสถานะ)
ผลที่โตตามระดับยังโตต่อหลัง 50 (มีเพดาน: โล่ธาตุดิน 60% ของ HP โอกาสติดสถานะธาตุความมืด 60% โอกาสสาปหินธาตุหิน 40% สะท้อน 60% หลบเวท 60% ต้านสถานะ 75%)
ขั้นสองมีจุดเพิ่มทุกธาตุ: ระดับ 65 พลังโจมตีและป้องกันธาตุนั้น +20 · ระดับ 80 ค่าด้านเด่นของธาตุ (ราว 25 แต้ม เช่น ไฟ: พลังโจมตีและพลังเวท +7%)
· ระดับ 100 ดาเมจ +10% และพลังโจมตีธาตุนั้น +50 ธาตุที่ยังไม่มีภาพไอคอน (เงา ทอง) ใช้สัญลักษณ์วาดด้วยโค้ด

**ตารางดรอปของมอนสเตอร์** (`src/drops.ts`, `fieldDrops`): มอนสเตอร์ในฟิลด์ทุกตัว (161 ตัว รวมตัวหายากและบอส) มี**วัตถุดิบประจำตัว**ของตัวเองหนึ่งอย่าง
ดรอปจากตัวนั้นตัวเดียว (`mat_<id>` ชื่ออยู่ที่ `mat` ในตาราง `MONSTERS` ของ `src/bestiary.ts` เช่น ปูก้ามเหล็ก → ก้ามเหล็กของปู · ผู้พิทักษ์ศาลป่า → แก่นไม้ผู้พิทักษ์)
เป็นของขาย ไม่ใช้ในสูตรสร้าง ตัวธรรมดา 30% (ตัวถึก 36% ตัวไว 27%) ตัวหายาก 100% บอส 100% ทีละ 3–4 ชิ้น ไอคอนตามเผ่า สีตามธาตุ
ราคาขาย (`materialSell`) = (4 + 2.8 × เลเวล) × ชนิด (ตัวธรรมดา ตัวถึก ตัวไว ตัวร่ายเวท ×1 ตัวหายาก ×3 บอส ×8) เลเวลคือเลเวลประจำชนิดของมัน
เช่น เลเวล 10 ได้ 32 ทอง · 50 ได้ 144 · 100 ได้ 284 · 200 ได้ 564 ทองที่ได้จากวัตถุดิบประจำตัวต่อตัวโดยเฉลี่ยจึงราวหนึ่งในสามของทองที่ได้ตอนฆ่า ((1.5–3.5) × เลเวล)
วัตถุดิบตามเผ่า (`MATERIAL_OF`) สัตว์ แมลง สัตว์น้ำ → หนังสัตว์ · ไร้รูป มนุษย์ อันเดด → แร่เหล็ก · พืช ปีศาจ เทวะ มังกร → เศษอัญมณี (มังกรได้หนังสัตว์ด้วย)
ตัวธรรมดา 12% (ตัวถึก 14% ตัวไว 11%) ตัวหายาก 60% บอส 96% และอีกสองอย่างที่ไม่ใช่ของเผ่าอย่างละ 3% (ตัวหายาก 15% บอส 24%) ทุกช่วงเลเวลจึงหาวัตถุดิบครบทั้งสามไว้สร้างและปรุงยา
แก่นอสูร 1.5% + 0.03% ต่อเลเวล (ตัวหายาก ×10 บอส ×16)
หินนภาและหินดาราอย่างละ 0.6% (ตัวหายาก 5% บอส 30%) และอุปกรณ์ของช่วงเลเวลตัวเอง (`gearTierAt`: เลเวล 30–59 ได้ของเลเวล 30 ฯลฯ)
ตัวธรรมดา 0.3% ตัวหายาก 6% บอส 40% (`TIER_DROP`) ครึ่งหนึ่งเป็นอาวุธชนิดที่ผู้เล่นถืออยู่ในมือหลัก (ไม่ถืออะไร: อาวุธประจำอาชีพ) อีกครึ่งสุ่มชิ้นใดก็ได้ในช่วงนั้น
ทุกโอกาสเพิ่มตามโอกาสได้ของและโชคดีของผู้เล่น

**ตำรา** (`BOOKS`): ตำราสกิลทุกเล่ม ความเชี่ยวชาญทุกอย่าง และธาตุทุกธาตุมีตำราของตัวเอง (`book_<kind>_<id>`)
ดับเบิลคลิกในกระเป๋าเพื่ออ่าน ตำราสกิลของอาชีพอื่นอ่านไม่ได้ มอนสเตอร์ในฟิลด์ดรอปตำราที่ผู้เล่นยังเรียนได้
สุ่มเท่า ๆ กันทุกเล่ม (`BOOK_CHANCE`: ตัวธรรมดา 0.1% ตัวหายาก 2% บอส 25%) สไลม์ยังดรอปตำราผู้รอดชีวิต เก็บเกี่ยว และสายฟ้า (เล่มละ 0.03% สไลม์ม่วง 0.2%) ร้านค้าไม่ขายตำรา
สไลม์รอบอีเดนดรอปน้อย: เยลลี่ 40–60% ใบอ่อน (สไลม์เขียว 3% สไลม์ม่วง 20%) และไม่ดรอปชุด ชุดซื้อได้ที่ร้านค้า

**ตำราขั้นสอง**: ความเชี่ยวชาญอาวุธทุกอย่าง (`book_mastery2_<id>` ขยายถึง 60) และธาตุทุกธาตุ (`book_element2_<id>` ขยายถึง 100)
อ่านได้เมื่อเรียนเล่มแรกแล้วเท่านั้น ดรอปจากมอนสเตอร์เลเวล 40 ขึ้นไปเท่านั้น (`TIER2_DROP_LEVEL`) มูลค่า 9000 ทอง

ไอคอนตำราขั้นสองใช้ภาพของเล่มแรกพร้อมป้าย "II" ที่มุมขวาล่าง (`icon.badge`)

**หน้าต่างสกิล** (<kbd>K</kbd>, `src/charui.ts`) แบบ Ragnarok ขนาดคงที่ไม่มีแผงข้าง: ปุ่ม + และ − อยู่ที่มุมไอคอนของแต่ละสกิล กด + จองแต้มได้หลายแต้ม (คลิกขวาหรือ − คืน)
แถบล่างอยู่ตลอดที่ความสูงเดิม บอกแต้มที่เหลือและที่จอง (ชี้ดูว่าจะลงอะไรเท่าไร) มีปุ่ม **ยืนยัน** (ใช้แต้มที่จองทีเดียว ยืนยันแล้วคืนไม่ได้) และ **ยกเลิก** (ทิ้งที่จองทั้งหมด) และ "?" บอกวิธีใช้ ไม่มีหน้าต่างยืนยันเด้งขึ้นมาแล้ว
แท็บตำราสกิลวาดต้นไม้พร้อมเส้นบอกว่าต้องอัพอะไรถึงระดับเท่าไรก่อน ชี้ที่สกิล (แตะบนมือถือ) ขึ้นรายละเอียดลอยทับ: กดใช้หรือติดตัว ระดับ ธาตุที่โจมตี (หรือไร้ธาตุ)
ผลระดับนี้และระดับถัดไป MP ทุกระดับ คูลดาวน์ เวลาร่ายหลังลดเวลาร่าย ดาเมจโดยประมาณจากค่าสถานะตอนนี้ สิ่งที่ต้องอัพก่อน (✓/✗) และสกิลที่เปิดทางไปสู่ แท็บความเชี่ยวชาญและธาตุเป็นเส้นตรงที่มีจุดความสามารถพิเศษ ชี้ที่จุดเพื่อดูรายละเอียด ลากสกิลไปวางที่แถบสกิล หรือดับเบิลคลิกเพื่อใส่ช่องว่างช่องแรก คลิกขวาที่ช่อง (หรือลากออกนอกแถบ) เพื่อถอด ลากช่องไปช่องอื่นเพื่อสลับ
แถบสกิลกับความคืบหน้าทั้งหมดเซฟใน localStorage (`mmoproject.character.v1`)

| หอกบุทะลวง | อัศวินชั้นสูง | คมหอกราชันย์ (ติดตัว) → ท่วงท่าทวนเทพ (ติดตัว) · แทงทะลวงใจ → พายุพันหอก (คอมโบต่อจากแทงทะลวงใจ) → ห่าฝนหอกเทวา (ต้องมีปณิธานทวนเหล็กด้วย คอมโบต่อจากพายุพันหอก หรือหอกทะลุทัพ) · ขว้างหอกพิฆาต → หอกทะลุทัพ (คอมโบต่อจากขว้างหอกพิฆาต) · ขว้างหอกพิฆาต → ปณิธานทวนเหล็ก |
| เทพศาสตรา | อัศวินชั้นสูง | กายาเทพศาสตรา (ติดตัว) → ปรมาจารย์ร้อยศาสตรา (ติดตัว) · ฟันเทพศาสตรา → คลื่นศาสตราสะท้านฟ้า (คอมโบต่อจากฟันเทพศาสตรา) → เทพศาสตราพันเล่ม (ต้องมีเกราะเทพศาสตราด้วย คอมโบต่อจากคลื่นศาสตราสะท้านฟ้า) · วงล้อร้อยศาสตรา → ปัดป้องสะท้านศาสตรา · เกราะเทพศาสตรา |
| สายปืน | สไนเปอร์ | ศูนย์เล็งสไนเปอร์ (ติดตัว) → ลั่นไกสายฟ้า (ติดตัว) · ยิงรัวสามนัด → กราดยิงถล่ม (คอมโบต่อจากยิงรัวสามนัด หรือกระสุนกระจาย หรือปืนคู่ระห่ำ) → พายุกระสุนรอบทิศ (ต้องมีจังหวะมือปืนด้วย คอมโบต่อจากกราดยิงถล่ม) · กระสุนกระจาย → จังหวะมือปืน · ปืนคู่ระห่ำ |
| สายธนู | สไนเปอร์ | เล็งช่องเกราะ (ติดตัว) → ศรตามติดเงา (ติดตัว ต้องมีศรเจาะเกราะด้วย ร่ายศรเจาะเกราะเอง) · ศรเจาะเกราะ → ศรทลายเกราะ (คอมโบต่อจากศรเจาะเกราะ หรือศรทะลวงแนว) → ศรสังหารสุดขอบฟ้า (ต้องมีสมาธิพลซุ่มยิงด้วย คอมโบต่อจากศรทลายเกราะ) · ง้างสุดคันศร (ติดตัว) → สมาธิพลซุ่มยิง · ศรทะลวงแนว |
| เจ้าแห่งพลังธาตุ | พ่อมด | ลูกแก้วเพลิง → ปราชญ์สามธาตุ (ติดตัว) · ผสานธาตุ → มหาเวทธาตุแท้ (ต้องมีปราชญ์สามธาตุด้วย) · ลูกแก้วน้ำแข็ง → บ่อธาราแห่งปัญญา (ติดตัว) · ลูกแก้วอัสนี → ความคิดเร็วกว่าคำ (ติดตัว) |
| พ่อมดคำสาป | พ่อมด | ตำราต้องห้าม (ติดตัว) → คำสาปซึมลึก (ติดตัว) · ศรสาปทมิฬ → คำสาปเปราะสลาย → ฝนนรกาสามคำสาป (ต้องมีพิธีโลหิตทมิฬด้วย คอมโบต่อจากคำสาปเปราะสลาย หรือหมอกพิษกัดกร่อน หรือลาวาทะลักพสุธา) · หมอกพิษกัดกร่อน · ลาวาทะลักพสุธา → พิธีโลหิตทมิฬ |
| พลังธรรมชาติ | ดรูอิด | รากแก้วโบราณ (ติดตัว) → ผิวเปลือกไม้ศิลา · หนามพฤกษา → ศิลาผุดพสุธา (คอมโบต่อจากหนามพฤกษา) → พายุพงไพรพิโรธ (ต้องมีภูตพฤกษาผู้เยียวยาด้วย คอมโบต่อจากศิลาผุดพสุธา หรือหนามพฤกษา) · ฟื้นฟูแห่งพงไพร → ภูตพฤกษาผู้เยียวยา · ใจพฤกษาศิลา (ติดตัว) |
| พลังสัตว์ป่า | ดรูอิด | ร่างหมีสน → ตะปบหมีคำราม (คอมโบต่อจากพายุขนนกคม หรือเขากวางชุบชีวา) · ร่างนกอินทรี → พายุขนนกคม (คอมโบต่อจากตะปบหมีคำราม หรือเขากวางชุบชีวา) → สัญชาตญาณป่าดิบ (ติดตัว ต้องมีตะปบหมีคำรามและเขากวางชุบชีวาด้วย ร่ายตะปบหมีคำรามและพายุขนนกคมและเขากวางชุบชีวาเอง) · ร่างกวางเขาแดง → เขากวางชุบชีวา (คอมโบต่อจากตะปบหมีคำราม หรือพายุขนนกคม) · วิญญาณสัตว์ป่า (ติดตัว) |
| สายมีด | มือสังหาร | คมมีดมัจจุราช (ติดตัว) → สายเลือดมือสังหาร (ติดตัว) · แทงสามจุดตาย → เชือดไม่ขาดสาย (คอมโบต่อจากแทงสามจุดตาย หรือเงามีดพุ่งผ่าน) → แทงทะลวงหัวใจ (คอมโบต่อจากเชือดไม่ขาดสาย) → ร้อยมีดส่งวิญญาณ (ต้องมีปลุกสัญชาตญาณสังหารด้วย คอมโบต่อจากแทงทะลวงหัวใจ) · เงามีดพุ่งผ่าน → ปลุกสัญชาตญาณสังหาร |
| สายกรงเล็บ | มือสังหาร | เขี้ยวเล็บมรณะ (ติดตัว) → จุดตายนับพัน (ติดตัว) → กระหายเลือด (ติดตัว) · ตะปบฉีกจุดตาย → ฉีกร่างสี่คม (คอมโบต่อจากตะปบฉีกจุดตาย) → พันเล็บมัจจุราช (ต้องมีเนตรเสือดำด้วย คอมโบต่อจากฉีกร่างสี่คม) · ระบำกรงเล็บ → เนตรเสือดำ |
| ทหารคุ้มกัน | ราชองครักษ์ | โล่องครักษ์หลวง (ติดตัว) → เกราะสะท้อนพยัคฆ์ (ติดตัว) · กระแทกโล่มังกร → สามกระบวนดาบเสื้อแพร (คอมโบต่อจากกระแทกโล่มังกร) → ดาบอาญาสิทธิ์ (ต้องมีท่าประลองยุทธ์ด้วย คอมโบต่อจากสามกระบวนดาบเสื้อแพร) · กระแทกโล่มังกร → กำแพงโล่ทองแดง · ท่าประลองยุทธ์ → สวนดาบเสื้อแพร (ติดตัว) |
| ทหารไล่ล่า | ราชองครักษ์ | สัญชาตญาณมือปราบ (ติดตัว) → ฝีเท้ามือปราบ (ติดตัว) · ดาบปลดเกราะ → ดาบปลดอาวุธ (คอมโบต่อจากดาบปลดเกราะ หรือโซ่ตรวนราชทัณฑ์) → ตาข่ายสวรรค์ (ต้องมีหมายจับราชโองการด้วย คอมโบต่อจากดาบปลดอาวุธ หรือพุ่งตะครุบ) · โซ่ตรวนราชทัณฑ์ → พุ่งตะครุบ · หมายจับราชโองการ |
| ทหารจู่โจม | ราชองครักษ์ | เล็งมั่นองครักษ์ (ติดตัว) → ตาเหยี่ยวราชสำนัก (ติดตัว) · ยิงสกัดทัพ → ยิงทะลวงแนว (คอมโบต่อจากยิงสกัดทัพ) → นัดพิฆาตองครักษ์ (ต้องมีประจำป้อมซุ่มยิงด้วย คอมโบต่อจากยิงทะลวงแนว หรือระดมยิงถล่ม) · ยิงกระจายพัด → ระดมยิงถล่ม · ประจำป้อมซุ่มยิง |
| ชีวิตประดิษฐ์ | นักเล่นแร่แปรธาตุ | ตำราชีวิตประดิษฐ์ (ติดตัว) → โฮมุนครุสผู้เยียวยา → สายใยผู้สร้าง (ติดตัว) · โฮมุนครุสพลยิง → โฮมุนครุสผู้พิทักษ์ · ขวดกรดสังเคราะห์ → ยาปลุกพลังชีวิต · ขวดกรดสังเคราะห์ → สายธารสสารบริสุทธิ์ (ต้องมียาปลุกพลังชีวิตด้วย คอมโบต่อจากขวดกรดสังเคราะห์) |
| ระเบิดทำลายล้าง | นักเล่นแร่แปรธาตุ | ดินระเบิดสามธาตุ (ติดตัว) → สูตรระเบิดหนัก (ติดตัว) · ระเบิดสะเก็ดเหล็ก → ผงเร่งปฏิกิริยา → มหาระเบิดแปรธาตุ (ต้องมีระเบิดพวงสามลูกด้วย คอมโบต่อจากระเบิดพวงสามลูก) · ระเบิดหินถล่ม → ระเบิดพวงสามลูก (คอมโบต่อจากระเบิดหินถล่ม หรือระเบิดโคลนดูด) · ระเบิดโคลนดูด |
| ธาตุสังเคราะห์ | นักเล่นแร่แปรธาตุ | กายสังเคราะห์ (ติดตัว) → โลหิตแปรธาตุ (ติดตัว) · ฟาดสสารสังเคราะห์ → คลื่นสสารแปรธาตุ (คอมโบต่อจากฟาดสสารสังเคราะห์) → มหาสังเคราะห์ (ต้องมีผลึกธาตุโจมตีด้วย คอมโบต่อจากคลื่นสสารแปรธาตุ) · ผลึกธาตุโจมตี · ผลึกธาตุป้องกัน → ผลึกฝังกาย (ติดตัว) |
| กระบี่พเนจร | จอมยุทธ์ | กระบี่เดียวดาย (ติดตัว) → ใจกระบี่รุกรับ (ติดตัว) · กระบี่สามประกาย → ปราณกระบี่พันลี้ (คอมโบต่อจากกระบี่สามประกาย หรือก้าวเงาพเนจร) → กระบี่ไร้เทียมทาน (ต้องมีกระบี่ท่องยุทธภพด้วย คอมโบต่อจากปราณกระบี่พันลี้) · ก้าวเงาพเนจร → กระบี่ท่องยุทธภพ · กระบี่ไร้รูปปัดป้อง |
| ต่อสู้มือเปล่า | จอมยุทธ์ | ท่าสวนกลับ (ติดตัว) → ตั้งท่าสวนกลับ · หมัดพายุสายฟ้า → หมัดมังกรผงาดฟ้า (คอมโบต่อจากหมัดพายุสายฟ้า หรือก้าวพริบตา) → หมัดพิฆาตพันลี้ (ต้องมีตั้งท่าสวนกลับด้วย คอมโบต่อจากหมัดมังกรผงาดฟ้า) · ก้าวพริบตา → ก้าวเมฆาเตะพายุ · หมัดไร้เงา (ติดตัว) |
| สายขวาน | นักรบไวกิ้ง | เลือดนักรบเหนือ (ติดตัว) → โลหิตเป็นคมขวาน (ติดตัว) · ผ่ากะโหลก → ขวานทลายโล่ (คอมโบต่อจากผ่ากะโหลก) → ขวานวัลฮัลลา (ต้องมีเบอร์เซิร์กเกอร์ด้วย คอมโบต่อจากขวานทลายโล่) · ขวานหมุนพายุเหนือ → เบอร์เซิร์กเกอร์ · คมขวานไม่สนเกราะ (ติดตัว) |
| สายกระบอง | นักรบไวกิ้ง | กายาภูผาน้ำแข็ง (ติดตัว) → หนังหมีขาวเกราะเหล็ก (ติดตัว) · ทุบสะท้าน → ค้อนทลายหัว (คอมโบต่อจากทุบสะท้าน หรือทุบพื้นสั่นปฐพี) → ค้อนอัสนีทลายพิภพ (ต้องมีใจธารน้ำแข็งด้วย คอมโบต่อจากค้อนทลายหัว) · ทุบพื้นสั่นปฐพี → ใจธารน้ำแข็ง · ค้อนหนักพันชั่ง (ติดตัว) |
| ทะลวงฟัน | ซามูไร | ลมหายใจบูชิโด (ติดตัว) → ดาบกระหายเลือด (ติดตัว) · ชักดาบพริบตา → ฟันลมกรดสามจังหวะ (คอมโบต่อจากชักดาบพริบตา) → ซากุระร่วงพันกลีบ (ต้องมีใจนิ่งดั่งผิวน้ำด้วย คอมโบต่อจากฟันลมกรดสามจังหวะ) · วิถีคาตานะ (ติดตัว) → ใจนิ่งดั่งผิวน้ำ · สมาธิเยียวยากาย |

กลไกใหม่ที่สายเหล่านี้ใช้ (`SkillDef` ใน `src/progression.ts`): ลูกแก้วธาตุและผสานธาตุ (`orb`, `invoke`) แปลงร่าง (`form`)
ผู้ช่วยแบบยิงไกล (`spirit`) และแบบฟื้นฟู (`familiar`) ที่ยืมหน้าตามอนสเตอร์ได้ (`look`) ค่า `hpToAtk` `counter` `allyPct`
เงื่อนไขมือรองว่าง (`need.offEmpty`) และฮีลต่อเนื่อง (`hot`)

**อาชีพที่ 2 ใหม่: พ่อค้า** (`merchant`, นายห้างซาอีดที่โนอา) สาย ค้าขาย · เกวียนสินค้า ทุกสายได้สกิล "เปิดร้าน" (`src/stall.ts`):
ตั้งร้านในเมือง วางของได้ 6 ช่องขึ้นไป ตั้งราคาเอง ชาวเมืองแวะซื้อ (ราคาไม่เกินราคากลางซื้อแน่) เดินแล้วร้านปิด
**อาวุธใหม่: ปืนสั้น ปืนยาว** และความเชี่ยวชาญปืน **ยาใหม่:** ยาส้ม ยาเหลือง ยาขาว และความเชี่ยวชาญปรุงยา (ตำรานักปรุงยา)
**ตำราสกิลใหม่ 6 เล่ม:** นักรบเกราะหนัก เนโครแมนเซอร์ กระบองเหล็ก ขวานคลั่ง เกราะเวทมนตร์ เกราะศักดิ์สิทธิ์
**มอนสเตอร์ที่จู่โจมก่อน** มองเห็นไกลขึ้นและไล่ไม่เลิกจนผู้เล่นพ้นระยะสายตา 15 ม. ลากเป็นขบวนได้

## บอทล่ามอนสเตอร์

บอท (`src/bot.ts`, หน้าต่าง `src/botui.ts`) ล่าสไลม์รอบจุดที่ยืนตอนกดเริ่ม เดินอ้อมบ้าน บ่อน้ำ และพุ่มไม้ด้วยการหาเส้นทางบนกริด 40 ซม. (`findPath` ใน `src/world.ts`)
ตั้งค่าได้ในหน้าต่าง <kbd>B</kbd> และเซฟไว้ใน localStorage (`mmoproject.bot.v1`)

- **สกิล:** ทุกสกิลที่เรียนแล้วมีกฎของตัวเอง เปิด/ปิด และเลื่อนลำดับได้ (บนสุดใช้ก่อน) เงื่อนไขมี 3 แบบ:
  - ทันทีที่พร้อม: สกิลโจมตีใช้เมื่อเป้าหมายอยู่ในระยะ ส่วนฮีล โล่ และบัฟใช้ระหว่างสู้เมื่อเลือดไม่เต็ม ไม่มีโล่ หรือบัฟหมด
    บัฟที่อยู่นานตั้งแต่ 1 นาทีขึ้นไป (`LONG_BUFF` เช่นพรของนักบวช) ใช้ใหม่ทันทีที่หมดแม้อยู่นอกการต่อสู้ (ยกเว้นตอนนั่งพัก)
  - เมื่อ HP ต่ำกว่า X%
  - เมื่อมอนในวงสกิล (หรือรอบตัว) มีอย่างน้อย N ตัว
  สกิลที่เรียนใหม่จะเพิ่มท้ายรายการพร้อมเงื่อนไขตั้งต้นตามชนิด
  สกิลโจมตีที่ถึงเงื่อนไขแล้วแต่ MP ยังไม่พอ จะกัน MP ส่วนนั้นไว้ สกิลที่อยู่ล่างกว่าใช้ได้เฉพาะ MP ที่เกินจากนั้น
  (ไม่งั้นสกิลถูก ๆ จะใช้ MP ทันทีที่ฟื้น จนสกิลใหญ่ด้านบนไม่ได้ใช้เลย) สกิลที่แพงเกิน MP สูงสุดไม่กันอะไร
- **ตีปกติ:** ตีระหว่างรอคูลดาวน์ ถ้าปิดไว้ บอทจะยืนห่างตามระยะของสกิลที่สั้นที่สุด
- **เป้าหมาย:** เลือกชนิดสไลม์ที่จะล่า เลือกตัวที่ใกล้ที่สุด เลือดน้อยที่สุด หรือเลเวลสูงที่สุด และเลือกได้ว่าจะสู้กับตัวที่โจมตีเราก่อนเสมอ
- **พื้นที่ล่า:** รัศมี 3–25 ม. รอบจุดศูนย์กลาง (เส้นประบนพื้น) ย้ายจุดศูนย์กลางมาที่ตัวละครได้ ไม่มีมอนในเขตก็เดินกลับไปรอที่จุดศูนย์กลาง
  หรือติ๊ก "ล่าทั้งแผนที่" ให้ไล่ตัวไหนก็ได้ทั่วลาน (ซ่อนเส้นประและแถบรัศมี) ไม่มีมอนเหลือก็ยืนรอตรงนั้นจนมีตัวเกิดใหม่
- **พักฟื้น:** HP หรือ MP ต่ำกว่าที่ตั้งไว้และไม่มีตัวไหนไล่ตีอยู่ จะนั่งพัก (ฟื้น 2.5% ต่อวินาที) จนถึงระดับที่ตั้งไว้ และเก็บ MP ส่วนหนึ่งไว้ให้สกิลช่วยเหลือได้
- **เก็บของ:** ติ๊ก "เดินไปเก็บของที่ดรอป" (เปิดไว้ตั้งแต่ต้น) แล้วระหว่างไม่มีตัวไหนไล่ตี บอทจะเดินไปเหยียบของที่ตกในเขตล่า (ล่าทั้งแผนที่: ในระยะ 9 ม.) ก่อนหาตัวต่อไป ไปไม่ถึงจะข้ามชิ้นนั้น 8 วินาที
- **อื่น ๆ:** หยุดเมื่อกระเป๋าเต็ม ตัวละครล้มเมื่อไรบอทหยุดเองเสมอ
- กดเดิน คลิก หรือ Space เองได้ตลอด บอทจะหยุดรอ 2.5 วินาทีแล้วทำต่อ เดินไปหาเป้าหมายไม่ได้นานเกิน 1.2 วินาทีจะข้ามตัวนั้นไป 8 วินาที
- ระหว่างทำงานปุ่ม "ออโต้" ข้างแถบสกิลขึ้นว่าหยุดออโต้ หน้าต่างบอทบอกสถานะ เวลา จำนวนที่ล่าได้ EXP และของที่ได้

## เมืองอีเดนและแผนที่

- **อีเดน** (`src/world3d/town_eden.ts`) เมืองเริ่มต้น วางตามผังที่วาดมือ (ทิศเหนือขึ้นจอ 1 พิกเซลผัง = 18 ซม. แล้วย่อทั้งเมืองเหลือ 85% ด้วย `TOWN_SCALE` ทั้งตึก ถนน ต้นไม้ กรอบชน และตำแหน่งชาวเมือง ตัวเมืองราว 150 × 128 ม.)
  มีกำแพงเมืองและประตู 3 ทิศ ถนนใหญ่สองสายตัดกันกลางเมือง และย่านละหนึ่งลาน:
  มหาวิหาร (ตะวันตกเฉียงเหนือ) ตลาด (ตะวันออกเฉียงเหนือ) สวนวีรบุรุษ (ตะวันตกเฉียงใต้) ลานน้ำพุกับโรงเตี๊ยมและร้านเครื่องมือ (ตะวันออกเฉียงใต้)
  และย่านท่าเรือริมทะเลฝั่งตะวันออก มีแอ่งจอดเรือ ท่าเทียบเรือ เรือใหญ่ และประภาคาร
- **บ้านเรือน** เรียงติดกันเป็นแถวตลอดแนวถนนแบบพรอนเทร่า เว้นซอยเข้าลาน บ้านแต่ละหลังสลับแบบและสีหลังคา/ผนัง
  ของทุกชิ้นมาจากชุดของเมือง (`src/world3d/kits/`) วาดเป็น instanced mesh แยกตามบล็อก 50 ม. บล็อกที่อยู่นอกจอจึงไม่เสียแรงวาด
- **มองทะลุตึก:** ตึกหรือต้นไม้ที่บังผู้เล่นจะโปร่งเป็นวงรอบตัว (dither) ถนนระหว่างตึกสูงจึงยังมองเห็น
- **ชาวเมือง** (`src/npcs.ts`) ยืนตามจุดแดงในผัง: ทหารยามประตู ผู้นำทาง นักบวชรักษาฟรี ร้านเครื่องมือ กะลาสี ฯลฯ หันหาผู้เล่นเมื่อเข้าใกล้ เหนือหัวมีแค่ชื่อกับฉายา (ฉายาสว่างขึ้นเมื่ออยู่ในระยะคุย) คุยด้วยแล้วขึ้นหน้าต่างคุย (ดูหัวข้อ "คุยกับชาวเมือง และเควส")
- **วาร์ป:** เดินเข้าวงแสงสีฟ้าหน้าประตูเพื่อออกไปฟิลด์ข้างนอก (ประตูตะวันตก: ทุ่งหญ้าตะวันตก ประตูเหนือ: ถนนหลวง ประตูใต้: ทุ่งสะวันนาใต้) และวงแสงในฟิลด์พากลับ
  วาร์ปพาไปถึงจุดของแผนที่ปลายทางที่บอกว่า "มาจากแผนที่ไหน มาโผล่ตรงไหน" (`gates` ของแต่ละแผนที่) จึงไปและกลับได้ทุกทาง
  ในเมืองไม่มีมอนสเตอร์ ตายแล้วฟื้นที่ลานน้ำพุของอีเดน
- **เรือโดยสาร:** กัปตันที่ท่าเรืออีเดนพาไปโยเดีย โอซากิ เวนิชเซีย หรือซูโจว กัปตันโยเดียไปอีเดนหรือเวนิชเซีย กัปตันโอซากิกลับอีเดน
  กัปตันเวนิชเซียไปอีเดน โยเดีย หรือซูโจว กัปตันซูโจวไปอีเดนหรือเวนิชเซีย (เปิดแผนที่โลกให้เลือกได้แค่ท่าเรือของเรือลำนั้น)
- **แผนที่** (`src/maps.ts`) สร้างครั้งแรกที่เข้าแล้วเก็บไว้ เมื่อเข้าแผนที่ กรอบชน ขอบเขต และตาราง path ของ `src/world.ts` เปลี่ยนตาม
- **หน้าโหลด:** ตอนเข้าเกมและตอนเปลี่ยนแผนที่ หน้าโหลดบังจอพร้อมแถบความคืบหน้าจนกว่าทุกอย่างพร้อม: สร้างฉาก แต่งตัวชาวเมืองครบ
  compile shader ทุกตัวของฉาก (`World3D.compile`) และถ่ายภาพแผนที่ ระหว่างนั้นเกมหยุดรอ จึงไม่มีเฟรมกระตุกหรือคนที่ยังไม่ได้แต่งตัวโผล่มา

### Minimap และหน้าต่างแผนที่ (`src/mapui.ts`, `src/worldmap.ts`)

- **ภาพแผนที่** ของแต่ละที่คือฉาก 3 มิติจริงมองจากด้านบนตรง ๆ ทิศเหนือขึ้น (`World3D.snapshot`) ถ่ายในเฟรมแรกที่เข้าแผนที่นั้นแล้วเก็บไว้
  วาดเป็นแผ่น ๆ ลงมุมของ canvas เกมเองแล้วคัดลอกออก shader ทุกตัวจึงไม่ต้อง compile ใหม่ ปิดหมอกและการมองทะลุตึกตอนถ่าย
  และยกดวงอาทิตย์ให้สูงขึ้นเงาจะได้สั้น ภาพกว้างกว่าขอบเขตเดินได้ 10 ม. ทุกด้านให้เห็นวงวาร์ป (คอม 2048 พิกเซล มือถือ 1280)
- **Minimap** มุมขวาบน รัศมีราว 60 ม. รอบตัว (มือถือ 48 ม.) ทิศเหนือขึ้นเสมอ ลูกศรคือทางที่ตัวละครหัน พัดจาง ๆ คือทางที่กล้องมอง
  จุดเหลืองร้านค้า จุดเขียวนักบวช จุดขาวชาวเมือง จุดแดงมอนสเตอร์ วงฟ้าวาร์ป บนมือถือแตะ minimap เพื่อเปิดแผนที่ (ปุ่มแถบเมนูเลื่อนไปทางซ้ายของ minimap)
- **แผนที่ของที่ที่อยู่:** ภาพเต็มของเมืองหรือทุ่ง ชื่อย่าน (`labels` ของแต่ละแผนที่) ร้าน นักบวช ทางวาร์ปว่าไปไหน ประตูที่ปิดเป็นกากบาท
  ชี้ที่จุดเพื่อดูชื่อคนหรือคำอธิบายข้างล่าง
- **คลิกเพื่อเดินไป:** คลิก (หรือแตะ) ตรงไหนบนแผนที่ ตัวละครเดินไปเองตามเส้นทางที่อ้อมบ้านและกำแพง (`findPath` ของ `src/world.ts`)
  คลิกชาวเมืองก็เดินไปคุย (ร้านเปิดร้าน นักบวชรักษา) คลิกวงวาร์ปก็เดินเข้าวาร์ป บนแผนที่โลกคลิกที่ที่ติดกับแผนที่นี้เพื่อเดินไปวาร์ปทางนั้น
  ทางที่เหลือเป็นเส้นประสีทองพร้อมธงปลายทางบนแผนที่และ minimap และมีวงสีทองบนพื้นตรงจุดหมาย
  คลิกพื้นในฉากก็เดินแบบเดียวกัน (คอมพิวเตอร์) กดเดินเอง โจมตี หรือติดอยู่กับที่เกินวินาทีกว่า ๆ (เช่นโดนมอนสเตอร์ขวาง) คือเลิกเดิน ที่ที่ไปไม่ถึงเลย (กลางทะเล ในตึก) ขึ้นว่า "ไปที่นั่นไม่ได้"
  บนมือถือแตะแล้วแผนที่ปิดเองให้เห็นตัวละครเดิน
- **แผนที่โลก** (`src/worldmap.ts`) เป็นตารางแบบ RO: ช่องละหนึ่งแผนที่ แต่ละช่องคือภาพจริงของแผนที่นั้นมองจากด้านบน (ทิศเหนือขึ้น)
  วางเรียงตามทางเดินที่ต่อกัน (ออกทางตะวันออกของช่องไหนก็เข้าช่องทางขวา) อีเดนอยู่ช่อง (0, 0) ช่องที่ไม่มีแผนที่เป็นทะเล ภูเขาหิมะ ป่า ทราย หรือทุ่งที่ยังไม่มีใครสำรวจ
  สองแผนที่ที่ติดกันแค่มุม (ถนนหลวงกับเชิงเขาหิมะ ที่อ้อมปราสาท และที่ราบใต้โนอากับเวนิชเซีย) มีทางออกที่มุมนั้น
  ทุกแผนที่ต่อกับช่องข้างๆ อย่างเนียน: ขอบที่ติดทะเลมีชายฝั่งกับทะเล ขอบที่ติดแผ่นดินมีภูมิประเทศแบบเดียวกับข้างๆ (หิมะต่อหิมะ
  ป่าต่อป่า ต่างกันก็ค่อยๆ เปลี่ยน) และทางออกของสองแผนที่อยู่ตรงตำแหน่งเดียวกันบนขอบที่ติดกัน ตรวจด้วย `node tools/world_fit.cjs`
  (อ่านขอบแต่ละด้านจากภาพของช่อง เทียบกับช่องข้างๆ และทางออก บอกเฉพาะที่ไม่เข้ากัน)
  ลากเพื่อเลื่อน ล้อเมาส์หรือปุ่ม + − ซูม ช่องที่อยู่มีขอบสีทองและลูกศรบอกตำแหน่งจริงของผู้เล่นในช่อง ชื่อแผนที่อยู่ใต้ช่อง ฟิลด์บอกเลเวลมอนสเตอร์
  ผู้นำทางและกัปตันเปิดแผนที่ทั้งโลก ช่องที่พาไปไม่ได้จะมืดลง ค่าเดินทางคิด 600 ทองต่อช่อง (ขั้นต่ำ 1,000)
  ภาพของแต่ละช่องถ่ายล่วงหน้าด้วย `node tools/world_tiles.cjs [map id ...]` (โหลดทุกแผนที่ในเกมจริงแล้วถ่ายจากด้านบน เก็บที่ `public/assets/worldmap/<id>.webp`) แผนที่เปลี่ยนเมื่อไรให้ถ่ายใหม่

## เมืองและฟิลด์

เมือง 12 แห่ง (`src/world3d/town_<id>.ts`, รวมพระราชวังหลวง) และฟิลด์ 66 แห่ง (`src/world3d/field_<id>.ts`) โหลดครั้งแรกที่เข้า ผู้นำทางในทุกเมืองพาไปเมืองอื่นได้ทันที เสียค่าเดินทาง 1,000 ทองขึ้นไป ไกลยิ่งแพง (`travelFee` ใน `src/mapui.ts`; ชี้ที่เมืองเพื่อดูราคา) เรือโดยสารยังไม่เสียเงิน

- **แดนตะวันตก** (คอนเซ็ปใน `docs/west_lands.md`): เมืองหลวงเก่าโนอาเป็นชุมทาง ไฮแลนด์ ฮิลอยู่เชิงเขาหิมะ ซูโจวกับเวนิชเซียเป็นเมืองท่าที่มีเรือ

  ผู้เล่นต้องเดินทางไปทั่วแดนตามเลเวลของตัวเอง
- **เมืองของแดนตะวันตก**

  - **ซูโจว**: เมืองท่าแบบจีน เจดีย์แปดเหลี่ยม 7 ชั้นที่เป็นประภาคาร คลองกับสะพานโค้ง ซุ้มไผ่ไหล ถนนโคมแดง สวนจีนกับประตูพระจันทร์ และเรือสำเภา
  - **ไฮแลนด์ ฮิล**: เมืองหินในหิมะ หินบรรพบุรุษกลางลาน วิหารบรรพบุรุษบนลานสูง เรือนกระจกกับแปลงผักใต้หิมะ ภูเขาหิมะทางตะวันออกเฉียงเหนือ
  - **เวนิชเซีย**: เมืองคลองแบบเวนิส คลองใหญ่รูปตัว S สะพานแบบรีอัลโต มหาวิหาร 5 โดม หอระฆัง เสาสิงโตมีปีก กอนโดลา และท่าเรือใหญ่

- **พื้นต่างระดับ** (`src/world3d/terrain.ts`): เนิน แอ่ง ที่ราบสูงมีหน้าผาหินล้อมรอบ (เดินขึ้นลงหน้าผาไม่ได้) และทางลาดขึ้นแต่ละชั้น
  ความสูงของพื้นใต้แต่ละจุดเข้าไปใน `mapY` ของ `src/projection.ts` ตัวละคร มอนสเตอร์ เอฟเฟกต์ วงเป้าหมาย และวาร์ปจึงยืนบนพื้นจริง
  คลิกพื้นหาจุดที่สายตาชนพื้นก่อน (`groundAt`) หน้าผาที่บังอยู่จึงรับคลิกแทนพื้นข้างหลัง ของทุกชิ้นที่วางในเมืองและฟิลด์ตั้งบนพื้นเอง
- **ฟิลด์** (`src/world3d/field.ts`): สร้างแบบเดียวกับเมือง มีทางดิน แม่น้ำ สะพาน จุดวาร์ป และจุดเกิดมอนสเตอร์ ขอบรอบนอกเป็นป่าทึบ หน้าผา หรือทะเล ไม่เห็นขอบโลก
  ของประกอบฉากแต่ละภูมิประเทศอยู่ในชุด `plains` `snowland` `steppe` `frontier` `desert` `jungle` `volcanic` (ดูได้ที่ `/kits.html`)
- **มอนสเตอร์ในฟิลด์:** มอนสเตอร์แต่ละชนิดมีเลเวลเดียว (`level` ใน `MONSTERS` ของ `src/bestiary.ts`) ทุกตัวของชนิดนั้นเกิดที่เลเวลนี้เสมอ ทั้งในฟิลด์บ้านและฟิลด์ที่มันไปเยือน (`VISITORS`) มอนสเตอร์ในฟิลด์เดียวกัน (ชนิดประจำฟิลด์ ตัวที่มาเยือน และบอส) มีเลเวลห่างกันไม่เกิน 20
  ช่วงเลเวลของฟิลด์ (แผนที่โลก สมุดภาพ) คือเลเวลต่ำสุดถึงสูงสุดของชนิดที่อยู่ในฟิลด์นั้น (`fieldLevels`)
- **มอนสเตอร์เก่งขึ้นตามเลเวล (v0.3, `monsterMight` ใน `src/bestiary.ts`):** HP พลังโจมตี ป้องกัน และต้านเวทของมอนสเตอร์ทุกตัว (`statsFor`) และสไลม์ (`VARIANTS`)
  คูณ 1.2 ที่เลเวล 1–30 · 1.4 ที่ 31–70 · 1.6 ที่ 71–100 · 1.8 ที่ 101–150 · 2 ที่ 151–200 EXP เท่าเดิม
  ขอบแต่ละช่วงค่อย ๆ ไล่ขึ้น 4 เลเวลรอบขอบ (+0.04 ต่อเลเวล เช่น เลเวล 29: 1.24 · 30: 1.28 · 31: 1.32 · 32: 1.36 · 33: 1.4) มอนสเตอร์จึงไม่เก่งขึ้นทีเดียว 1 ใน 5 จากเลเวลข้างกัน
  เพราะทั้ง HP และพลังโจมตีคูณพร้อมกัน HP ที่เสียต่อการสู้หนึ่งตัวเพิ่มราวกำลังสองของตัวคูณ (1.2 → ราว 1.45 เท่า · 1.4 → 2 เท่า · 2 → 4 เท่าขึ้นไป) และเวลาที่ใช้ฆ่าเพิ่มเท่าตัวคูณ (EXP ต่อชั่วโมงลดลงราว 20% ช่วงแรก)
  ตัวละครใหม่เลเวล 1 ยังตีสไลม์เขียวได้สบาย (ตีปกติอย่างเดียว: นักรบราว 24 ตัวต่อหลอด HP นักเวทราว 10 ตัว จากเดิม 35 และ 15) สไลม์ม่วงเลเวล 9 เหลือราว 2–6 ตัวต่อหลอด HP
  ตั้งแต่เลเวล 30 ขึ้นไปการตีปกติอย่างเดียวไม่พอ ต้องใช้สกิล ยา ฮีล บัฟ และอุปกรณ์ (ในอนาคตปาร์ตี้)

## คุยกับชาวเมือง และเควส

คุยกับใครก็ได้ (คลิกหรือ <kbd>F</kbd>) ขึ้นหน้าต่างคุย (`TalkDialog` ใน `src/questui.ts`): สิ่งที่เขาพูด (เปลี่ยนไปทุกครั้งที่คุย) แล้วเป็นเมนู
- **เมนูหน้าที่** (▸): ร้านค้า "ซื้อของ" / "ขายของ" (เปิดหน้าต่างร้านที่แท็บนั้น) · นักบวช "รักษา" (HP และ MP เต็ม ตอบในหน้าต่าง) ·
  ผู้นำทาง "เซฟจุดเกิด" / "วาร์ป" · กัปตันเรือ "ขึ้นเรือ"
- **เควสของเขา:** ป้าย "ส่งเควส" (ทำครบแล้ว) · "เควส" (รับได้) · "กำลังทำ" เลือกแล้วอ่านเรื่องกับรางวัล แล้วกด "รับเควส" หรือ "ส่งเควส"
  ไม่บอกล่วงหน้าว่าเควสมีกี่ขั้น หรือขั้นต่อไปคืออะไร เห็นแค่ขั้นที่ทำอยู่ (ผู้เล่นลุ้นเอง)

ไม่มีเครื่องหมายบนหัวชาวเมือง เควสที่รับได้ทั้งหมดดูได้ในสมุดเควส แท็บ "รับได้" (บอกว่าใครให้ อยู่เมืองไหน)
เดินออกห่างหรือกด <kbd>Esc</kbd> แล้วหน้าต่างปิดเอง
<kbd>J</kbd> หรือปุ่ม "เควส" เปิดสมุดเควส: กำลังทำ (สิ่งที่ต้องทำตอนนี้ ความคืบหน้า ส่งที่ใคร ยกเลิกได้) · รับได้ (และที่ยังรับไม่ได้เพราะอะไร) · สำเร็จแล้ว

**บอกสถานที่:** ทุกที่ที่เอ่ยชื่อคน (คนให้เควส คนที่ต้องไปคุย คนรับของ) บอกเมืองกับจุดที่ยืน เช่น "ท่านนาดีม (บาฮามัส · โอเอซิส)"
ขั้นล่ามอนบอกฟิลด์ที่มันอยู่ จุดที่ยืนคือป้ายชื่อบนแผนที่ที่ใกล้ที่สุด (`src/world_index.ts` สร้างด้วย `node tools/world_index.cjs`)

**นำทาง** (ปุ่มในตัวติดตามเควสใต้ HP/MP ในสมุดเควส และในหน้าต่างคุยตอนเควสยังไม่เสร็จ, `src/guide.ts`): เดินไปจุดหมายของขั้นที่ทำอยู่เอง
ข้ามแผนที่ทีละแผนที่ทางทางออกที่สั้นที่สุด ถึงแล้วเดินเข้าไปคุยกับคนนั้น หรือหยุดเมื่อถึงฟิลด์ของมอน ที่ไปได้แค่ทางเรือจะพาไปหากัปตันเรือ
กดเดินเองหรือคลิกที่อื่นคือเลิกนำทาง
เควสที่ทำอยู่ขึ้นที่แถบใต้ HP/MP ด้วย (คลิกเพื่อเปิดสมุด)

- **แบบ:** ทำครั้งเดียว หรือทำซ้ำได้ (รับใหม่ได้เมื่อครบเวลา 3–15 นาที) ขั้นเดียวจบ หรือต่อกันหลายขั้น แต่ละขั้นส่งให้คนที่กำหนดก่อนขึ้นขั้นต่อไป
- **เป้าหมาย:** ปราบมอนสเตอร์ตามจำนวน · เก็บของมาส่ง (ส่งแล้วของถูกเอาไป บางอย่างดรอปเฉพาะตอนที่เควสต้องการ) · ไปคุยกับใคร ·
  ไปถึงแผนที่ไหน (ผ่านไปเองเมื่อถึง) · ถึงเลเวล บางเควสต้องเลเวลถึงหรือทำเควสก่อนหน้าก่อน บางขั้นฝากของให้ถือไปส่ง (จดหมาย)
- **รางวัล:** ทอง EXP แต้มสกิล (บวกจากแต้มต่อเลเวล เก็บใน `bonus` ของตัวละคร) และไอเทม กระเป๋าเต็มของจะตกที่เท้า เควสทำซ้ำไม่ให้แต้มสกิล

## ร้านค้า ทอง และยา

- **ร้านเครื่องมือของลิเลีย** อยู่ลานน้ำพุในอีเดน และ **แม่ค้ามิร่า** ยืนข้างรถเข็นกลางลานในทุ่งหญ้า (`src/shop.ts`) หันหาผู้เล่นเมื่อเข้าใกล้ ใช้สไปรต์นักผจญภัยตัวแรกจาก Oriverse (ไม่ใช้เครดิตเพิ่ม) และมีกรอบชนของตัวเองใน `src/world.ts`
- **ซื้อ:** ขายแค่ของพื้นฐาน: ยาแดง/ยาแดงเข้มข้น (ฟื้น HP 45/150, 50/160 ทอง) ยาฟ้า/ยาฟ้าเข้มข้น (ฟื้น MP 18/60, 60/180 ทอง; ตั้งใจให้ฟื้นน้อยและแพง สกิลป้องกันและฟื้นฟูจึงคุ้มกว่า) อาวุธทุกชนิด ของมือรองทุกชิ้น และเสื้อผ้าบางสี ยากดจำนวนได้
  (ตำรา หมวก รองเท้า แหวน และเครื่องประดับไม่ขาย ต้องหาในเกม) ยาฟื้นเป็นหน่วยตายตัว ขวดแปรธาตุเพิ่มให้ 25%
- **ขาย:** ทุกอย่างในกระเป๋าที่ไม่ได้สวมใส่ ได้ 40% ของราคา วัตถุดิบมีราคารับซื้อของตัวเอง และมีปุ่มขายวัตถุดิบทั้งหมด
- **ดูรายละเอียด:** ชี้เมาส์ที่ไอเท็ม (ทั้งหน้าซื้อและหน้าขาย) เห็นรายละเอียดแบบเดียวกับในกระเป๋า (ชนิด ค่าสถานะ ดาเมจ/ระยะ และเหตุผลถ้ายังใส่ไม่ได้) แตะหรือคลิกที่ไอเท็มเพื่อเปิดรายละเอียดค้างไว้ใต้แถว (สำหรับจอสัมผัส) แตะอีกครั้งเพื่อปิด
- **ทอง:** สไลม์ทุกตัวให้ทองตามเลเวล (การเก็บเกี่ยวเพิ่มให้ด้วย)
- **ยา:** ดับเบิลคลิกเพื่อดื่ม (คูลดาวน์ 0.8 วิ) บอทดื่มเองเมื่อ HP/MP ต่ำกว่าที่ตั้งไว้ โดยเลือกขวดเล็กที่สุดที่พอ

## ระบบอื่น

**กระเป๋า** (`src/inventory.ts`, `src/ui.ts`): ตาราง 8×5 กับช่องสวมใส่ 10 ช่อง (มือหลัก มือรอง หมวก เสื้อ กางเกง/กระโปรง รองเท้า แหวน 2 ช่อง ประดับ 2 ช่อง) และทองที่มี
หมวก รองเท้า แหวน และเครื่องประดับเพิ่มค่าสเตตัส (ยังไม่วาดบนตัวละคร) ร้านค้าไม่ขาย มอนสเตอร์ในฟิลด์ดรอปทุกแบบ (ตัวธรรมดา 1.2% ตัวหายาก 25% บอส 60%)
**อุปกรณ์ตามเลเวล** (`GEAR_TIERS`: 30 60 90 120 150 180, id `t<เลเวล>_<ช่อง>`): ทุกเลเวลมีอาวุธครบ 12 ชนิด เสื้อเกราะ เกราะท่อนล่าง หมวก รองเท้า แหวน และจี้
ชื่อตามวัสดุ (เหล็ก เงินยวง ทองคำขาว มิธริล อดามันต์ ดารา) แรงกว่าของร้านนิดหน่อยและไม่มีความสามารถพิเศษ (`tierStats`) ใส่ได้เมื่อเลเวลถึง
อาวุธ: พลังโจมตี (ไม้เท้า: พลังเวท) 0.3 × เลเวลของอุปกรณ์ สองมือ ×1.5 (อาวุธมือรองให้ค่าสถานะครึ่งหนึ่ง) · เสื้อ: ป้องกันและต้านเวท · ท่อนล่าง: ป้องกันและ HP
· หมวก: ป้องกันและต้านเวท · รองเท้า: ป้องกัน หลบหลีก ความเร็วเดิน 4% · แหวน: พลังโจมตีและพลังเวท · จี้: HP และ MP
เสื้อและท่อนล่างตามเลเวลใส่ได้ทั้งชายและหญิง (`Item.male`: ตัวละครชายใช้ทรงนักรบสีเดียวกัน, `garmentLook`) เลเวลบอกในคำอธิบายไอเทม (ไอคอนไม่มีเลข)
หาได้จากมอนสเตอร์ (ดูตารางดรอป) หรือสร้างเท่านั้น ร้านค้าไม่ขาย
**ไอเทมตีบวกและไอเทมที่สร้าง**: id ของอุปกรณ์มีระดับตีบวกและชื่อผู้สร้างต่อท้ายได้ `<id>~<บวก>^<ผู้สร้าง>` เช่น `t60_sword_1h~3^มิร่า`
(`splitId`/`joinId`) `ITEMS` เป็น Proxy ที่สร้างไอเทมนั้นจากของตั้งต้นตอนถูกเรียกครั้งแรก: ชื่อ "+3 ดาบมือเดียวเงินยวง ของมิร่า" ค่าสถานะของตั้งต้นบวกค่าตีบวก (`refineStats`)
ตีบวกได้ถึง +10 (`REFINE_MAX`) ต่อ +1: อาวุธ พลังโจมตี/พลังเวท 2–6 (ตามเลเวลอุปกรณ์) · แหวน พลังโจมตีและพลังเวท 1–3 · จี้ HP 8–28 · โล่ ป้องกันและต้านเวท ·
สมุด/ขวด พลังเวท 2 · ที่เหลือ ป้องกัน 1–3 หินที่ใช้ (`stoneFor`): หินนภาสำหรับอาวุธและแหวน หินดาราสำหรับชุด หมวก รองเท้า จี้ และของมือรอง ไอคอนมี "+N" ที่มุมซ้ายบน
**วัตถุดิบ**: แร่เหล็ก หนังสัตว์ เศษอัญมณี แก่นอสูร (ใช้สร้างของ) หินนภา หินดารา (ใช้ตีบวก) และวัตถุดิบประจำตัวของมอนสเตอร์แต่ละตัว (ไว้ขายร้านค้า) ดรอปจากมอนสเตอร์ตามตารางดรอป

**สารบัญ** (<kbd>C</kbd> หรือปุ่ม "สารบัญ", `src/codex.ts`): ข้อมูลทั้งหมดของเกม อ่านจากตารางในโค้ดตรง ๆ จึงตรงกับเกมเสมอ
- มอนสเตอร์: เรียงตามฟิลด์และเลเวล ภาพจากสไปรต์ (ไม่มีภาพใช้สัญลักษณ์เผ่า) เลเวลประจำชนิด HP พลังโจมตี ป้องกัน ต้านเวท EXP ที่เลเวลนั้น (`statsFor`)
  นิสัย (โจมตีก่อน ยิงไกล เรียกพวก…) ป้องกันธาตุ ที่อยู่ และของดรอปพร้อมโอกาส (`fieldDrops` วัตถุดิบประจำตัวพร้อมราคาขาย อุปกรณ์ตามเลเวล ของร้านแบบสุ่ม ตำรา)
- ไอเทม: กรองตามชนิดและค้นหาชื่อ แต่ละชิ้นบอกรายละเอียดและที่มาทุกที่ (ร้านค้า มอนสเตอร์ที่ดรอป ช่วงเลเวลของอุปกรณ์ การสร้าง รางวัลเควส ของระหว่างเควส)
- เปลี่ยนอาชีพ: อาชีพแรกและตำรา อาชีพที่ 2 ทุกอาชีพ เจ้าอาชีพกับเมือง เงื่อนไข ขั้นตอนเควส และสายทั้งหมด
- ตำนาน: ยังว่างไว้ (เล่าทีหลัง) · ที่มาของเมือง: ประวัติทั้ง 7 เมือง (`TOWN_LORE`)

**โรงช่าง** (`src/workshop.ts`): เปิดได้สองทาง
1. คุยกับช่างตีเหล็ก (NPC `role: "smith"`: กุนเธอร์ที่อีเดน บียอร์นที่ไอซ์เบิร์ก ฮันส์ที่คราเดีย ซอลองโกที่ทรุนราดา) เลือก "ตีบวก" หรือ "สร้างไอเทม"
   ช่างทำให้ทุกคนแต่คิดค่าจ้างเป็นทอง เดินห่างจากช่างหน้าต่างจะปิด
2. สกิลของความเชี่ยวชาญการสร้าง (ลากใส่แถบสกิลแล้วกดใช้) เปิดหน้าต่างได้ทุกที่ ไม่เสียค่าจ้าง:
   ระดับ 1 สกิลสร้าง (เตาหลอมพกพา / โต๊ะช่างเกราะ / โต๊ะเจียระไน) ระดับ 3 สกิลตีบวก (ทั่งตีบวก / ตีบวกเกราะ / ตีบวกอัญมณี: เฉพาะของที่ความเชี่ยวชาญนั้นสร้าง)
   บอทไม่ใช้สกิลพวกนี้
- **ตีบวก**: ของที่สวมอยู่และในกระเป๋า ครั้งละหิน 1 ก้อน (`stoneFor`) ที่ช่างเสียค่าจ้างอีก 100 × (ระดับถัดไป) × (1 + เลเวลอุปกรณ์/60) ทอง
  โอกาสสำเร็จ (`REFINE_CHANCE`) ถึง +4: 100% · +5 85% · +6 70% · +7 55% · +8 40% · +9 30% · +10 20% คูณโชคดี (`luckFactor`)
  และบวก 0.5% ต่อระดับของความเชี่ยวชาญการสร้างที่ทำของชนิดนั้น (`CRAFT_REFINE`) ตีไม่ติดเสียหิน (และค่าจ้าง) ของยังเป็นระดับเดิม
- **สร้างไอเทม**: สูตร (`recipe`, k = เลเวลอุปกรณ์/30): อาวุธ แร่เหล็ก 3k+2 (สองมือ ×1.5) · ชุด หนังสัตว์ 3k+2 · หมวก/รองเท้า หนังสัตว์ 2k+1 · แหวน/จี้ เศษอัญมณี 2k+2 ทุกชิ้นใช้แก่นอสูร k ก้อน
  ที่ช่าง: สร้างได้ทุกชนิดถึงเลเวลของผู้เล่น จ่ายค่าจ้าง 250–300 × k ทอง ของไม่มีชื่อผู้สร้าง
  ด้วยสกิล: ต้องรู้ความเชี่ยวชาญการสร้าง (`weaponcraft` สร้างอาวุธ, `armorcraft` สร้างชุด หมวก รองเท้า, `jewelcraft` สร้างแหวนและจี้)
  ได้จากอาชีพนักประดิษฐ์หรือตำรา (`book_mastery_<id>` ดรอปแบบตำราทั่วไป) เป็นความเชี่ยวชาญสายชีวิต สูงสุด 30 ระดับ (`CRAFT_MAX`) ไม่เพิ่มค่าสถานะ
  ระดับ 1/5/10/15/20/25 สร้างได้ถึงของเลเวล 30/60/90/120/150/180 (`CRAFT_TIER_AT`) ไม่เสียค่าจ้าง ของมีชื่อผู้สร้าง (ชื่อตัวละคร)
  และทุกระดับเพิ่มโอกาสที่ของออกมาเป็น +1 อีก 1% (`CRAFT_BONUS`, คูณโชคดี)
ปุ่ม "เรียงของ" รวมกองที่ซ้อนได้แล้วเรียงตามชนิด ทรง และสี คลิกขวาที่ไอเท็มมีเมนูใช้/ใส่ ทิ้ง 1 ชิ้น ทิ้งทั้งหมด หรือลากไอเท็มออกนอกกระเป๋าไปวางในฉากเพื่อทิ้ง (ถามยืนยันก่อนเสมอ)

ของเซฟใน localStorage ตัวละครใหม่มีแค่ของที่ใส่อยู่ ยา และทอง (ดูหน้าเริ่มเกม) (เซฟเก่าที่มีไอเท็มชุดจะแยกเป็นเสื้อกับกางเกงให้เอง มีดคู่กลายเป็นมีดสั้นสองเล่ม
และเซฟจากก่อนมีมือรองได้โล่ไม้กลม สมุดเวท และมีดสั้นเพิ่มหนึ่งครั้ง)

**แต่งตัว** (`src/look.ts`): เพศ สีผม และสีตาเลือกตอนสร้างตัวละคร (เปลี่ยนสีผมทีหลังไม่ได้แล้ว v0.3) ทรงผมตั้งต้นคือบ็อบธรรมดา

**ชุดที่เห็นเปลี่ยนตามอาชีพ** (`src/outfits.ts`): ยังไม่มีคลาสใส่ชุดสีน้ำตาล มีคลาสแล้วใส่ชุดของคลาส เปลี่ยนอาชีพที่ 2 หรือ 3 ชุดก็เปลี่ยนตาม
(แบบ RO ที่เปลี่ยนอาชีพแล้วสไปรต์เปลี่ยน) **ชุดสวมใส่** (เสื้อเกราะ เกราะท่อนล่าง หมวก รองเท้า) เพิ่มแค่ค่าสถานะ ไม่เปลี่ยนรูปลักษณ์
แต่ละอาชีพกำลังได้ตัวของตัวเองจาก Oriverse แยกหญิงชาย (ทรงที่มี `job` ใน `SHAPES` ใส่ตามที่วาดมา ไม่ย้อมสี) ตอนนี้มีนักดาบ จอมเวท อัศวิน บาทหลวง นายพราน หัวขโมย และตัวตลก หญิงและชาย (`swordsman_f`, `swordsman_m`, `wizard_f`, `wizard_m`, `knight_f`, `knight_m`, `bishop_f`, `bishop_m`, `ranger_f`, `ranger_m`, `thief_f`, `thief_m`, `jester_f`, `jester_m`) นักรบคลั่งชาย (`warlord_m`; นักรบคลั่งหญิง Oriverse สร้างไม่สำเร็จ จึงยังใส่เสื้อกั๊กนักผจญภัยสีแดง) และจอมเวทนักสู้หญิง (`battlemage_f`; จอมเวทนักสู้ชาย Oriverse สร้างไม่สำเร็จ จึงยังใส่แจ็กเก็ตนักรบสีฟ้า)
อาชีพที่ยังไม่มีตัวของเพศนั้น ชุดของอาชีพคือทรงที่มีอยู่ในสีของอาชีพนั้น: ตัวละครหญิงใช้เสื้อคลุมจอมเวท ชุดนักบวช
หรือเสื้อกั๊กนักผจญภัย ตัวละครชายใช้แจ็กเก็ตนักรบ สายอาชีพเดียวกันใช้ทรงของคลาสแล้วเปลี่ยนสี (จอมเวทนักสู้เสื้อคลุมฟ้า จอมเวทชั้นสูงสีน้ำเงินเข้ม ฯลฯ)
ช่องเสื้อกับกางเกงของตัวละครจึงเป็นชุดของอาชีพ (`"@ทรง/สี"` ที่ `src/look.ts` อ่านเป็นชิ้นผ้าตรง ๆ) แทนของที่สวม
**ชุดแฟชั่น** (เสื้อและกางเกงที่ไม่มีค่าสถานะ เปลี่ยนแค่รูปลักษณ์) เอาออกจากเกมไปก่อนเพราะยังไม่มีทางได้มา: ไม่ขายในร้าน ไม่อยู่ในสารบัญ
และที่เซฟเก่ามีอยู่ (ในกระเป๋าหรือใส่อยู่) ขายคืนให้อัตโนมัติตามราคาที่ร้านรับซื้อ (`isFashion` ใน `src/items.ts`)
ชิ้นผ้าเหล่านี้ยังอยู่ในโค้ดสำหรับมอนสเตอร์ที่เป็นคน (โจรป่า แม่มดบึง สาวกมังกรทะเล) และใช้ต่อได้เมื่อมีทางได้ชุดแฟชั่น

ทรงของชุด: เสื้อกับกางเกง/กระโปรงแยกกัน แต่ละชิ้นมี **ทรง** (ครึ่งหนึ่งของสไปรต์ตัวละครจาก Oriverse: เสื้อคือหัวถึงเอวรวมแขน กางเกงคือเอวถึงเท้า) และ **สี**

- **ชั้นของแต่ละชิ้น** (`piece` ใน `src/look.ts`): เสื้อเก็บทุกส่วนของตัวเองไว้แม้อยู่ใต้เอว ทั้งชายเสื้อคลุมที่ยาวลงไป (`tails`) มือ ขอบและเส้นขอบที่ติดกัน
  กางเกงลบส่วนที่เป็นของเสื้อทรงเดิมออก (ชายเสื้อ มือ) แล้วเติมขาที่ถูกบังด้วยสีจากขาข้างล่าง (`legs`) จึงไม่มีรอยตัดครึ่งตัว เสื้อคลุมยาวทับกระโปรงได้ และใต้เสื้อสั้นยังเห็นขาเต็ม

  (รันทุกท่าใหม่ด้วยถ้าตัวใหม่วาดท่าอื่นมาด้วย) เพิ่ม `"cast"` ใน `clips` ของ `wizard_m` แล้วรัน `tools/eye_track.py wizard_m` `tools/hand_anchors.py` กับทุกชีตรวมท่าร่าย และ `tools/hand_fists.py wizard_m`
- ตาของนักรบคลั่งชายกับหัวขโมยชายไม่เปลี่ยนตามสีตาที่เลือก: วาดมาเป็นสีดำ/เทาแทบไม่มีสี จึงไม่มีสีให้ย้อม (ไม่มีใน `tools/eye_track.py`)
- ชุดนักบวชยังไม่มีท่าฟัน (Oriverse สร้างไม่สำเร็จ) จึงใช้ท่าแทงแทนไปก่อน
- เสื้อนักบวชเป็นชุดคลุมยาวที่ต่อลงเป็นกระโปรง (`dress` ใน `bodies.json`) ใส่กับท่อนล่างชุดอื่นจึงได้ชุดคลุมทั้งตัว ตรงผ้าคาดหน้าเปิดให้เห็นท่อนล่าง แทนที่จะถูกตัดครึ่งที่เอว ส่วนขอบกระโปรงของเสื้อที่ยังเหลือตรงเอว (`hem` เช่นเสื้อกั๊กนักผจญภัย) กลายเป็นเข็มขัดหนัง
- ท่าที่ Oriverse วาดอาวุธมาให้ในภาพแล้ว (`builtin` ใน `bodies.json`) ใช้ตามภาพเฉพาะธนูในท่ายิง ส่วนดาบในท่าฟันลอยหลุดมือในบางทิศ เกมจึงวาดดาบเข้ามือเองในท่าแทงแทน ท่าที่มีอาวุธในภาพไม่ใช้กับอาวุธอื่น (สกิลท่าฟัน/ยิงตอนถือค้อน ร่ายเวทของชุดที่ไม่มีท่าร่าย) จะได้ไม่มีอาวุธชิ้นที่สามงอกออกมา
- ไอคอนของเสื้อและกางเกงเป็นภาพชิ้นผ้าแยกชิ้นแบบ RO (เสื้อคลุม กระโปรง กางเกง...) วาดเป็นพิกเซล 24×24 ต่อทรงใน `src/garments.ts` แล้วลงสีตามสีย้อมของไอเท็ม
- สีย้อมเปลี่ยนเฉพาะผ้าหลักของชิ้นนั้น (`cloth` ใน `bodies.json`) ชิ้นอื่นและผมไม่โดน
- เสื้อกับกางเกงทรงเดียวกันย้อมทั้งตัวตามชิ้นผ้า ไม่ตัดที่เอว (เสื้อคลุมจอมเวทยาวเลยเอวลงไป เสื้อกั๊กสีเดียวกับกางเกงอยู่เหนือเอว) ใส่ต่างทรงกันจึงย้อมแค่ชิ้นของตัวเอง

ทรงผมทำงานแบบหัวกับตัวแยกกัน (อย่าง Ragnarok Online):
- ตัวของชุดใหม่สร้างด้วยผมสั้น `tools/char_layers.py body` หาหัวในท่ายืนแล้วตามหัวไปทุกเฟรมของทุกท่า (template matching) เก็บตำแหน่งหัวแต่ละเฟรมลง `bodies.json` แล้วลบหัวออกจากชีต
- ทรงผมแต่ละทรงเป็นสไปรต์ Oriverse ท่ายืน 8 ทิศ ใส่ชุดแดงล้วนเพื่อให้แยกผมออกจากชุดด้วยสีได้ `tools/char_layers.py hair` ตัดหัวเหนือคอกับผมที่ต่อจากหัวลงมา เป็นชั้นหลัง (ผมยาวที่อยู่หลังตัว) กับชั้นหน้า
- ในเกม `Looks.attachHead` วาดชั้นหลัง ตัว ชั้นหน้า ทีละเฟรมตามตำแหน่งหัว หัวทุกสไปรต์ต่อกันได้ที่คอเพราะ Oriverse วางตัวละครทุกตัวกลางช่องเดียวกัน
- ชุดจอมเวทใช้ตัวผมสั้น `outfit_mage_boycut` ที่ตัดหัวแล้ว (`mageb`) ครบ 6 ท่า ผมทวินเทลจึงเป็นทรงผมหนึ่งในระบบทรงผมเหมือนทรงอื่น ตัวจอมเวทตัวเดิมที่มีทวินเทลติดตัว (`mage`) เก็บไว้เฉย ๆ ไม่ได้ใช้แล้ว

สีเปลี่ยนตามช่วงสีของแต่ละตัวใน `public/assets/chars/bodies.json` (ผมกับตาของชั้นหัวอยู่ใน `hair.json`) สีย้อมผมจึงไม่ไปโดนชุด
ตัวละครชาย (`warrior`) ผมกับเสื้อแจ็กเก็ตเป็นแดงชุดเดียวกัน จึงแบ่งด้วยแนวคอที่เลื่อนตามหัวทุกเฟรม

**อาวุธ** (`src/items.ts`, `src/combat.ts`, `src/weapons.ts`): แต่ละชนิดมีระยะ ความเร็ว ดาเมจ และลูกเล่นต่างกัน

| อาวุธ | ท่า | ลูกเล่น |
| --- | --- | --- |
| ดาบมือเดียว / ดาบสองมือ | ฟัน | โดนทุกตัวในแนวโค้ง สองมือกว้างกว่า ช้าแต่แรง |
| ขวาน / ขวานสองมือ / ค้อน | สับ | ขวานคริติคอลบ่อย ขวานสองมือฟันกว้างและหนัก (ใช้ความเชี่ยวชาญขวาน) ค้อนตีหนัก |
| หอกมือเดียว / หอกสองมือ | แทง | ระยะไกล หอกสองมือแทงทะลุทุกตัวในแนว |
| มีดสั้น | แทง | เร็ว เหมาะถือมือรอง |
| ไม้เท้า | แทง + ลูกเวท | ยิงลูกเวทใช้พลังเวท |
| ธนู | ยิง | ยิงไกลที่สุด |
| สนับมือ (v0.3) | ต่อย (ท่าแทงมือเปล่า) | สวมที่กำปั้น ต่อยเร็ว (ทุก 0.45 วิ ดาเมจ 13–17) ระยะสั้น 0.85 ม. อาวุธทุบ ความเชี่ยวชาญเด่นตีให้มึนและเจาะเกราะ |
| กรงเล็บ (v0.3) | ข่วน (ท่าแทงมือเปล่า) | ใบมีดสามเล่มเหนือกำปั้น ข่วนเร็ว (ทุก 0.42 วิ ดาเมจ 12–16) ระยะ 1 ม. คริติคอลบ่อยกว่านิดหน่อย อาวุธฟัน ความเชี่ยวชาญเด่นคริติคอลและเลือดไหล |

สนับมือและกรงเล็บเป็นอาวุธมือเดียวมือหลัก (ใส่มือรองได้อีกข้างเหมือนอาวุธมือเดียวอื่น) ขายที่ร้าน 300 ทอง มีในอุปกรณ์ตามเลเวลทุกระดับ (`t<เลเวล>_knuckle`, `t<เลเวล>_claw`)
สร้าง ตีบวก และดรอปแบบอาวุธอื่น ภาพในมือวาดด้วย `python3 tools/draw_items.py public/assets knuckle claw` (สนับมือนั่งบนกำปั้น ปุ่มหนามชี้ไปทางที่แขนชี้ `grip` 0.64 ·
กรงเล็บมีแถบรัดบนกำปั้น ใบมีดยื่นเลยกำปั้นไปตามแขน `grip` 0.84 ใน `WEAPON_ART` ของ `src/weapons.ts`) ใช้ตำแหน่งมือทุกเฟรมจาก `bodies.json` เหมือนอาวุธอื่น

**มือหลักและมือรอง:** อาวุธสองมือ (ดาบสองมือ ขวานสองมือ หอกสองมือ ธนู) กินทั้งสองช่อง ใส่แล้วของมือรองกลับเข้ากระเป๋า และช่องมือรองแสดงอาวุธนั้นจาง ๆ
อาวุธมือเดียวใส่มือรองได้ (ลากไปช่องมือรอง หรือคลิกขวาเลือก "ใส่มือรอง") ตีทีหนึ่งได้ 2 ฮิต: มือหลักเต็ม 100% แล้วมือรองตามไปอีก 50% ของดาเมจอาวุธมือรอง
ถืออาวุธทั้งสองมือจะตีช้าลง 15% ความเชี่ยวชาญของอาวุธใช้ได้ไม่ว่าจะถือมือไหน ของมือรองที่ไม่ใช่อาวุธ (`offhand` ใน `src/items.ts`):

| ของมือรอง | ราคา | ค่าที่ได้ |
| --- | --- | --- |
| โล่ไม้กลม | 300 | ป้องกัน +6 ต้านเวท +2 |
| โล่อัศวิน | 900 | ป้องกัน +14 ต้านเวท +4 HP +5% เดินช้าลง 3% |
| ขวดแปรธาตุ | 700 | ยาฟื้นแรงขึ้น 25% ฟื้น MP +1.5/วิ |
| สมุดเวท | 650 | พลังเวท +8% ลดคูลดาวน์ 4% ลดเวลาร่าย 5% |
| คัมภีร์โบราณ | 1,800 | พลังเวท +14% MP +10% ลดคูลดาวน์ 6% ลดเวลาร่าย 10% |

อาวุธที่ไม่ได้มากับท่าของ Oriverse จะวาดเข้ามือเฉพาะตอนโจมตีและตอนร่ายเวท (ของมือรองวาดที่มือซ้าย อาวุธสองมือจับกลางระหว่างสองมือ) ตำแหน่งมือทุกเฟรมเก็บใน `bodies.json` (`hands`) หาด้วย `tools/hand_anchors.py` แล้วย้ายลงกำปั้นด้วย `tools/hand_fists.py` (ตัวแรกมักได้ข้อศอกหรือไหล่ของแขนที่ห้อยอยู่) เฟรมที่มือรองถูกตัวบัง (`lh`) วาดของมือรองไว้หลังตัว
ภาพอาวุธและไอคอนวาดด้วย `python3 tools/draw_items.py public/assets` ไอคอนสกิลวาดด้วยโค้ด (`src/icons.ts`)
ยกเว้นสกิลที่มีภาพจาก Oriverse แล้ว (`public/assets/skills/<id>.png` รายชื่อใน `index.json`): สร้างเป็นภาพเดียวแบบตาราง 3×3
ด้วย `generate_image` แล้วตัดด้วย `python3 tools/skill_icons.py <ภาพ.png> 3 3 <id> ...` (ไล่แถวจากซ้ายไปขวา) ตอนนี้มีครบทุกสกิล 157 อัน
(ทุกสกิลในต้นสกิลเดิม 13 ต้น และสกิลจากความเชี่ยวชาญอาวุธ 7 อัน) สกิลของอาชีพที่ 2 และตำราใหม่ทำเป็นตาราง 4×4 แผ่นละ 16 อัน
(`tools/skill_icon_sheets.json` เก็บ prompt ทุกแผ่น `done` บอกว่าแผ่นไหนทำแล้ว ตัดด้วย `skill_icons.py <ภาพ> 4 4 <id> ...`)
ครบทั้ง 288 อัน (18 แผ่น) สกิลลดเวลาร่ายสองอัน (ร่ายฉับไว ร่ายคล่องปาก) ใช้ภาพเดียวกับร่ายไว ตอนนี้ทุกสกิลในเกมมีภาพจาก Oriverse
ไอคอนหมวดก็มาจาก Oriverse แบบเดียวกัน (`tree_<id>`, `mastery_<id>`, `element_<id>`): ต้นสกิลทั้ง 37 ต้น ความเชี่ยวชาญ 8 อย่าง ธาตุ 14 ธาตุ
รวมทั้งความเชี่ยวชาญสนับมือ กรงเล็บ และการสร้าง ธาตุเงา ทอง ควัน และสกิลของอาชีพ v0.2 (6 แผ่น 96 อัน)
อาชีพที่ 3 ทั้ง 11 อาชีพมีภาพครบ: สกิล 182 อัน ต้นสกิล 26 ต้น ตราอาชีพ 11 อัน และขวดยาพิษ แผ่นศิลาจารึก (14 แผ่น `skill_icons_v03_*`)
ไอเทมมีภาพจาก Oriverse ในโฟลเดอร์เดียวกัน ตั้งชื่อตาม id ของไอเทม (ไอเทมที่เคยเป็นสัญลักษณ์ และยา หาภาพชื่อเดียวกันก่อน): หมวก รองเท้า แหวน
เครื่องประดับ 16 ชิ้น ยา 4 ขวด ของเควส 8 อย่าง ตำราทำผม 2 เล่ม เหรียญทอง (`gold_coin` ข้างจำนวนทองในกระเป๋าและร้านค้า)
ตราอาชีพ (`class_<id>`, `job_<id>`) ขึ้นหน้าชื่ออาชีพใน HUD โปรไฟล์ และการ์ดตัวละคร และเป็นไอคอนอาชีพตอนสร้างตัวละคร
ใช้ทั้งในแท็บหน้าต่างสกิลและเป็นภาพของตำราแต่ละเล่มในกระเป๋าและร้านค้า

## ฉาก 3 มิติ

ชุดของสำหรับ 11 เมือง (อีเดน บาฮามัส โยเดีย คราเดีย ไอซ์เบิร์ก ทรุนราดา โอซากิ โนอา ซูโจว ไฮแลนด์ ฮิล เวนิชเซีย) และ 12 ภูมิประเทศของฟิลด์ (ทุ่งราบ เทือกเขาหิมะ สเตปป์ ชายแดน ทะเลทราย ป่าดิบ ภูเขาไฟ และของแดนตะวันตก: ทุ่งและที่ราบ ป่าโบราณกับภูผา แม่น้ำเยือกแข็งกับเขาเหนือ เนินเขากับนาขั้นบันได ซากโบราณ) อยู่ใน `src/world3d/kits/` ดูทุกชิ้นได้ที่ `/kits.html`

ลานหมู่บ้านเป็นฉาก 3 มิติจริง (three.js, WebGL: `src/world3d/`) ส่วนตัวละครยังเป็นสไปรต์ 2D แบบ Ragnarok
- **ของในฉากแปลงจาก Oriverse ทีละสูตร:** `courtyard.ts` คือ `#mesh` ทุกชิ้นของ `oriverse/frieren/courtyard.weave` (repo the-hero-fighter)
  เขียนด้วยฟังก์ชันชื่อเดียวกับ Weave ใน `geo.ts` (`box_at`, `beam_between`, `gable_roof`, `array`, `rotate_z` ...) ตัวเลขและตำแหน่งตรงตามไฟล์ Weave
  บ้าน ศาลาบ่อน้ำ รถเข็น ม้านั่ง ลัง รั้ว ป้าย หิน วางตาม `object` ของ world เดียวกัน (กรอบชนใน `src/world.ts` จึงตรงกับของ)
- **ต้นไม้และพุ่มไม้** (`trees.ts`) สร้างจากสูตร `#tree` เดิม: ลำต้นผ่าน trunk point กิ่งเข้าทรงพุ่มรี (`crown_ellipsoid`) และใบเป็นแผ่นลาย LeafClump ไหวตามลม
- **หินและไม้ตามธรรมชาติ** (`geo.ts` `rock`, `nature.ts`): หินทุกก้อนพองเป็นก้อนนุ่ม ๆ แล้วถูกระนาบแตกตัดเป็นหน้าเรียบใหญ่ ๆ
  แบบหินแตกจริง (ก้อนเกินเมตรมีหน้ามากขึ้น) `coverTop` ปูมอส หิมะ ทราย หรือเถ้าบนหน้าที่หงายขึ้น (ขอบหยัก แรเงานุ่ม `patches` ทำให้เป็นหย่อม)
  `fallenTrunk` ขอนไม้ล้ม (แผ่นรากถอนพร้อมดิน ปลายเลื่อยมีวงปี หรือปลายหักเป็นเสี้ยน กิ่งตอ มอสเป็นหย่อม เห็ดชั้น)
  `stumpOf` ตอไม้บนรากแผ่ (รอยเลื่อยเอียงมีวงปี หรือยอดหักเป็นเสี้ยน หิมะพอกบนหน้าตัด)
  `snag` ต้นไม้ไม่มีใบ (แตกกิ่ง 4 ชั้น รากเกาะดิน ตอกิ่งเลื่อย โพรง ยอดหัก) หน้าตัดไม้ใช้ลายวงปี (`endgrain` ใน `textures.ts`, `endGrain(สี)`)
- **พื้น** (`ground.ts`): ลายหญ้าผสมทางดินตามโพลิกอน `#terrain_paint` ของ Oriverse ใน shader (พื้นเรียบ ไม่มีกอหญ้า 3 มิติ) และดอกไม้ขาว/เหลืองตาม `#scatter`
- รอบลานมีป่า (ต้นไม้และพุ่มไม้) เพื่อไม่ให้เห็นขอบโลก
- **วัสดุ** (`textures.ts`): ลายไม้ หิน ปูน ผ้า โลหะ เปลือกไม้ กระเบื้องหลังคา วาดด้วยโค้ดตอนเริ่ม แล้วย้อมสีตามวัสดุของ Weave (ไม่มีไฟล์ภาพให้โหลด)
- **แสงเงา:** แสงท้องฟ้า + ดวงอาทิตย์ เงาจริง (shadow map คำนวณครั้งเดียวเพราะฉากไม่ขยับ) tone mapping แบบ ACES

กล้อง orthographic ก้ม 45° ตรงกับ `src/projection.ts` ทุกประการ (1 ซม. ต่อ 1 พิกเซลแผนที่) หมุนได้รอบตัวด้วยคลิกขวาลาก หรือปัดจอบนมือถือ
แคนวาส 2D เดิมจึงวาดเอฟเฟกต์เวท ลูกธนู และตัวเลขดาเมจทับฉากได้ตรงตำแหน่ง และการคลิกยังแปลงเป็นจุดบนพื้นด้วยสูตรเดิม
เอฟเฟกต์ที่ราบกับพื้น (วงเวท ดอกไม้ของทุ่งดอกไม้ แสงเรืองบนพื้น) วาดเป็นแผ่นสี่เหลี่ยมในฉาก 3 มิติแทน (`World3D.ground`, `groundSprites` ใน `src/particles.ts`)
ดอกไม้จึงอยู่ใต้เท้าตัวละครและสไลม์ และโดนม้านั่ง กระถาง หรือบ้านบังตามจริง ส่วนกลีบที่ลอยกับลำแสงยังวาดบนแคนวาส 2D

ตัวละคร (ผู้เล่น สไลม์ แม่ค้า) วาดด้วยโค้ดวาด 2D เดิมลงแคนวาสเล็กของแต่ละตัว แล้วตั้งเป็นป้ายหันหน้าเข้ากล้อง (billboard) ยืนที่เท้าในฉาก 3 มิติ
ต้นไม้หรือบ้านที่อยู่หน้าตัวละครจึงบังตามความลึกจริง และตัวผู้เล่นมีเงาจาง ๆ ซ้อนทับให้เห็นแม้เดินไปหลังบ้านหรือใต้ต้นไม้
ดอกไม้ไม่บังตัวละคร วงเป้าหมายใต้สไลม์และวงเขตล่าของบอทเป็นวงบนพื้นในฉาก ตัวละครเลือกแถวของชีตตามมุมกล้อง (8 ทิศ / สไลม์ 4 ทิศ) และ WASD เดินตามมุมกล้องเสมอ

บนมือถือดอกไม้ 60% และ shadow map 2048 (คอมพิวเตอร์ 4096)

## ตัวละครและมอนสเตอร์จาก Oriverse

- จอมเวท: `Ori.sprite.@taoisaman.mage_twintail` สร้างจากข้อความล้วน 8 ทิศ ช่อง 96 px
  ท่ายืน (Rest) เดิน (Walk) ฟัน (Swing) แทง (Thrust) ยิง (Shoot) ร่ายเวท (Cast)
- ชุดนักบวช `outfit_priestess` ชุดนักผจญภัย `outfit_adventurer_b` ตัวละครชาย `warrior_boy` และทรงผม `hair_*` สร้างแบบเดียวกัน
  ชุดใหม่ใช้ท่าตี 4 เฟรม (ประหยัดเครดิต) เดิน 8 เฟรม ทรงผมมีแค่ท่ายืน ตัวละครชายใช้ท่าตี 8 เฟรม
- ชุดจอมเวทผมสั้น `outfit_mage_boycut` (ตัดหัวเป็น `mageb`) ยืน เดิน 8 เฟรม ฟัน แทง ยิง 4 เฟรม ร่ายเวท 8 เฟรม ใช้แทนตัวจอมเวทที่มีทวินเทลติดตัว
- สไลม์: `Ori.sprite.@taoisaman.jelly_slime` 4 ทิศ ช่อง 64 px ยืน กระโดด (Hop) โดนตี (Hurt) ตาย (Die) สีอื่นได้จากการหมุน hue
- ตัวที่สร้างโดยแนบภาพอ้างอิงไปด้วยสร้างท่าทางไม่ได้ ("Animation first frame differs from its retained input") ต้องสร้างจากข้อความล้วน
- ดึงเฟรมจาก `preview_sprite` (`height_px` เท่ากับขนาดช่อง) ได้ 1 ภาพต่อท่าต่อทิศ แล้วต่อเป็นชีต:
  ```sh
  python3 tools/sprite_cells.py --size 96 --frames 8 public/assets/chars/mage_walk.png Walk_0.png … Walk_7.png
  python3 tools/char_layers.py body priestess RAW_DIR 39       # ตามหัว ลบหัว เขียน bodies.json
  python3 tools/char_layers.py head swordsman_m RAW_DIR 34     # ตัวชายที่เก็บผมของตัวเอง: ตามหัวอย่างเดียว ไม่ลบ
  python3 tools/char_layers.py hair bob Rest.png               # แยกชั้นผมหลัง/หน้า เขียน hair.json
  python3 tools/hand_anchors.py priestess public/assets/chars/priestess_thrust.png …
  python3 tools/hand_fists.py priestess                       # มือลงกำปั้น หามือรองใหม่
                                                              # มือที่ใส่ถุงมือ (GLOVES) หรือกำปั้นเหล็กที่ไม่เห็นผิว (REACH) ตั้งไว้ใน tools/hand_anchors.py
  python3 tools/eye_track.py swordsman_m                      # ตาของตัวชาย (กรอบตาใน BOXES) สำหรับเปลี่ยนสีตา
  ```
  ทุกชีตมี 1 แถวต่อทิศ (ลำดับของ Oriverse: หน้า แล้ววนตามเข็มนาฬิกามองจากด้านบน) และ 1 คอลัมน์ต่อเฟรม
