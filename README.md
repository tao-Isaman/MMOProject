# MMOProject: ลานหมู่บ้าน + เวททุ่งดอกไม้

ต้นแบบเกม MMORPG บนเว็บ เดินในลานหมู่บ้านที่สร้างใน Oriverse เลือกคลาสจอมเวทหรือนักรบ ตีสไลม์ เก็บเลเวล (สูงสุด 200) แจกแต้มสกิลลงต้นสกิล ความเชี่ยวชาญ และธาตุ เก็บของเข้ากระเป๋า และแต่งตัว
TypeScript (strict) + Canvas 2D, build ด้วย Vite

## เล่น

```sh
npm install
npm run dev        # เปิด http://localhost:5173
npm run build      # ตรวจ type (tsc --noEmit) แล้ว build ลง dist/
npm run typecheck  # ตรวจ type อย่างเดียว
```

Vercel build ด้วย `npm run build` แล้วเสิร์ฟ `dist/` (ดู `vercel.json`) ไฟล์ภาพและ JSON ทั้งหมดอยู่ใน `public/assets/` และเสิร์ฟที่ `assets/...`

## คลาส เลเวล และค่าสถานะ

เริ่มเกมครั้งแรกเลือกคลาส (`ClassPicker` ใน `src/charui.ts`) แล้วได้อาวุธของคลาสนั้นใส่มือ

| คลาส | จุดเด่น | ต้นสกิลเริ่มต้น |
| --- | --- | --- |
| จอมเวท | MP และพลังเวทสูง HP ต่ำ | เวทโจมตี, เวทพฤกษา, เวทผนึก |
| นักรบ | HP พลังโจมตี และพลังป้องกันสูง | คลั่ง, ผู้พิทักษ์, ดวลดาบ |

- เลเวลสูงสุด 200 ค่าประสบการณ์ต่อเลเวลคือ `round(25·L^1.55 + 15)` (`src/progression.ts`)
- ทุกเลเวลได้ 1 skill point (เลเวล 1 มี 1 แต้ม) แจกได้สามทาง: ต้นสกิล ความเชี่ยวชาญ ธาตุ
  ตอนนี้รีเซ็ตแต้มได้ฟรีในหน้าต่างสกิล
- ค่าสถานะ (`src/stats.ts`): HP, MP, พลังโจมตี, พลังเวท, ป้องกัน, ป้องกันเวท, คริติคอล, แรงคริติคอล, ความเร็วโจมตี, ความเร็วเดิน, ลดคูลดาวน์, ฟื้น HP/MP
  มาจากค่าตั้งต้นของคลาส + การเติบโตต่อเลเวล + ธาตุ + passive + บัฟ
- สูตรดาเมจ: ตีปกติ = (ดาเมจสุ่มของอาวุธ + พลังโจมตี) × (1 + โบนัสดาเมจ) ไม้เท้าใช้พลังเวทแทน
  สกิล = (พลังโจมตีหรือพลังเวท + พลังอาวุธ) × ตัวคูณของสกิล บวกโบนัสธาตุ
  คริติคอลคูณ (1 + แรงคริติคอล) แล้วลดตามป้องกัน `× 100 / (100 + def)` (ป้องกัน 100 รับดาเมจครึ่งเดียว)
- สไลม์มีเลเวล (1, 3, 5, 9) และสวนกลับ สไลม์ม่วงโจมตีก่อนเมื่อเข้าใกล้ สไลม์ตายแล้วเกิดใหม่หลัง 9 วินาที
- ผู้เล่น HP หมดแล้วเกิดใหม่ที่จุดเริ่มหลัง 4 วินาที

**ต้นสกิล** (`TREES`): ต้นละ 5 ช่อง (สกิลกดใช้กับสกิลติดตัว) ต่อกันเป็นต้นไม้ ช่องไหนมี `req` ต้องอัพช่องก่อนหน้าถึงระดับที่กำหนดก่อน (เช่น ลำแสงทำลายล้างต้องมีระเบิดเวทระดับ 3 และเวทเจาะเกราะระดับ 2) ต้นสกิลใหม่ปลดล็อกจากหนังสือสกิล (ตอนนี้มี "ผู้รอดชีวิต" ใช้ได้ทุกคลาส)

**ความเชี่ยวชาญ** (`MASTERIES`): อัปเป็นเส้นตรงสูงสุด 30 ระดับ แต่ละระดับดาเมจ +2% ความเร็วโจมตี +0.5% เมื่อถืออาวุธชนิดนั้น
จุดบนเส้น: ระดับ 5 ติดตัว, 10 ดาเมจ +5%, 15 ได้สกิล, 20 ความเร็วโจมตีและคริติคอล, 30 ปรมาจารย์ เริ่มเกมมีครบทุกอาวุธ (ดาบ ขวาน ค้อน หอก มีด ไม้เท้า ธนู)
ทักษะชีวิต "การเก็บเกี่ยว" ปลดล็อกจากหนังสือ (เพิ่มโอกาสดรอป)

**ธาตุ** (`ELEMENTS`): อัปเป็นเส้นตรงสูงสุด 50 ระดับ ทุกระดับได้ค่าสถานะหลายด้าน และเสริมสกิลทุกสกิล (ทั้งต้นสกิลและความเชี่ยวชาญ)

| ธาตุ | เด่น | เสริมสกิล | 10 | 20 | 35 | 50 |
| --- | --- | --- | --- | --- | --- | --- |
| ดิน | ป้องกัน | โล่ 0.4% HP สูงสุดต่อระดับตอนใช้สกิล | สถานะผิดปกตินานขึ้น 30% | ลดความเสียหาย 5% | โล่หนาขึ้นเท่าตัว | HP และป้องกัน +10% |
| น้ำ | ฟื้นฟู | ฮีลแรงขึ้น 2% ต่อระดับ | สกิลดูด HP 5% | ฟื้น MP +15% | ใช้สกิลแล้วฟื้น HP 3% | ดูด HP 10%, HP +8% |
| ลม | ความเร็ว | ลดคูลดาวน์ | ใช้สกิลแล้ววิ่งเร็วขึ้น 25% 2 วิ | ความเร็วโจมตี +6% | 15% คูลดาวน์หายทันที | ลดคูลดาวน์และความเร็วเดิน +8% |
| ไฟ | โจมตี | ดาเมจสกิล +1% ต่อระดับ | สกิลเผา 20% ใน 3 วิ | พลังโจมตีและพลังเวท +5% | เผาแรงขึ้นเป็น 40% | ดาเมจสกิลอีก +15% |
| สายฟ้า (หนังสือ) | คริติคอล | คริติคอลสกิล | สกิลกระโดดไปโดนอีกตัว 30% | แรงคริติคอล +15% | กระโดด 2 ตัว | กระโดดแรง 60%, คริติคอล +5% |

**หนังสือ** ดรอปจากสไลม์ (ม่วงดรอปบ่อยสุด) ดับเบิลคลิกในกระเป๋าเพื่ออ่าน ภารกิจยังไม่มี

**หน้าต่างสกิล** (<kbd>K</kbd>): แท็บต้นสกิลวาดต้นไม้พร้อมเส้นบอกว่าต้องอัพอะไรถึงระดับเท่าไรก่อน คลิกสกิลเพื่อดูตารางทุกระดับ (เปอร์เซ็นต์ ส่วนที่เพิ่ม และดาเมจโดยประมาณจากค่าสถานะตอนนี้) แท็บความเชี่ยวชาญและธาตุเป็นเส้นตรงที่มีจุดความสามารถพิเศษ ชี้ที่จุดเพื่อดูรายละเอียด ลากสกิลไปวางที่แถบสกิล หรือดับเบิลคลิกเพื่อใส่ช่องว่างช่องแรก คลิกขวาที่ช่องเพื่อถอด
แถบสกิลกับความคืบหน้าทั้งหมดเซฟใน localStorage (`mmoproject.character.v1`)

## บอทล่ามอนสเตอร์

บอท (`src/bot.ts`, หน้าต่าง `src/botui.ts`) ล่าสไลม์รอบจุดที่ยืนตอนกดเริ่ม เดินอ้อมบ้าน บ่อน้ำ และพุ่มไม้ด้วยการหาเส้นทางบนกริด 40 ซม. (`findPath` ใน `src/world.ts`)
ตั้งค่าได้ในหน้าต่าง <kbd>B</kbd> และเซฟไว้ใน localStorage (`mmoproject.bot.v1`)

- **สกิล:** ทุกสกิลที่เรียนแล้วมีกฎของตัวเอง เปิด/ปิด และเลื่อนลำดับได้ (บนสุดใช้ก่อน) เงื่อนไขมี 3 แบบ:
  - ทันทีที่พร้อม: สกิลโจมตีใช้เมื่อเป้าหมายอยู่ในระยะ ส่วนฮีล โล่ และบัฟใช้ระหว่างสู้เมื่อเลือดไม่เต็ม ไม่มีโล่ หรือบัฟหมด
  - เมื่อ HP ต่ำกว่า X%
  - เมื่อมอนในวงสกิล (หรือรอบตัว) มีอย่างน้อย N ตัว
  สกิลที่เรียนใหม่จะเพิ่มท้ายรายการพร้อมเงื่อนไขตั้งต้นตามชนิด
- **ตีปกติ:** ตีระหว่างรอคูลดาวน์ ถ้าปิดไว้ บอทจะยืนห่างตามระยะของสกิลที่สั้นที่สุด
- **เป้าหมาย:** เลือกชนิดสไลม์ที่จะล่า เลือกตัวที่ใกล้ที่สุด เลือดน้อยที่สุด หรือเลเวลสูงที่สุด และเลือกได้ว่าจะสู้กับตัวที่โจมตีเราก่อนเสมอ
- **พื้นที่ล่า:** รัศมี 3–25 ม. รอบจุดศูนย์กลาง (เส้นประบนพื้น) ย้ายจุดศูนย์กลางมาที่ตัวละครได้ ไม่มีมอนในเขตก็เดินกลับไปรอที่จุดศูนย์กลาง
- **พักฟื้น:** HP หรือ MP ต่ำกว่าที่ตั้งไว้และไม่มีตัวไหนไล่ตีอยู่ จะนั่งพัก (ฟื้น 2.5% ต่อวินาที) จนถึงระดับที่ตั้งไว้ และเก็บ MP ส่วนหนึ่งไว้ให้สกิลช่วยเหลือได้
- **อื่น ๆ:** ฟื้นจากการล้มแล้วล่าต่อ, หยุดเมื่อกระเป๋าเต็ม
- กดเดิน คลิก หรือ Space เองได้ตลอด บอทจะหยุดรอ 2.5 วินาทีแล้วทำต่อ เดินไปหาเป้าหมายไม่ได้นานเกิน 1.2 วินาทีจะข้ามตัวนั้นไป 8 วินาที
- ระหว่างทำงานมีแถบด้านบนบอกสถานะ เวลา และจำนวนที่ล่าได้ หน้าต่างบอกด้วยว่าได้ EXP และของไปเท่าไร

## ระบบอื่น

**กระเป๋า** (`src/inventory.ts`, `src/ui.ts`): ตาราง 8×5 กับช่องสวมใส่ 4 ช่อง (อาวุธ ชุด เสื้อ กางเกง)
ลากไอเท็มเพื่อย้ายหรือสลับช่อง ไอเท็มชนิดเดียวกันซ้อนกันได้ ดับเบิลคลิกเพื่อใส่ ถอด หรืออ่านหนังสือ
ของเซฟใน localStorage เริ่มเกมครั้งแรกได้อาวุธครบทุกชนิดกับชุด 11 ชุด

**แต่งตัว** (`src/look.ts`): หน้าต่างแต่งตัว (<kbd>C</kbd>) เลือกตัวละคร ทรงผม สีผม สีตา
ชุดเป็นไอเท็ม: ชุดกำหนดทรงของตัว (แต่ละทรงเป็นสไปรต์ Oriverse ของตัวเอง) และสีตั้งต้น ส่วนเสื้อกับกางเกงเป็นสีย้อมทับท่อนบนและท่อนล่างของชุด ถอดออกได้

| ชุด | ตัว | สี |
| --- | --- | --- |
| ชุดจอมเวท | `mage` เสื้อคลุมขาวขลิบทอง มาพร้อมผมทวินเทล | ขาว/ดำ |
| ชุดนักบวช ×5 | `priestess` เสื้อคลุมยาว ผ้าคาดหน้าตราอาทิตย์ ผ้าคลุมไหล่ | กรมท่า, แดงไวน์, ป่าลึก, รัตติกาล, หิมะ |
| ชุดนักผจญภัย ×5 | `adventurer` เสื้อกั๊กหนัง เกราะไหล่ สายสะพาย กระโปรงจีบ | แดง, ทะเล, พรานป่า, พลบค่ำ, ทะเลทราย |

ตัวไหนที่ชีตยังไม่ครบ 6 ท่า (`clips` ใน `bodies.json`) เกมจะใช้ตัวจอมเวทแทน ชุดและตัวละครชายจะโผล่ในเกมเองเมื่อเพิ่มชีตครบ

ทรงผมทำงานแบบหัวกับตัวแยกกัน (อย่าง Ragnarok Online):
- ตัวของชุดใหม่สร้างด้วยผมสั้น `tools/char_layers.py body` หาหัวในท่ายืนแล้วตามหัวไปทุกเฟรมของทุกท่า (template matching) เก็บตำแหน่งหัวแต่ละเฟรมลง `bodies.json` แล้วลบหัวออกจากชีต
- ทรงผมแต่ละทรงเป็นสไปรต์ Oriverse ท่ายืน 8 ทิศ ใส่ชุดแดงล้วนเพื่อให้แยกผมออกจากชุดด้วยสีได้ `tools/char_layers.py hair` ตัดหัวเหนือคอกับผมที่ต่อจากหัวลงมา เป็นชั้นหลัง (ผมยาวที่อยู่หลังตัว) กับชั้นหน้า
- ในเกม `Looks.attachHead` วาดชั้นหลัง ตัว ชั้นหน้า ทีละเฟรมตามตำแหน่งหัว หัวทุกสไปรต์ต่อกันได้ที่คอเพราะ Oriverse วางตัวละครทุกตัวกลางช่องเดียวกัน
- ชุดจอมเวทยังใช้ทรงผมอื่นไม่ได้ เพราะผมทวินเทลกับเงาเสื้อคลุมใช้สีชุดเดียวกัน แยกออกจากตัวไม่ได้

สีเปลี่ยนตามช่วงสีของแต่ละตัวใน `public/assets/chars/bodies.json` (ผมกับตาของชั้นหัวอยู่ใน `hair.json`) สีย้อมผมจึงไม่ไปโดนชุด
ตัวละครชาย (`warrior`) ผมกับเสื้อแจ็กเก็ตเป็นแดงชุดเดียวกัน จึงแบ่งด้วยแนวคอที่เลื่อนตามหัวทุกเฟรม

**อาวุธ** (`src/items.ts`, `src/combat.ts`, `src/weapons.ts`): แต่ละชนิดมีระยะ ความเร็ว ดาเมจ และลูกเล่นต่างกัน

| อาวุธ | ท่า | ลูกเล่น |
| --- | --- | --- |
| ดาบมือเดียว / ดาบสองมือ | ฟัน | โดนทุกตัวในแนวโค้ง สองมือกว้างกว่า ช้าแต่แรง |
| ขวาน / ค้อน | สับ | ขวานคริติคอลบ่อย ค้อนกระแทกกระเด็น |
| หอกมือเดียว / หอกสองมือ | แทง | ระยะไกล หอกสองมือแทงทะลุทุกตัวในแนว |
| มีดสั้น / มีดคู่ | แทง | เร็ว มีดคู่แทงสองครั้งต่อการโจมตี |
| ไม้เท้า | แทง + ลูกเวท | ยิงลูกเวทใช้พลังเวท |
| ธนู | ยิง | ยิงไกลที่สุด |

อาวุธที่ไม่ได้มากับท่าของ Oriverse จะวาดเข้ามือเฉพาะตอนโจมตีและตอนร่ายเวท ตำแหน่งมือทุกเฟรมเก็บใน `bodies.json` (`hands`) หาด้วย `tools/hand_anchors.py`
ภาพอาวุธและไอคอนวาดด้วย `python3 tools/draw_items.py public/assets` ไอคอนสกิลวาดด้วยโค้ด (`src/icons.ts`)

## กล้องและการเดินลอดใต้ต้นไม้

- กล้องหมุนได้ 4 มุม (ทีละ 90°) แต่ละมุมใช้ภาพฉากของตัวเอง `public/assets/maps/map_y{0..3}.jpg` ที่ถ่ายจาก Oriverse ด้วยกล้องหมุนตาม
  `src/projection.ts` แปลงพิกัดโลกเป็นพิกัดบนภาพตามมุมกล้อง (`setYaw`, `mapX`, `mapY`) ตัวละครเลือกแถวของชีตตามทิศเทียบกับกล้อง
- ของที่ตั้งสูง (บ้าน ต้นไม้ พุ่มไม้ บ่อน้ำ) ถูกตัดเป็นชิ้นแยกไว้ใน `occluders_y{k}.png` แต่ละชิ้นรู้ความลึก (ขอบหน้าฐาน) จึงวาดเรียงกับตัวละครได้
  เดินไปหลังต้นไม้ ตัวจะถูกต้นไม้บัง และชิ้นที่บังตัวผู้เล่นจะโปร่งใสลงให้ยังเห็นตัว (`src/occluders.ts`)
- **สถานะตอนนี้:** มีภาพแค่มุมเริ่มต้น (`map_y0.jpg`) ส่วน `occluders.json` ยังว่าง เพราะการถ่ายภาพจาก Oriverse ต้องให้แท็บ editor เปิดอยู่หน้าจอ
  กด Q/E ตอนนี้จะขึ้นว่า "มุมกล้องนี้ยังโหลดไม่ได้" โค้ดทั้งหมดพร้อมแล้ว รอแค่ภาพ

## ฉากจาก Oriverse

ฉากต้นฉบับอยู่ใน repo the-hero-fighter ที่ `oriverse/frieren/courtyard.weave`
การเชื่อมต่อ Oriverse ที่ใช้ export ฉากเป็นไฟล์ 3D ไม่ได้ เว็บนี้จึงใช้ภาพที่ render จาก Oriverse เป็นพื้น แล้ววาดตัวละคร เวท และ HUD เอง

ทำภาพฉากของแต่ละมุมกล้อง (ทำซ้ำเมื่อแก้ฉาก):

1. โหลด `courtyard_capture.weave` (ฉากล้วน ไม่มีเวท ไม่มีตัวละคร) เข้า Oriverse
2. ถ่ายภาพ orthographic 6 ภาพตาม `tools/capture_tiles.json` (กล้องก้ม 45°, 1 px = 1 cm) มุมอื่นหมุนกล้องรอบจุดกลางลานทีละ 90°
   ถ่ายทีละภาพ (playtest ละ 1 view) จะได้ภาพขนาดเต็ม 2048×1024 แท็บ editor ต้องเปิดอยู่หน้าจอตลอด
3. ต่อภาพเป็นแผนที่ (สคริปต์ลบคำบรรยายที่ playtest ใส่ไว้มุมซ้ายบนให้):
   ```sh
   python3 tools/stitch_map.py r0c0.png r0c1.png r1c0.png r1c1.png r2c0.png r2c1.png -o public/assets/maps/map_y1.jpg
   ```
4. โหลด `courtyard_occluders.weave` (ฉากเดิมบนพื้นสีม่วงแดง ไม่มีพื้นหญ้า) ถ่ายด้วยกล้องชุดเดียวกัน ตั้งชื่อ `B_y<k>_r<row>c<col>.png` แล้วตัดชิ้น:
   ```sh
   python3 tools/occluders.py CAPTURES_DIR --yaws 0,1,2,3
   ```

กรอบชนใน `src/world.ts` ใช้ตำแหน่งวัตถุจาก world ชุดเดียวกัน (`tools/occluders.py` อ่าน `SPECS` จากไฟล์นี้ด้วย)

## ตัวละครและมอนสเตอร์จาก Oriverse

- จอมเวท: `Ori.sprite.@taoisaman.mage_twintail` สร้างจากข้อความล้วน 8 ทิศ ช่อง 96 px
  ท่ายืน (Rest) เดิน (Walk) ฟัน (Swing) แทง (Thrust) ยิง (Shoot) ร่ายเวท (Cast)
- ชุดนักบวช `outfit_priestess` ชุดนักผจญภัย `outfit_adventurer_b` ตัวละครชาย `warrior_boy` และทรงผม `hair_*` สร้างแบบเดียวกัน
  ชุดใหม่ใช้ท่าตี 4 เฟรม (ประหยัดเครดิต) เดิน 8 เฟรม ทรงผมมีแค่ท่ายืน
- สไลม์: `Ori.sprite.@taoisaman.jelly_slime` 4 ทิศ ช่อง 64 px ยืน กระโดด (Hop) โดนตี (Hurt) ตาย (Die) สีอื่นได้จากการหมุน hue
- ตัวที่สร้างโดยแนบภาพอ้างอิงไปด้วยสร้างท่าทางไม่ได้ ("Animation first frame differs from its retained input") ต้องสร้างจากข้อความล้วน
- ดึงเฟรมจาก `preview_sprite` (`height_px` เท่ากับขนาดช่อง) ได้ 1 ภาพต่อท่าต่อทิศ แล้วต่อเป็นชีต:
  ```sh
  python3 tools/sprite_cells.py --size 96 --frames 8 public/assets/chars/mage_walk.png Walk_0.png … Walk_7.png
  python3 tools/char_layers.py body priestess RAW_DIR 39       # ตามหัว ลบหัว เขียน bodies.json
  python3 tools/char_layers.py hair bob Rest.png               # แยกชั้นผมหลัง/หน้า เขียน hair.json
  python3 tools/hand_anchors.py priestess public/assets/chars/priestess_thrust.png …
  ```
  ทุกชีตมี 1 แถวต่อทิศ (ลำดับของ Oriverse: หน้า แล้ววนตามเข็มนาฬิกามองจากด้านบน) และ 1 คอลัมน์ต่อเฟรม

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/main.ts` | โหลด asset, game loop, กล้องและการหมุน, รับปุ่ม, ลำดับการวาด |
| `src/types.ts` | type ที่ใช้ร่วมกัน (Vec2, View, Atlas, Textures) |
| `src/projection.ts` | แปลงพิกัดโลก ↔ แผนที่ ตามมุมกล้อง |
| `src/world.ts` | ขอบเขตเดินได้, กรอบชนของบ้าน/บ่อน้ำ/ต้นไม้/พุ่มไม้, หาเส้นทางอ้อมสิ่งกีดขวาง |
| `src/occluders.ts` | ชิ้นฉากที่บังตัวละคร, ความโปร่งเมื่อบังผู้เล่น |
| `src/player.ts` | ตัวละคร: แอนิเมชัน 8 ทิศ, เล็งตามเมาส์, ท่าโจมตี/ร่าย/พุ่ง |
| `src/progression.ts` | คลาส, เลเวล, ต้นสกิล, ความเชี่ยวชาญ, ธาตุ, หนังสือ, แถบสกิล |
| `src/stats.ts` | คำนวณค่าสถานะและดาเมจ |
| `src/bot.ts`, `src/botui.ts` | บอทล่ามอนสเตอร์และหน้าต่างตั้งค่า |
| `src/hero.ts` | HP/MP, บัฟ, โล่, คูลดาวน์, ตายและเกิดใหม่ |
| `src/skills.ts` | ใช้สกิลทุกแบบ (ลูกเวท พัด ระเบิด ลำแสง พุ่ง ฮีล โล่ บัฟ ทุ่งดอกไม้) และผลของธาตุ |
| `src/combat.ts` | การโจมตีปกติ, ลูกธนูและลูกเวท, ตัวเลขดาเมจ, ไฟลุก |
| `src/monsters.ts` | สไลม์: เดิน, โจมตี, โดนตี, สถานะผิดปกติ, ตาย, ดรอป |
| `src/items.ts` | อาวุธ ชุด เสื้อผ้า หนังสือ วัตถุดิบ และสีย้อม |
| `src/inventory.ts` | กระเป๋าและช่องสวมใส่, เซฟลงเบราว์เซอร์ |
| `src/ui.ts` | หน้าต่างกระเป๋าและหน้าต่างแต่งตัว |
| `src/charui.ts` | หลอด HP/MP/EXP, เลือกคลาส, หน้าต่างสถานะ, หน้าต่างสกิล |
| `src/hud.ts` | แถบสกิล 10 ช่อง, คูลดาวน์ |
| `src/icons.ts` | ไอคอนสกิล |
| `src/look.ts`, `src/recolor.ts` | ประกอบหัวกับตัว, ย้อมสีผม ตา เสื้อ กางเกง และสีสไลม์ |
| `src/weapons.ts` | วาดอาวุธเข้ามือ |
| `src/spell.ts`, `src/particles.ts`, `src/motes.ts` | เวททุ่งดอกไม้, particle, ละอองเรืองแสง |
| `public/assets/` | `maps/` ภาพฉากและชิ้นที่บัง, `chars/` ชีตตัวละครและ `bodies.json`/`hair.json`, `slime_*.png`, `weapons/`, `items/`, texture เวท |
| `tools/` | ต่อภาพฉาก (`stitch_map.py`), ตัดชิ้นฉาก (`occluders.py`), ดึงเฟรมสไปรต์ (`sprite_cells.py`), แยกหัวกับตัว (`char_layers.py`), หาตำแหน่งมือ (`hand_anchors.py`), วาดอาวุธและไอคอน (`draw_items.py`) |
