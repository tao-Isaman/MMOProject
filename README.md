# MMOProject: ลานหมู่บ้าน + เวททุ่งดอกไม้

ต้นแบบเกม MMORPG บนเว็บ เดินในลานหมู่บ้านที่สร้างใน Oriverse ตีสไลม์ด้วยอาวุธ 10 ชนิด เก็บของเข้ากระเป๋า แต่งตัว และร่ายเวท "ทุ่งดอกไม้" จากช่องสกิล 1
ไม่มี build step: HTML + Canvas 2D + ES modules

## เล่น

ES modules ต้องเปิดผ่าน http (ไม่ใช่ `file://`) ใช้ static server ตัวไหนก็ได้ เช่น

```sh
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

| ปุ่ม | ทำอะไร |
| --- | --- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> หรือปุ่มลูกศร | เดิน 8 ทิศ (กดสองปุ่มพร้อมกันเดินเฉียง) |
| คลิกสไลม์ | เดินเข้าไปจนถึงระยะของอาวุธ แล้วตีต่อเนื่องจนกว่าจะตายหรือเราเดินออก |
| <kbd>Space</kbd> | ตีสไลม์ตัวที่ใกล้ที่สุดในระยะ ถ้าไม่มีก็ตีไปทางที่หัน |
| คลิกพื้น | ตีไปทางจุดที่คลิก |
| <kbd>1</kbd> หรือคลิกช่อง 1 | ทุ่งดอกไม้: ร่าย 1.5 วินาที, คูลดาวน์ 9 วินาที |
| <kbd>I</kbd> | กระเป๋า |
| <kbd>C</kbd> | แต่งตัว |
| <kbd>Esc</kbd> | ปิดหน้าต่าง |
| <kbd>`</kbd> หรือเปิดด้วย `?debug` | แสดงกรอบชนและ fps |

## ระบบ

**กระเป๋า** (`src/inventory.js`, `src/ui.js`): ตาราง 8×5 กับช่องสวมใส่ 4 ช่อง (อาวุธ ชุด เสื้อ กางเกง)
ลากไอเท็มเพื่อย้ายหรือสลับช่อง ไอเท็มชนิดเดียวกันซ้อนกันได้ (เยลลี่ใบอ่อนสูงสุด 99) ดับเบิลคลิกเพื่อใส่หรือถอด หรือลากไปวางที่ช่องสวมใส่ก็ได้
ของในกระเป๋าเซฟไว้ใน localStorage ของเบราว์เซอร์ เริ่มเกมครั้งแรกได้อาวุธครบทุกชนิด ชุดใหม่ 10 ชุด กับเสื้อและกางเกงอย่างละตัว (เซฟเก่าได้ชุดใหม่ให้ครั้งเดียว)

**แต่งตัว** (`src/look.js`): หน้าต่างแต่งตัว (C) เลือกตัวละคร (หญิง/ชาย) ทรงผม 11 ทรง สีผม สีตา
ชุดเป็นไอเท็ม: ชุดกำหนดทรงของตัว (แต่ละทรงเป็นสไปรต์ Oriverse ของตัวเอง) และสีตั้งต้น ส่วนเสื้อกับกางเกงเป็นสีย้อมทับท่อนบนและท่อนล่างของชุด ถอดออกได้

| ชุด | ตัว | สี |
| --- | --- | --- |
| ชุดจอมเวท | `mage` เสื้อคลุมขาวขลิบทอง มาพร้อมผมทวินเทล | ขาว/ดำ |
| ชุดนักบวช ×5 | `priestess` เสื้อคลุมยาว ผ้าคาดหน้าตราอาทิตย์ ผ้าคลุมไหล่ | กรมท่า, แดงไวน์, ป่าลึก, รัตติกาล, หิมะ |
| ชุดนักผจญภัย ×5 | `adventurer` เสื้อกั๊กหนัง เกราะไหล่ สายสะพาย ผ้าพันแขน กระโปรงจีบ | แดง/เขียว, ทะเล, พรานป่า, พลบค่ำ, ทะเลทราย |

ตัวละครชาย (`warrior`) ใช้ทรงผมของตัวเอง ใส่ชุดไหนก็ได้สีของชุดนั้นกับเสื้อและกางเกง ผมย้อมสีได้

ทรงผมทำงานแบบหัวกับตัวแยกกัน (อย่าง Ragnarok Online):
- ตัวของชุดนักบวชและนักผจญภัยสร้างด้วยผมสั้น `tools/char_layers.py body` หาหัวในท่ายืนแล้วตามหัวไปทุกเฟรมของทุกท่า (template matching) เก็บตำแหน่งหัวแต่ละเฟรมลง `bodies.json` แล้วลบหัวออกจากชีต
- ทรงผมแต่ละทรงเป็นสไปรต์ Oriverse ท่ายืน 8 ทิศ ใส่ชุดแดงล้วนเพื่อให้แยกผมออกจากชุดด้วยสีได้ `tools/char_layers.py hair` ตัดหัวเหนือคอกับผมที่ต่อจากหัวลงมา เป็นชั้นหลัง (ผมยาวที่อยู่หลังตัว) กับชั้นหน้า (หัว และผมด้านหลังเวลาหันหลัง)
- ในเกม `Looks.attachHead` วาดชั้นหลัง ตัว ชั้นหน้า ทีละเฟรมตามตำแหน่งหัว หัวทุกสไปรต์ต่อกันได้ที่คอเพราะ Oriverse วางตัวละครทุกตัวกลางช่องเดียวกัน
- ชุดจอมเวทยังใช้ทรงผมอื่นไม่ได้ เพราะผมทวินเทลกับเงาเสื้อคลุมใช้สีชุดเดียวกัน แยกออกจากตัวไม่ได้

สีเปลี่ยนตามช่วงสีของแต่ละตัวใน `assets/chars/bodies.json` (ผมกับตาของชั้นหัวอยู่ใน `hair.json`) สีย้อมผมจึงไม่ไปโดนชุดของตัวที่ใช้ชั้นหัว
ตัวละครชายผมกับเสื้อแจ็กเก็ตเป็นแดงชุดเดียวกัน จึงแบ่งด้วยแนวคอที่เลื่อนตามหัวทุกเฟรม

**อาวุธ** (`src/items.js`, `src/combat.js`, `src/weapons.js`): แต่ละชนิดมีระยะ ความเร็ว ดาเมจ และลูกเล่นต่างกัน

| อาวุธ | ท่า | ลูกเล่น |
| --- | --- | --- |
| ดาบมือเดียว / ดาบสองมือ | ฟัน (ดาบและแสงฟันวาดมาจาก Oriverse) | โดนทุกตัวในแนวโค้งหน้าตัว สองมือกว้างกว่า ช้าแต่แรง |
| ขวาน / ค้อน | สับ (ท่าแทง + อาวุธหมุนจากเหนือหัวลงหน้า) | ขวานคริติคอลบ่อย ค้อนกระแทกกระเด็น |
| หอกมือเดียว / หอกสองมือ | แทง | ระยะไกล หอกสองมือแทงทะลุทุกตัวในแนว |
| มีดสั้น / มีดคู่ | แทง | เร็ว มีดคู่แทงสองครั้งต่อการโจมตี |
| ไม้เท้า | แทง + ลูกเวท | ยิงลูกเวทระยะกลาง |
| ธนู | ยิง (ธนูวาดมาจาก Oriverse) | ยิงไกลที่สุด |

อาวุธที่ไม่ได้มากับท่าของ Oriverse จะวาดเข้ามือเฉพาะตอนโจมตีและตอนร่ายเวท ตำแหน่งมือในทุกเฟรมหาด้วย
`python3 tools/hand_anchors.py assets/hand_anchors.json assets/mage_thrust.png assets/mage_cast.png`
ภาพอาวุธและไอคอนวาดด้วย `python3 tools/draw_items.py assets` (บริการวาดชีตพิกเซลของ Oriverse ใช้ไม่ได้ตอนทำ) ไม้เท้ามาจากสไปรต์ Oriverse ตัวเดิม

**สไลม์** (`src/monsters.js`): 16 ตัว 4 สี (เขียว ชมพู ฟ้า ม่วง เลือดและของดรอปต่างกัน) กระโดดไปมารอบจุดเกิด โดนตีขึ้นตัวเลขดาเมจ หลอด HP และกระเด็น
ตายแล้วดรอปเยลลี่ ใบอ่อน หรือเสื้อผ้าเข้ากระเป๋าโดยตรง แล้วเกิดใหม่หลัง 9 วินาที

## ฉากจาก Oriverse

ฉากต้นฉบับอยู่ใน repo the-hero-fighter ที่ `oriverse/frieren/courtyard.weave`
การเชื่อมต่อ Oriverse ที่ใช้ทำงานนี้ export ฉากเป็นไฟล์ 3D ไม่ได้ (export ได้แค่ไฟล์ `.oripak` ของ Oriverse เองกับเกมสำหรับ Windows) เว็บนี้จึงใช้ภาพฉากที่ render จาก Oriverse เป็นพื้น แล้ววาดตัวละคร เวท และ HUD เอง

`assets/map.jpg` ทำแบบนี้ (ถ้าแก้ฉากใน Oriverse ให้ทำซ้ำ):

1. โหลด `courtyard_capture.weave` (ฉากล้วน ไม่มีเวท ไม่มีตัวละคร) เข้า Oriverse
2. ถ่ายภาพ orthographic 6 ภาพตามมุมกล้องใน `tools/capture_tiles.json` (กล้องก้ม 45° หันไปทาง +X, 1 px = 1 cm)
   ถ่ายทีละมุม (playtest ละ 1 view) ภาพจะได้ขนาดเต็ม 2048×1024 ถ้าถ่ายหลายมุมพร้อมกันภาพจะถูกย่อ
3. ต่อภาพเป็นแผนที่ (สคริปต์ลบคำบรรยาย "0s sky full" ที่ playtest ใส่ไว้มุมซ้ายบนของแต่ละภาพให้ด้วย):
   ```sh
   python3 tools/stitch_map.py r0c0.jpg r0c1.jpg r1c0.jpg r1c1.jpg r2c0.jpg r2c1.jpg -o assets/map.jpg
   ```

สูตรแปลงพิกัดโลก (ซม. ของ Oriverse) เป็นพิกเซลบนแผนที่อยู่ที่ `src/projection.js` กรอบชนใน `src/world.js` ใช้ตำแหน่งวัตถุจาก world ชุดเดียวกัน
ตอนนี้ฉากเป็นภาพแผ่นเดียว ตัวละครจึงยังเดินลอดหลังต้นไม้หรือหลังคาบ้านไม่ได้ (จะถูกวาดทับด้านบน)

## ตัวละครและมอนสเตอร์จาก Oriverse

- ตัวละคร: สไปรต์ `Ori.sprite.@taoisaman.mage_twintail` สร้างจากข้อความล้วน มือเปล่า 8 ทิศ ช่อง 96 px
  ท่ายืน (Rest) เดิน (Walk) ฟัน (Swing) แทง (Thrust) ยิง (Shoot) และร่ายเวท (Cast, เพิ่มทีหลังใน revision 2)
- สไลม์: สไปรต์ `Ori.sprite.@taoisaman.jelly_slime` 4 ทิศ ช่อง 64 px ท่ายืน กระโดด (Hop) โดนตี (Hurt) ตาย (Die) สีอื่นได้จากการหมุน hue
- ตัวที่สร้างโดยแนบภาพอ้างอิงไปด้วย สร้างท่าทางไม่ได้เลย (ทุกงานล้มด้วย "Animation first frame differs from its retained input") ส่วนตัวที่สร้างจากข้อความล้วนผ่านทุกงาน
- ดึงเฟรมจากภาพ preview ของ Oriverse (`preview_sprite` ที่ `height_px` เท่ากับขนาดช่อง) ได้ 1 ภาพต่อท่าต่อทิศ แล้วต่อเป็นชีต:
  ```sh
  python3 tools/sprite_cells.py --size 96 --frames 8 assets/mage_walk.png Walk_0.png Walk_1.png … Walk_7.png
  python3 tools/sprite_cells.py --size 96 assets/mage_idle.png Rest_0.png … Rest_7.png
  ```
  ทุกชีตมี 1 แถวต่อทิศ (ลำดับของ Oriverse: หน้า แล้ววนตามเข็มนาฬิกามองจากด้านบน) และ 1 คอลัมน์ต่อเฟรม

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/main.js` | โหลด asset, game loop, กล้อง, รับปุ่ม, ลำดับการวาด |
| `src/projection.js` | แปลงพิกัดโลก ↔ แผนที่ |
| `src/world.js` | ขอบเขตเดินได้, กรอบชนของบ้าน/บ่อน้ำ/รถเข็น/ต้นไม้/พุ่มไม้ |
| `src/player.js` | ตัวละคร: แอนิเมชัน 8 ทิศ, เดินเข้าหาเป้าหมาย, โจมตีตามอาวุธ, ลอยตัวตอนร่าย, cast bar |
| `src/items.js` | ตารางอาวุธ เสื้อผ้า วัตถุดิบ และสีย้อม |
| `src/inventory.js` | กระเป๋าและช่องสวมใส่, เซฟลงเบราว์เซอร์ |
| `src/ui.js` | หน้าต่างกระเป๋าและหน้าต่างแต่งตัว |
| `src/look.js`, `src/recolor.js` | ย้อมสีผม ตา เสื้อ กางเกง และสีสไลม์ |
| `src/combat.js` | การโจมตีปกติ, ลูกธนูและลูกเวท, ตัวเลขดาเมจ |
| `src/weapons.js` | วาดอาวุธเข้ามือ |
| `src/monsters.js` | สไลม์: เดิน, โดนตี, ตาย, ดรอป, เกิดใหม่ |
| `src/spell.js` | timeline ของเวททุ่งดอกไม้ (ย้ายมาจาก Weave เป็นวินาที) |
| `src/particles.js` | ระบบ particle บนพิกัดโลก |
| `src/motes.js` | ละอองเรืองแสงลอยทั่วลาน |
| `src/hud.js` | แถบสกิล 10 ช่อง, คูลดาวน์ |
| `assets/` | `map.jpg` ภาพฉาก, `mage_*.png` ชีตตัวละคร, `slime_*.png` ชีตสไลม์, `weapons/` และ `items/` ภาพอาวุธและไอคอน, texture ดอกไม้/กลีบ/วงเวท |
| `tools/` | ต่อภาพฉาก (`stitch_map.py`), ดึงเฟรมสไปรต์ (`sprite_cells.py`), หาตำแหน่งมือ (`hand_anchors.py`), วาดอาวุธและไอคอน (`draw_items.py`) |
