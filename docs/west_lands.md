# แดนตะวันตก (v0.3) — คอนเซ็ปเมืองและฟิลด์

ทวีปฝั่งตะวันตกของอีเดน มีเมืองใหม่ 4 เมืองและฟิลด์ใหม่ 15 ฟิลด์ (เลเวล 30–200) ทุกแผนที่เชื่อมกันด้วยประตูหรือวาร์ปที่ขอบแผนที่
ส่วนเมืองท่า (ซูโจว เวนิชเซีย) เชื่อมกันด้วยเรือด้วย

หลักในการวางเลเวล: ฟิลด์ที่อยู่ติดกันต้องมีช่วงเลเวลต่างกันมาก เพื่อไม่ให้มอนสเตอร์เลเวลใกล้ๆ กันไปกระจุกอยู่โซนเดียว
ผู้เล่นจะต้องเดินทางไปทั่วแดนตะวันตกตามช่วงเลเวลของตัวเอง

## แผนที่โลก: ตาราง (src/worldmap.ts)

แผนที่โลกเป็นตาราง 13 × 11 ช่อง ช่องละหนึ่งแผนที่ (ภาพจริงของแผนที่นั้นจากด้านบน) อีเดนอยู่ช่อง (0, 0)
คอลัมน์นับไปทางตะวันออก แถวนับลงใต้ แผนที่ที่ติดกันในตารางคือแผนที่ที่มีทางเดินถึงกัน
แผนที่ที่มีสองทางออกด้านเดียวกัน (ประตูตะวันออกของโนอาและของเวนิชเซีย) หรือทางออกอยู่ที่มุม จะต่อกับแผนที่ข้างๆ ทางมุม

```
 คอลัมน์ →  -6        -5          -4            -3          -2            -1             0
 แถว -3                                     หน้าผาเหนือ                ช่องเขาน้ำแข็ง (ไอซ์เบิร์กอยู่เหนือขึ้นไป)
 แถว -2              ที่ราบเนินเขา   ไฮแลนด์ ฮิล   เนินเขาวงกต   เชิงเขาหิมะ    (ปราสาท)
 แถว -1              ภูผาหินปูน     แม่น้ำเยือกแข็ง ทุ่งหญ้าโนอา                  ถนนหลวง
 แถว  0        ช่องเขาตะวันตก ป่าโบราณ      โนอา          ป่าใหญ่ตะวันตก ทุ่งหญ้าตะวันตก  อีเดน
 แถว  1  แหลมตะวันตก ซูโจว     บึงลากูน       ที่ราบใต้โนอา                              ทุ่งสะวันนาใต้
 แถว  2        นาขั้นบันได                                  เวนิชเซีย     ที่ราบแห้งแล้ง   ขอบทะเลทราย
 แถว  3                                                                ที่ราบโบราณ    บาฮามัส
 แถว  4                                                                สุสานหลวง     ป่าดิบแดนใต้
```

เส้นเรือ: อีเดน → โยเดีย → เวนิชเซีย → (เลียบฝั่งตะวันตก) → ซูโจว

| ท่าเรือ | กัปตัน | ไปได้ |
|---|---|---|
| อีเดน | กัปตันมาร์โก | โยเดีย โอซากิ เวนิชเซีย ซูโจว |
| โยเดีย | กัปตันสมุทร | อีเดน เวนิชเซีย |
| เวนิชเซีย | (ใหม่) | อีเดน โยเดีย ซูโจว |
| ซูโจว | (ใหม่) | อีเดน เวนิชเซีย |

## เมือง

### โนอา (`noa`): เมืองหลวงเก่า (ขนาดใกล้เคียงอีเดน)
- **เรื่อง**: เคยเป็นเมืองหลวงที่รุ่งเรืองที่สุด เมื่อคนมากขึ้นราชสำนักจึงย้ายไปอีเดนที่ติดทะเล แต่โนอายังเป็นชุมทางของทวีปฝั่งตะวันตก
- **สถาปัตยกรรม**: แบบเดียวกับอีเดน (หิน ปูน หลังคากระเบื้อง) แต่เก่ากว่า หินสีเทาอมเขียวมีมอสเกาะ หลังคาสีซีด
  กำแพงเมืองชั้นในพังบางส่วน วังเก่าที่เหลือแต่ซุ้มโค้งและเสา ท่อส่งน้ำโบราณ (aqueduct) พาดผ่านเมือง หอนาฬิกา
  ลานตลาดเก่าที่ยังคึกคัก โรงเตี๊ยมของกองคาราวาน
- **ทางออก 5 ทาง**: ตะวันออกฝั่งเหนือ → `noa_meadow`, ตะวันออกฝั่งใต้ → `west_woods` (ไปอีเดน),
  เหนือ → `frozen_river`, ตะวันตก → `elder_forest`, ใต้ → `noa_plains`
- **NPC**: ผู้นำทาง, ร้านค้า, นักบวชรักษา, ช่างตีเหล็ก, ทหารยามทุกประตู, นักปราชญ์ในหอจดหมายเหตุ, คนเล่าเรื่องวังเก่า
- **ชุดโมเดล**: ใช้ชุด `eden` เป็นหลัก ใส่สีแบบเก่า (colourways) และเพิ่มชุด `noa` สำหรับของเก่า: ซากวัง ซุ้มโค้งพัง
  ท่อส่งน้ำ หอนาฬิกา รูปปั้นกษัตริย์องค์แรก น้ำพุเก่า กำแพงพัง

### ซูโจว (`suzhou`): เมืองท่าตะวันตกสุด
- **เรื่อง**: เมืองท่าของพ่อค้าทางทะเลตะวันตก ค้าชา ผ้าไหม เครื่องเคลือบ ตั้งอยู่ปลายสุดของทวีป
- **สถาปัตยกรรม**: แบบจีน: หลังคาโค้งปลายงอนกระเบื้องเขียวหรือเทา เสาแดง ประตูพระจันทร์ กำแพงขาวหลังคาดำ
  เจดีย์หลายชั้น ซุ้มประตูไผ่ไหล (pailou) สะพานโค้งหิน คลอง โคมแดง เรือสำเภา ท่าเรือไม้
- **ทางออก 3 ทาง**: ตะวันตก → `west_cape`, เหนือ → `west_pass` (ข้ามเขาไปโนอา), ใต้ → `rice_terraces`; มีเรือ
- **NPC**: ผู้นำทาง, กัปตันเรือ (`ports: eden, venezia`), ร้านชา, ร้านค้า, นักบวช, ช่างตีเหล็ก, ทหารยาม
- **ชุดโมเดล**: สร้างชุด `suzhou` ใหม่ (ห้ามซ้ำกับโอซากิซึ่งเป็นแบบญี่ปุ่น)

### ไฮแลนด์ ฮิล (`highland`): เมืองโบราณเชิงเขาหิมะ
- **เรื่อง**: ว่ากันว่าเป็นถิ่นกำเนิดของบรรพบุรุษคนในแผ่นดินนี้ เมืองหนาวหิมะคลุม แต่ยังปลูกพืชทนหนาวได้
  (มันฝรั่ง กะหล่ำ ข้าวบาร์เลย์ในเรือนกระจก) มีหินบรรพบุรุษกลางเมือง
- **สถาปัตยกรรม**: คล้ายโนอา (หิน หลังคากระเบื้อง) แต่หลังคาชันขึ้นและมีหิมะ ปล่องไฟหิน กำแพงหินเตี้ยแบบไร่
  ลานขั้นบันไดไต่ขึ้นเขา เรือนกระจก แปลงผักใต้หิมะ วิหารบรรพบุรุษบนเนิน
- **ทางออก 4 ทาง**: ใต้ → `frozen_river` (ไปโนอา), เหนือ → `north_cliffs` (ทะเล), ตะวันตก → `highland_downs`, ตะวันออก → `tangled_hills`
- **NPC**: ผู้นำทาง, ร้านค้า, นักบวช, ช่างตีเหล็ก, ผู้เฒ่าเล่าตำนานบรรพบุรุษ, ชาวไร่
- **ชุดโมเดล**: สร้างชุด `highland`: บ้านหินหลังคาชันมีหิมะ ใช้ร่วมกับของ `eden`/`snowland`/`iceberg` ได้

### เวนิชเซีย (`venezia`): เมืองแห่งสายน้ำ
- **เรื่อง**: เมืองบนลากูน คนเดินทางด้วยเรือกอนโดลา สะพานโค้งข้ามคลองนับร้อย ท่าเรือใหญ่ส่งของไปทุกเมืองท่า
- **สถาปัตยกรรม**: แบบเวนิส: ตึกปูนสีพาสเทล (ชมพู ส้ม เหลือง) หน้าต่างโค้งแหลมแบบโกธิก-ไบแซนไทน์ ระเบียง
  เสาท่าเรือลายเกลียว กอนโดลา สะพานโค้งหิน จัตุรัสใหญ่หน้ามหาวิหารโดม หอระฆังสูง เสาสิงโตปีก
- **ทางออก 3 ทาง**: เหนือ → `noa_plains` (ไปโนอา), ตะวันออกเฉียงเหนือ → `dry_plains` (ต่อไปขอบทะเลทรายและบาฮามัส),
  ตะวันออกเฉียงใต้ → `ancient_plain`; มีเรือ
- **NPC**: ผู้นำทาง, กัปตันเรือ (`ports: eden, yodia, suzhou`), คนพายกอนโดลา, ร้านค้า, ร้านหน้ากาก, นักบวช, ช่างตีเหล็ก
- **ชุดโมเดล**: สร้างชุด `venezia` ใหม่
